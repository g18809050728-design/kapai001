# 八格卡图生产与接入

日期：2026-11-04。需求 FY-ART-001，授权见[根计划 §0.8](../实施计划与验收基线.md)。范围为 174 张 R3 插画，升级面复用。使用本机配置的 API 与模型；凭据由 Windows DPAPI 解密后仅传给本次进程，不进入工程或日志。

| 项目 | 做法 |
|---|---|
| 图集 | 22 张；每张 2 列×4 行，1024×1536；一次请求一张，不使用 n=8 |
| 每格 | 512×384，按左到右、上到下编号；内裁左右16、上下12像素，输出480×360 RGB PNG，不放大 |
| 主体安全区 | 中央70%，外围可舍弃背景；无文字、边框、跨格主体或额外小分屏 |
| 分批 | P01/P02/P03/P04各5张，公共与衍生2张；最后2格留空，不新增卡 |
| 质量与成本 | medium；先试产清单内第1张，核图后继续；不默认多候选；22是首次请求计划，非价格或计费次数保证 |
| 缺失恢复 | prepare只导出本地尚无输出的任务；不可重跑整批或使用force覆盖，超时先核对输出/服务状态 |
| 人物一致性 | 实际上传4张旧卡图与P01/P04肖像的风格参考图；P02/P03使用手/物件/背影，不声称身份已锁定 |

1024×1024的2×4图集会将横向插画压到256像素高；4×2横版的每格则变为竖图。所选竖版2×4能直接得到4:3原格，适合现有约148×96的卡牌小窗。最终内裁480×360保留可供UI二次居中裁切的留白；大型放大展示仍受原始像素限制。

统一画风延续校园成年学生、米白纸纹、深青细线、水粉和彩铅质感；每格仅一个清楚动作。主体场景沿用原174条设计，图集提示词明确全图结构，单卡负面词中的“拼贴分屏”只适用于格内，避免与八格目标矛盾。

运行 `python tools/build_card_art_prompts.py` 和 `python tools/build_card_art_atlases.py prepare`，生成[完整提示词](全新卡牌图片生成提示词_v3.md)、[图集任务](art/card-atlas-jobs-v3.jsonl)和[裁切坐标](art/card-atlas-layout-v3.json)。前者从独立[资源记录](art/card-art-assets-v3.json)恢复实际生成/选用状态。后者不访问API。统一版付费生成使用已安装imagegen CLI的edit，每张图集一次请求、同一现有游戏参考图输入，模型取本机配置；JSONL为任务清单，不直接传给generate-batch以免丢失参考图。先dry-run，再以配置的并发数2执行。每项CLI只启动一次，不重跑已有文件；SDK内部重试与实际计费次数不能据此保证。不增加自定义SDK。

统一版原图保存于 `output/imagegen/card-atlas-v3-unified/`。`crop`仅产出候选；实际查看图集及裁片联系表后，记录原图SHA256与AI视觉观察到 `visual-review.json`，`install`要求核图记录匹配原图才写入 `assets/cards/v3/` 和 `src/ui/ui_labels.json`。保留原图、完整提示词与旧入口所用资源。机器检查覆盖尺寸/解码/重复/hash；Godot导入后检查174个纹理均可加载，再跑UI回归与实际渲染。

AI视觉核对可支持原型选用，人工最终美术签收、服务条款/发布许可核对分别待办。本轮不新增角色肖像、地图、饰品、音轨，不改变卡牌规则、ID或存档。

画风细则见[统一约定](art/card-art-style-v3.md)。首轮纯文字候选已停止且未接入；12张本地原件仍保留在 `output/imagegen/card-atlas-v3/`，当时两个进行中的请求远端结果未知。统一版属于明确画风修正后的返工，不能将总请求仍描述为22次。实际生产数量与UI结果在末尾更新。

## 已生成图片的接入结果

依据用户继续使用图片的要求及[使用设计](plans/2026-11-04-card-art-usage-design.md)，本次从已存在的 22 张统一版图集与 1 张八格修正图集接入 174 张图片，没有新增付费请求。修正图替代 P02-20/23 及 P03-09/11/12/18/24/30 的 8 格，旧格位及原图保留。每张图片的提示词、参考图、原图/格位、输出 hash 和 AI 观察见[资源记录](art/card-art-assets-v3.json)，`generated_count=selected_count=174`。人工最终签收和许可核对保持待办。

已实际查看 174 裁片的全部五页联系表、22 图集总览、修正原图和现有画风参考，按在用格位记录 AI 观察；未采用的串脸/标点候选不参与安装。机器检查 23 张原图均为 1024×1536，174 裁片均为 480×360，损坏、尺寸错误和完全重复均为 0。联系表只能支持主体/画风/裁切初筛，不宣称细节或手部解剖已人工确认。

`assets/cards/v3/` 和 `src/ui/ui_labels.json` 已安装完整 174 ID。手牌、拖动副本、效果待选沿用 `BattleCard`；普通奖励、商店、事件和牌组查看等比显示；学年大奖励改为三候选并排配图，升级/移除目标补缩略图。图片不拦截鼠标；升级不新增插画。卡名、费用和效果独立绘制，未变更规则、内容 ID 或实际玩家档。
