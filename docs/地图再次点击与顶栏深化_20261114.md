# 地图再次点击与顶栏深化

日期：2026-11-14；对应根计划§0.20.10、UIR-019/063。人物UI、搜索及资产接入继续暂停。

地图现在首次点击预选，再次点击同一已选可达节点即可进入，不受系统双击间隔限制。快速双击、固定确认按钮与键盘保留。按下/释放算一次点击，拖动超过阈值后即使返回原位置也不进入；切换节点只预选，不可达、右键及过期回调不进入。节点、滚动和预览原地更新，复用`map:enter`及原GameSession门控，同一渲染最多提交一次。只读全图浮层不受这项导航行为扩展影响。

战斗及地图、房间使用同一个顶栏：资源和饰品在左侧，学年/房间居中，右侧保留地图、牌组数量和齿轮菜单。地图、牌组、齿轮使用原创多色SVG，沿已归档二代顶栏的三入口结构；主入口命中区为实际窗口坐标下64×56像素，不随战场缩小。查阅、演出、进度分组展开，保留原UID/快捷键，速度和动画显示实际状态并原地更新；菜单可滚动，关闭按钮固定，Esc/外部点击收起并恢复焦点。背景手牌、节点和快捷键被隔离，原合法/禁用状态恢复，打开菜单或切换演出设置不重建手牌或清除预选。

设计、资源复核与边界见[独立设计](plans/2026-11-14-ui-navigation-feedback-design.md)和[界面契约](界面层契约.md)。原生SVG在代码内绘制，复用现有字体、场景和卡图，不提取商业游戏运行资产。改前1851项输入hash见[before.json](../artifacts/verification/ui-navigation-feedback-20261114/before.json)。规则、内容、地图算法、玩家档和冻结提交包不属于本批修改范围。
