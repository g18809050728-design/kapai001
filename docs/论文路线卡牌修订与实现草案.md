## 1. 保留的参考规则

开题后每个不同牌名首次实际打出进度+1（上限10），重复同名引用+1（上限5）；第3/4/5层额外付1/2/3专注，付不起不加层、改抽1。同名每回合限打一次，包括公共、升级同名和复制品。新/旧名在卡牌正文前快照，记账在正文后；额外付款使用那时剩余专注。

完成度C=clamp(7×进度+6×引用+修正,0,100)。发表主目标C+10、其他floor(C/2)，满100所有目标再+20，不把新阶段纳入旧结算。增幅只加白名单正向数值，不加完成量、修正或负面；换题成功重置一个已用名并修正-1，不刷新回合同名次数。

## 2. 本轮新增或调整

| 主题 | v3设计与理由 |
|---|---|
| 路线数量 | 两条主流派：发表集中兑现、章节常驻推进；引用循环/完成度经营降为桥接，不强凑独立流派 |
| 章节输出 | 明确替代“中间牌不直接产生完成量”：结果章/结论章常驻可以推进任务，形成不同收益方式 |
| 部署与顺序 | 最多3个有序槽，下回合起效；自动不记账，手动只基础+记账；额外激活每实例每回合一次 |
| 发表代价 | 发表关闭本篇、清全部记录和增幅、所有章节退弃牌，不能无代价保留持续引擎 |
| 再开题 | 允许同战重新开篇；重新抽到/合法取回开题，取回同一个发表实例，不复制发表 |
| 起手 | 开题与引言章；开题固有占首次基础抽牌一格，不额外赠手牌 |
| 增幅 | 上限5；合并强化下一张卡正文首个白名单数值，一次消耗；章节自动和被动不受益 |
| 透支 | 赶工/通宵仍直接失精力并可能失败，本版增加耗尽以限制循环 |
| 引用多层 | 逐层付款，首次不足补抽1并停止本次剩余层数，满上限不收费不补抽 |
| 临时借名 | 只有固定旁听笔记；复制章仍同名、不可部署、使用耗尽，不靠随机改名刷进度 |

白名单为抽牌、放松、恢复精力、获得专注、直接增加论文进度和引用；被动新名记账不是白名单目标。引用转修正先失去原引用的6点贡献；换题不退既有进度/引用，只为下次跨回合用名提供机会。
