# 手机横屏手牌与返回操作（UIR-098）

按用户截图沿 G7 优化横屏。沿用正式校园战场、骨架、牌面资源与六类费用符号。略收紧战场高度，缩窄手牌并增加卡面纵向空间。左侧固定专注和取消，右侧固定牌堆和结束回合，中心手牌滑动停靠至整卡边界。多于可见槽位时显示当前张数范围。移动端省略常驻的目标操作提示，目标高亮和错误反馈继续生效。

将浮层画面与实际输入顺序对齐。牌组及三类牌堆返回后回到原来的战斗，嵌套读卡和底层牌堆的关闭路径分别可点。使用实际触控事件验证关闭、手牌滑动和保留选择，再核对公网入口。
