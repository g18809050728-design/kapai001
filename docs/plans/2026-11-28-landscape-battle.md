# 手机横屏与战斗清晰度（UIR-097）

用户明确以横屏游玩为主。本批修正 UIR-096 的竖屏入口。手机竖屏显示转向说明，转回横屏恢复同一对局。沿 G7 复用现有场景和骨架，继续采用《杀戮尖塔 2》的战场主体、敌方头顶意图、足边数值和底部手牌构图。

- 将回合和 DDL 并入顶栏。取消战场中央横贯的文本通知，移动到手牌信息区。意图紧贴各敌人，脚下显示敌名、进度和状态。使用部件的实际静止边界来适配骨架，并给动作留出空间。
- 横屏画布按可用安全区绘制，提高高像素密度手机的画布比例。保留画面配色，克制背景遮罩，让角色轮廓、乳白战斗字、金色预警和结算数值清楚区分。
- 验收普通遭遇、四位主角及多敌布局。核对横屏窗口、字号、触控、转向、原存档路径和版本化公网发布。
