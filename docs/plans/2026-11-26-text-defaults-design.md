# 文本编辑器编辑结果作为项目默认文本

日期：2026-11-26  
需求：UIR-081  
相关：§0.20.55 实体优先、§0.20.56 怪物分类

## 1. 目标

用户已在文本编辑器修改 237 条文本。把这些修改作为**项目内置默认文本**，而不是只保存在本机 `user://text_overrides.json`。

## 2. 数据

- 源文件：`data/text_defaults.json`（schema 1，237 条）。
- 内容：173 条卡牌详情、60 条词条、3 条 RX 饰品说明、1 条人物被动说明。
- 2026-11-27 追加（UIR-084）：用户编辑的 24 条新手教程文本已并入，内置默认现为 **261 条**；本机教程覆盖已清空，剩余 8 条卡牌说明覆盖保留。[教程默认](2026-11-27-tutorial-defaults.md)
- 这些 UID 均在当前 595 实体/1690 字段库中存在；没有修改规则、数值、命令、RNG 或存档 schema。
- 用户本机原覆盖文件已备份；其中的 237 条已清空，因为已全部成为默认值。

## 3. 分层

显示文本按以下顺序解析：

1. `user://text_overrides.json` 中用户当前修改；
2. `res://data/text_defaults.json` 内置默认；
3. 源 JSON/GDScript 原始文本。

- `TextOverrides.default_text(uid, fallback)` 读取内置默认。
- `TextOverrides.get_optional()`/`text()` 在无用户修改时返回内置默认。
- `TextLibrary` 的字段默认值使用 `default_text()`，因此文本编辑器的“默认”、实体恢复和全部重置都回到新默认。
- 用户覆盖仍可覆盖内置默认；清空某字段后回到新默认。
- 旧 `user://text_overrides.json` 格式不变，旧字段仍兼容。

## 4. 界面与验证
