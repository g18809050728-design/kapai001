# 战斗卡牌文案改进设计

日期：2026-11-06｜需求：FY-UX-026 / FY-UX-026-B｜状态：文案及用户澄清后的停留/固定交互均已实施，最终导入、完整 UI 回归与两尺寸 36 张追加实渲通过，证据见[实施记录](../战斗卡牌文案改进实施记录_20261106.md)。

## 问题与目标

战斗卡面需要保持可快速浏览，但现有悬停和 `I` 详情主要把效果字段压成一串短语。像“完成量”“连携”“实例限次”、先后顺序和条件加值等信息即使存在，也难以让玩家迅速看懂一张牌何时生效、实际做什么。

本次覆盖当前 `campus_four_year` 的 174 个卡牌定义。卡面继续显示精简摘要；战斗详情在当前只读卡面基础上，用白话说明费用、目标、使用条件和效果步骤，并解释影响结果的触发时机、动态值、限次和相关术语。实际升级面和考试替代面以传入视图为准。

## 设计

沿用 `I` 主动打开的固定详情入口，继续使用可滚动面板。卡面摘要不扩成长文，详情文案新增明确的“目标与条件”“结算顺序”“触发/次数”“术语说明”层次。多段效果按内容数组原有顺序逐条呈现；条件效果说明条件不满足时的结果，动态数量保留其计算依据，消耗、保留、持续能力、升级和考试替代等影响实际使用的边界单独标明。短术语释义只解释卡面/详情中实际出现的游戏概念，不引入新规则。

文案从当前生效的卡牌视图和已注册效果/条件字段生成，不维护第二份逐牌效果数据。预览仍只读，不提交命令，也不改领域状态、RNG 或 revision。未知字段沿现有内容校验边界处理，文案层不得把内部 op 名称直接暴露为玩家说明。

FY-UX-026-B：以用户再次澄清为准，完整介绍保留；同一张卡连续停留约 0.7 秒后展开全文，移开该卡立即收起，换卡重新计时，移入未固定说明不能续留。`I` 固定当前卡的说明，再按 `I` 取消；一次只有一份，固定期间其他卡的悬停不替换内容。取消后重新计时，`Esc` 也解除固定。介绍与对应卡牌保持关联，仅在其左侧/右侧定位，根据空间换边并调宽，不使用全局左上角回退。固定后可移入面板滚动阅读，其他出牌操作仍可用。标准/紧凑布局及较大字号共用这套状态；牌堆点击卡牌也固定同一份说明，局外页面沿原行为。

手牌区域按原卡位优先命中，防止抬起卡面的扩大区域截留相邻卡位；扇形外仍可命中当前抬起卡牌。此项来自真实连续鼠标输入暴露的缺陷，与短提示避让一起回归。

费用以当前有效专注/精力费用显示；升级面和考试替代面直接使用规则层已解析的效果，只补充该面实际引用的伙伴/场景元数据。加速剖析的卡面短摘要同步修正为已实现的侵蚀自然结算次数；首张工作加值明确作用于当前正在结算的牌；消耗协同/引用不附带卡牌耗尽的术语释义。P01 被动取回条件按当前实现说明满手仍计入机会，不以文案改动掩盖已有偏差。

## 验收

- 174 张基础定义和所有有升级面的卡均生成非空、无内部 op/条件枚举名的完整详情。
- 代表性用例覆盖组合效果顺序、条件加值、抽弃牌、动态数值、连携、持续能力、每回合/实例限次、消耗、升级和考试替代面；断言关键语义清楚且数量不变。
- 标准/紧凑布局用真实鼠标验证短暂经过不弹、同卡停留后全文、移出立即隐藏、换卡重新计时；5/10 张手牌连续切换及点击/拖拽保持。I 固定后移出仍保留且其他卡不能替换，再按 I 取消，最多一份；详情位于对应卡左右侧、窗口内，长文固定后可滚动。查看前后领域状态、RNG 和 revision 不变。
- 卡面保持短摘要；规则与内容数据 hash 不变；UI 回归及两种窗口尺寸实渲通过。验证命令、环境、输入 hash、退出码和原始日志记录在独立实施记录。

不在本设计范围内：修改卡牌规则、数值、费用、卡牌数据、图片、战斗动画、存档或其他页面的说明样式；亦不代表 G0/G6/G8 阶段验收通过。
