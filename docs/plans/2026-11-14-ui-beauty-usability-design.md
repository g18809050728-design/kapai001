# UI美观与实用性优化设计

日期：2026-11-14。范围来自根计划§0.20.8及文字需求§9.1；沿二代实际UI目标，人物继续暂停。

现状与取舍：已有暖纸地图、全屏场景、同源卡框和扇形战斗。改前地图960图中右侧身份和长路线同滚动，视野容易被图片及长段落占满；奖励/商店卡名与小价签直接压在复杂背景上，主要行动主要靠细边框区分；战斗血条数字较小。仅加装饰不能解决这些问题；改成表格会违反既有构图。采用局部整理：保留同场画面，优先信息对比、分组和稳定操作。

1. 地图右侧使用固定节点摘要和独立路线说明区。摘要含缩略图、类型/名称、层数与明确的“可进入/仅预览”状态；图片在小窗口/大字号缩短，长名称有限行并有全文提示。路线区保留RouteForecast返回全文及不确定性，不自行归纳成收益承诺。单击只替换两块内容，地图原控件/坐标/焦点/滚动不变。
2. 奖励与商品共用卡面和文字底托；选择同时显示勾选和暖金轮廓，悬停/键盘焦点有轮廓，减少动态仍可见。文字不跟随轻抬卡面移动；装饰不拦截指针、不增加命中区。奖励牌适当放大，按可用高度收敛，底部确认始终可见；商店价签紧贴对应商品，明确真实价格和可买/售罄/不足状态。
3. 主要确认采用较暖的切角表面，与次要蓝灰操作区分；禁用仍清楚，焦点仍有独立轮廓。战斗精力、剩余量/屏障增加字号、暗描边和血条厚度，任务意图/名称同样增强可读性，仍位于实体附近。保留真实事件过渡和原终局屏障。

结构：仅共享UiStyle、UiOfferCard、UiExperiencePage和BattleLayout的表现改动。GameSession、规则、内容、RNG、存档及人物控制器均不变；原类型费用角标保持。

验收：新增实际大小窗口与三档字号的地图滚动/预选只读/控件稳定、选牌焦点/确认和关键数值可见测试；保留地图双击与分类套件；完整UI、规则及四学年回归。新目录保存改前hash、输入hash/命令/退出码/原始日志和两尺寸实渲，实际打开地图、奖励、商店、战斗及大字号图片与官方归档对照。测试只证明对应行为，最终相似性、人工资源签收和整版出口继续待完成。
