# 主菜单文本编辑器实体优先改造

日期：2026-11-21  
需求：UIR-077（[需求文件](../../动作或者图片描述/主菜单文本编辑器实体优先_20261121.md)）  
上位记录：§0.20.34、UIR-076（旧版扁平字段编辑器）

## 1. 改造目标

旧结构以“文本字段”为列表单位，搜索 `R3-C-01` 会同时出现名称、基础说明、战斗说明等独立条目。新结构改为：

```text
搜索 → 实体
卡牌 / 饰品 / 人物 / 剧情 / 词条 / 其他
选中实体 → 该实体的全部字段
```

覆盖存储 `TextOverrides` 与现有 UID 保持不变，实体层只做分组、别名和字段展示，因此已有 `user://text_overrides.json` 不需要迁移。

## 2. 实体与字段

| 类型 | 实体数 | 实体 ID | 字段 |
|---|---:|---|---|
| 卡牌 | 174 | `card:R3-C-01` | 名称、基础说明、升级说明、基础战斗说明、升级战斗说明 |
| 饰品 | 104 | `relic:RX-C01` | 名称、说明 |
| 人物 | 4 | `character:P01` | 名称、被动说明 |
| 剧情 | 11 | `story:events.V01`、`story:rooms.L` | 事件标题、地点、叙述、全部事件选项标题；房间标题/地点/叙述 |
| 词条 | 44 | `glossary:focus` | 名称、分类、短说明、详细说明 |
| 怪物 | 60 | `monster:N03` | 名称、已有阶段名、已有意图名 |
| 其他 | 198 | `term:N03` 等 | 保留的旧/共享名称、状态/术语、背景 |
| 合计 | 595 | | 1690 个逻辑字段 |

底层覆盖 UID 共 1711 个：来自旧 `TextLibrary` 的 1699 个，加上为全部事件选项补齐的 12 个新 UID。所有旧 UID 均归属到恰好一个字段。

### 字段别名

`Field` 支持多个 UID：

- 词条名称：`glossary:<key>.name` + `label:<key>`（17 个词条存在共享标签）。
- 事件标题：`story:events.<id>.title` + `label:<id>`。

读取时优先取第一个存在的覆盖；若多个 UID 的覆盖值不同，字段显示“入口不一致”。编辑并保存后，所有别名写入同一文本；恢复默认时清除所有别名。

### 剧情选项

此前只有 `room_stories.json` 中配置过的选项标题可编辑，其余选项名写死在 `page_flow.gd`。本批：

- 新增共享 `EventText.option_name()`，页面与文本库共用同一默认名。
- `CampusRoomIllustration.option_title()` 对所有选项都读取 `story:events.<id>.option_titles.<option>` 覆盖。
- 文本库按事件定义生成全部选项字段。

## 3. 检索与界面

- 顶部页签：全部、卡牌、饰品、人物、剧情、词条、其他，显示实体数量。
- 搜索索引包含实体标题、ID、类型、分类、字段名称、字段默认值与当前草稿；结果按“精确 ID/名称 → 前缀 → 名称包含 → 字段正文”排序。
- 列表只显示实体；有字段命中时显示“命中字段 + 摘要”，选中后自动展开命中字段。
- 右侧实体区显示实体标题、ID/来源、字段数、已修改字段数；动作按钮为保存/撤销/恢复。
- 字段采用折叠块：标题显示字段名、默认/已修改/未保存/入口不一致与字数；点击展开一个字段，正文使用单行 `LineEdit` 或 `TextEdit`。
- 960×600 且字号 ≥125% 时，隐藏说明性副标题、实体元信息和实体状态行，保留标题、紧凑动作与字段列表，保证首个字段可见、可滚动编辑。
- 底栏保留“保存全部 / 全部重置 / 返回”。有未保存修改时返回需二次确认。

## 4. 保存语义

- 字段草稿与已保存值分开维护。
- “保存本实体”只写入当前实体字段，其他实体草稿仍保留为未保存。
- “保存全部”写入全部字段草稿。
- 字段恢复/实体恢复/全部重置只改草稿，点击保存后写入。
- 旧文件中的未归属 UID 保留，不静默删除；全部重置后才清除。
- 保存仍由 `TextOverrides.save_values()` 原子写入，显示层钩子不变。

## 5. 实现文件

- 新增 `src/ui/text_entity_library.gd`：实体构建、字段别名、事件选项补全、搜索索引。
- 新增 `src/ui/event_text.gd`：事件选项默认名共享。
- 重写 `src/ui/text_editor_page.gd`：实体列表、字段折叠、实体级操作、搜索命中定位。
- 修改 `src/ui/game_shell.gd`：缓存 `TextEntityLibrary` 数据。
- 修改 `src/ui/page_flow.gd`、`src/ui/campus_room_illustration.gd`：全部事件选项覆盖接入。
- 更新 `tests/suites/test_ui_text_editor.gd`、`tools/capture_text_editor.gd`。
- 旧 `src/ui/text_library.gd` 保留为实体层的字段来源，不再直接驱动页面。

## 6. 验证

- 专项：实体 595、字段 1690、UID 1711、源 UID 1699；全部旧 UID 有归属；卡牌/剧情/词条别名；全部事件选项；搜索按实体去重；字段编辑、实体保存、别名同步、实体恢复、全部重置、旧档兼容、坏文件回退、活动局不变；1280/960 与 100/125/150% 布局。
- 实渲：主菜单、全部实体、卡牌实体/基础说明/战斗说明、字段命中、剧情实体、词条实体、其他实体、修改/保存、空结果、960×600/150%。
- 完整 UI、完整规则与默认入口回归。

## 7. 已知边界

- 卡牌考试面仍共用基础/升级说明；独立考试面字段是后续扩展。
- “其他”分类保留 198 条旧/共享名称，不把它们强行塞进五类主实体。
- 规则实时拼装的数值短句和固定 GDScript 按钮/提示仍不在自由文本编辑范围。
- 自动化检查与实渲不构成用户最终视觉签收；原整版 G0/G6/G8 出口另记。
