# 战斗反馈与按位置分岔地图设计

日期：2026-11-05｜需求：FY-UX-024｜状态：已实施并完成本轮自动回归和渲染检查，证据及剩余边界见[实施记录](../战斗地图反馈实施记录_20261105.md)。

## 目标

无足够专注时点击手牌只显示不可用原因，不切进卡牌介绍。战斗中按已发布的规则事件逐项呈现卡牌移动和完成量反馈。四学年地图的后继由当前所在节点决定，使选过的路线实际限制下一站；每站最多显示两个可达去向，并继续保留候选节点的可达性。

## 实现

2026-11-06 B2 修正已实施并验证：使用实际手牌控件逐张抽入、落位显示，原位直接弃牌，任务条按 before→after 过渡；特效和队列统一页面倍速 ×4。[新记录](../战斗动画时序实施记录_20261106.md)取代下文初版副本表述。

战斗仍由 GameSession/BattleEngine 执行规则。BattleScreen 接收已排序、去重的事件后，为抽牌、弃牌/消耗与任务完成创建短暂的视图副本动画；每个实际抽牌事件按原顺序单独表现，完成量使用目标附近的数值反馈。动画开关和减少动态路径只控制表现。手牌禁用状态由已有 preview 决定；鼠标与数字键统一显示同一个禁用原因，不生成业务命令。

地图生成器先应用现有实验室、图书馆、风险与服务约束，再求解不超过两条边的逐位置后继。求解以覆盖下一层全部候选、保留每一节点的合法出口为硬条件，并按地图中的相对位置选择边；路线仍只能跨一层。页面以强高亮区分当前节点的直接后继和当前所在位置，其他连接保持低对比度。新开局使用新图；已有存档精确匹配旧图时保留原冻结连接，混合或损坏图仍拒绝。

最后一击切到奖励/终局时，短暂的纯表现层继续消费当前命令事件，保留完成量反馈；队列结束或下一次操作时清理。该层不拦截输入，不持有会话写入口，关闭动画时不创建。

## 错误处理与约束

动画素材缺失时跳过飞牌并保留事件文字；未知事件继续由原队列回退文字显示。短暂无动画对象不进入领域状态，不改变 revision、存档或随机流。若一层在现有节点类型限制下无可行的两边拓扑，生成器测试直接失败并报告年/层/节点，不放宽实验室、图书馆或战斗风险语义。

## 验证

### B2 时序修正设计（2026-11-06 实施与验证完成）

2026-11-06 用户实测要求全体特效基础速度提高 4 倍。BattleScreen.effect_speed() 统一返回页面倍速 × 4，供事件队列、飞牌、血条、闪光、浮字与切页清理使用。以下动作时长均为加速前参数；当前 1× 的实际时长为其四分之一。验证真实加速节奏，防止只改 Tween 而队列等待旧时长。

复用实际手牌控件作为唯一可见抽牌对象，批次开始先隐藏全部待抽牌；紧凑布局使用占位控件保留横向容器槽位，将真实控件临时移至演出层，落位后归还。标准布局演出期间跳过悬停归位。新命令前保存原手牌控件与位置，仅涉及离手事件的控件保留在新页面，card_played 原位提示，card_resolved/card_discarded 原位直接飞入目标堆。仅延长旧副本会保留重复卡面；延迟整个领域视图会影响现有发布边界，因此采用独立表现暂存。

consume_events 同步准备隐藏和数值回退后再启动队列，按 run/revision/index 去重。每张抽牌约 0.50 秒、弃牌约 0.46 秒，敌方血条 0.90 秒、提示 1.05 秒；队列分别留 0.56/0.52/1.12 秒，最后事件持续时间耗尽才发完成信号。动画关闭或重绘/尺寸变化立即收尾，释放占位并恢复所有卡牌；最后一击演出真正结束后再释放只读演出层。

验证实际控件身份、落位时序、单张可见、同 ID 弃后重抽、直接弃牌起点、扣血中间值、重复批次/关闭动画/重绘清理和最后一击；生产会话状态/RNG 对照，双尺寸截图保留。旧通过记录不替代本追加验证。

添加指针和事件演出回归；运行地图生成器后核验 20/28/36/40 个候选、最长两条后继、逐层连通、单层前进、无精英通关路线及四年完整 52 层 fixture。实际渲染以 1280×800 与 960×600 核对当前站、后继路径和卡牌/完成量动画；动画开关两种模式对照相同领域状态与随机快照。完整规则、四年和 UI runner 已通过，18 张两尺寸截图已查看，命令/输入哈希/原始日志见实施记录。
