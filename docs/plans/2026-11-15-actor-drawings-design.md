# P01 / N01 动作补绘与第三轮精修

日期：2026-11-15｜状态：已实现并实渲，完整UI回归通过，最终美术待查看｜范围：根计划 §0.20.17

用户要求继续优化，并明确可以多生成图片。当前累计成功 6/200 张的 API 授权继续有效。本轮只补 P01 林序和 N01 课后习题动作所缺绘图；v1/v2/v3、默认入口、真实玩家档与冻结提交材料保留。

上一版已经支持关节网格、足端约束、持物与眨眼，仍显单一朝向、出手轮廓不明确、受击缺少情绪。沿官方归档中可观察的蓄力、清晰作用姿势与错峰回收来修整；不推断未公开的原作中间件。

## 方案选择

继续只调角度无法画出新的面部与透视。整个人物逐帧替换会丢失已验证的脚点和持物约束，且绘图一致性成本高。因此采用现有原生骨架，加按动作阶段注册的局部替换绘图：头、胸口、出手前臂、纸怪正面和纸扇仍独立，由已有骨骼带动；极短过渡只衔接注册到相同锚点的局部纹理。

## 资源检查先于接入

初批 5 张：P01 侧前转身/专注出手/受击表情头部表，胸口转体表，持笔出手前臂表；N01 蓄力/刺击/受击正面表，以及折叠/张开的背部纸扇表。每次实际上传当前已用的身份或部件参考，保持画风、服装、道具和敌怪类别。接口输出不保证精确排版，保留原图，实际看图后抠取、补关节重叠并注册，另存处理过程与 hash。必要返工另起版本，不重跑已合格图片，不预设用满额度。金额由服务返回情况如实记录。

## 运行表现

- 新资源 version4 与 `--drawings` 显式入口；当前教室及 HUD/目标几何保持。
- P01 先侧前蓄力，肩肘带动伸手、笔尖向右明确出手，再错峰收回；头与胸口同向转体，受击短暂显示闭眼疼痛表情，随后恢复。托举手和笔记本继续独立约束。
- N01 蓄力合扇，笔尖朝左刺出，纸面展开/受击折痕按动作阶段衔接；金属夹、便签和散页继续独立跟随。
- 替换纹理依据表现时间，不写领域；打断从当前局部混合状态衔接，不重启待机；完成/减少动态/重新进入须恢复中立纹理。基础 ×4、用户倍速、一次消费及有限结果等待保留。

## 可观察验收与证据

先以正常速度和明确标注的慢放逐段看动作，再检查全窗口及 960×600、100/125/150% 字号。检查局部替换是否显现并释放、打断是否跳回、是否残留表情/纹理、透明边缘与关节是否断裂、六姿态足端和手物接触，以及实际事件中的作用时序。真实命令 A/B 的规则/RNG/revision/事件必须一致；局部动作预览单独标明。跑旧版本兼容及必要规则/UI 回归。
