# 地图再次点击与顶栏菜单设计

日期：2026-11-14；需求：UIR-019、UIR-063；实施范围见根计划§0.20.10。

用户要求选中地图节点后再次点击也能进入，并继续深度优化右上角菜单。沿已确认的《杀戮尖塔2》实际构图与当前规则实施；人物、美术搜索和冻结提交包保持暂停或原字节。

## 方案与决定

保留全部顶栏入口会继续挤压图标和命中面积；只扩大整排会占用场景；采用二代已归档顶栏的地图、牌组、齿轮三入口结构，将次要操作展开，兼顾构图与操作。精力、金币在左侧，饰品紧随资源，学年和当前房间居中；右侧地图、牌组数量、菜单使用统一高度的图形按钮。菜单按查阅、演出、进度分组，提供中文名称、实际状态、快捷键和禁用原因。

共享顶栏使用实际窗口坐标，避免战斗缩放让点击目标随画面缩至不足44像素。1280×800与960×600及100/125/150%字号沿同一构图；弹出菜单可滚动，关闭位置固定，焦点受控，Esc/点击外部收起并恢复原焦点。原有入口UID、GameSession门控和快捷键保留，打开菜单不得重建手牌、取消预选或推进状态/RNG。演出开关和速度只更新菜单状态，不为改变偏好重建战斗场景。

## 地图输入

第一次有效左键点击选择节点并原地刷新预览；再次点击同一已选、可达节点时进入，不依赖系统双击时间。快速双击继续可用；鼠标按下时记录先前选择，在同一节点释放且未拖动时执行，避免一次点击的按下/释放被误判为两次。切换到另一节点只预选。键盘焦点与悬停不算第一次点击；Enter/空格保留明确激活。不可达、旧generation、右键、拖动和过期revision不得进入；同一页面/修订最多提交一次。全图浮层中的节点继续严格只读。

## 边界与验证

先记录改前hash与需求/契约，再复核现有字体、原生SVG和已归档官方参考，不新增付费/人物资产；随后进入本批G7。只经现有预览、GameSession及一次命令入口，不改规则、内容、存档或地图生成。

定向检查首次/慢速再次/快速双击、切换节点、拖出和拖回、不可达及重复事件；真实Windows鼠标复核。两尺寸三档字号实渲顶栏、菜单、禁用/焦点及地图，核对无重叠、可点击、可读和外部关闭；完整UI与导入保存输入、环境、命令、退出码及原始输出。观察记录不得代替用户审美签收或整版G0/G6/G8出口。
