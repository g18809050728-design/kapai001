# 2026-11-20 · 全饰品正式接入与图鉴

> **后续决策（§0.20.37）**：下面是 120 件方案的历史交付记录。现行版本已移除全部 16 件 FY，仅保留 104 件 RX；以[移除与旧档转换记录](2026-11-20-relic-removal-design.md)为准。

原设计 §5 的 24 件仅首测限制由用户本轮「所有的饰品都落实到游戏中」取代。范围为全部 104 件 RX（含金色）及既有 FY 继续可获得，不是把 104 件一次性装备。保持三槽、八次年内奖励、四次独立大奖励。普通启动新冒险启用全量内容，现存正式冒险与旧试点按各自原 manifest/hash 读取；不迁移冻结候选。黄金、经济折扣、死亡保护、跨战标记采用独立新内容版本。现有定义、旧图、作品与真实存档保留。

## 接入方案

仅图鉴展示会漏掉玩法；直接改现行 manifest 会破坏旧档和冻结候选。因此为默认**新冒险**引入独立正式内容版本，复用原四学年地图与合法命令。仅按装配与明确的时点触发原设计数值：基础准备与抽牌、出牌前快照、结算／待选收尾、任务压力、阶段、自然／额外章窗口、状态、合作及交易／战斗／大奖励。跨战次数归存档，不因换位、读档或预览刷新。每次候选仍至多一金；考场限制看当年可达的未来遭遇。新局沿用试点发奖层（3/9，4/11），非地图改版。

## 图鉴与图像

图鉴新增第三页，复用连续八项画廊，按名称、效果、ID 搜索，按通用／角色／学年和品质过滤；详情有大图、完整效果、实际来源及上下项。继续采用游戏现行卡框、导航和焦点契约，不建第二套界面。三槽奖励和战斗小图与图鉴共用同一选定插画。

重绘票据、夹具、尺具、册页等易混簇，使用实体结构、轮廓、角度、材质和颜色共同区分，不以换色或品质框充数。按已有图像 API 配置制作独立 V2，保留 V1；四格母图对齐 256px 小图，并核对 64px 缩略。预算起点 159/200，最多 41 张成功原图；不重复生成既有可辨识资源。界面证据覆盖两个窗口、三字号、键盘焦点与真实奖励触发。全量平衡、用户最终美术和原 G0–G8 出口继续单独核收。

## 实际交付

- 普通主菜单「新的四年」加载正式全量版本；「继续冒险」按存档原 manifest 和内容校验读取。显式 24 件试点仍可单独启动，存档目录不合并。学年奖励仍三选一，保留三个装备槽、八个学年饰品奖励机会和四次独立大奖励。新金色 RX 从大三起进入奖励；早年原有 FY 金色保留低权重获取途径。
- 三槽共同按位置裁切：同一直接工作首段最多 +10，常规伙伴同段最多 +8，自然准备阶段额外专注最多 +2。部分兑现仍发生代价；完全裁切不记「首次实际」使用。`R3-P03-29`／`R3-P04-40` 启用对应主目标饰品时由玩家实际指定主目标，不替其他群体命中加值；虚弱扣除只跟原任务实例和阶段。前者实付为 0 时不额外要求指定。
- 美术使用原有 API 配置生成 14 张四格母图，选定 56 张 V2；其余 48 张 RX 延用 V1，16 张 FY 未替换。重点拉开轮廓、角度、材质和色彩；五张做了可重复的格边残片清理。104 张 RX 选图均为 256×256 无损 WebP，解码、尺寸、精确重图检查通过；纸底不是透明图。累计 173/200 张 API 母图。原图/提示保存在 `output/imagegen/relic-roster-20261120/`，可从[资源清单](../../assets/art/relic-roster-v2/asset-manifest.json)回追母图与格位。最终美术评价由用户决定。
