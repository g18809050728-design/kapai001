# 身份入口与游戏记录视觉修订

对应 §0.20.52 / UI-ACCOUNT-03。用户指出右上角登录样式与游戏记录页难看，当前大斜角身份条和裸背景上的稀疏文字不作视觉接受依据。

身份入口使用较小的圆角暗色底、细边、人物轮廓与状态点，昵称和状态有不同字号及颜色。保留右上角位置、44/52像素触控区、完整昵称提示、明确焦点和点击账号操作；长昵称省略不撑开布局。

游戏记录使用独立页面构图：暗化书桌背景、留白标题与来源入口、轻量汇总行、稳定滚动的记录区域和固定返回。空记录有居中图形及明确说明；有记录时用人物肖像、角色/难度、结局和到达学年组织条目。账号历史浮层使用同样的信息顺序。复用当前字体、背景与选定肖像；图形用代码绘制，无新位图或局外HTML。

验证只使用隔离档案与受控展示数据，覆盖空列表、多条记录、长昵称、两窗口三字号及移动横屏；确认返回/账号入口仍走既有动作与权限，查看记录不改存档或RNG。结果及截图见 `artifacts/verification/account-records-polish-20261121/`，完成后追加。用户最终视觉判断另记。
