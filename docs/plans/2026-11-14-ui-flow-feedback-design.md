# 创建配置、地图分路与操作流程修正

日期：2026-11-14。来源：用户逐项指出高级设置位置、难度未生效、`image copy 4.png`顶栏图标混乱、待选界面误放新一局、社团等服务无情境、重复分路及重复确认问题。依根计划§0.20.9实施；人物继续暂停。

## 决定与边界

沿二代实际游戏的窄顶栏、纸面地图和情境画面实施。高级设置与难度放在创建页固定配置区，种子编辑作为独立弹层，关闭保留草稿。难度提示直接来自生产规则；本批启用四年宽松/标准/挑战三档：开局精力84/72/60，DDL偏移+2/0/−1（仍受最小DDL约束），敌方每次意图的压力按80%/100%/120%向上取整，最后应用乏力/虚弱等原修正。不改变卡费、奖励或地图种子。标准规则原样保留。属于本批可调试玩参数，不能称平衡验收。

只改文字或只提高节点数均无法解决等价分路。采用map_version=3：冻结原v1/v2算法，三个主方向与长支线继续；支线独立安排同一段原有节点预算，至少两个不同节点类别/补给时机，保留风险层避免连续精英。选择分路时能看到实际顺序差异；全部路径仍有原战斗/商店/休息/服务数量、可达Boss与安全路线，起点/Boss外无全图必经节点。旧局之后的学年继续用旧算法。新增难度仅增补配置，只有反向删除两档并严格重现历史内容hash时才接受旧标准档，不放宽未知内容的兼容检查。

顶栏统一原创细线图标的尺寸、笔画、底托、悬停/焦点；牌组与记录使用不同图案并给出文字提示。抽弃待选的退出入口改“返回主页”，只切换页面，待选工作区保持内存，继续后原样恢复，禁止保存半条效果。

完整地图采用独立近全屏浮层，来自本学年已冻结公开节点，所有节点/连线及图例可看，点击节点读摘要，支持M/Esc/关闭/背景关闭与焦点回还，不提交规则命令或刷新战斗手牌。普通房间、奖励、战斗共用，未来学年不提前揭示。

事件与社团/实习/图书馆/实验室/导师/毕设复用已核对校园背景和相关既有插画，补独立情境主图、实际节点标题、简短活动描述与选项含义，避免一屏只有按钮。使用本作已存在资源，不生成/购买人物。普通无目标的休息/事件/服务操作直接执行一次，付费/选牌/替换/升级/删牌保留预览与一次最终确认；取消在左、主要确认在右且位置固定，地图原位单击只读/双击进入保留。目标选择不重建鼠标下地图控件。

## 验证

新难度：生产GameSession创建→实际战斗→压力结算→保存继续，三档同seed的地图/RNG对照；标准旧档content hash兼容与未知hash拒绝。地图：四年×多种子逐路预算/无死路/无交叉/无连续风险/非等价分岔、v1/v2逐字确定性与旧局跨年。UI：1280×800/960×600、100/125/150%，高级设置不滚走，实际选难度、模态焦点、地图打开/关闭不改revision/RNG/手牌，返回主页保留强制待选，直接操作仅提交一次，确认位置一致。运行完整规则/UI回归，保存独立原始日志、输入hash及实渲，实际看图。冻结提交包/人物/类型费用图案保持原字节，整体G0/G6/G8未完成出口继续保留。
