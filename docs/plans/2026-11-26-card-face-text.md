# 卡面正文改用可编辑“说明”文本（2026-11-26）

**范围**：表现层文字来源，`src/ui/card_display_model.gd` 一处。规则、数值、命令、RNG、存档与内容定义不变。

## 背景

卡图只有 480×360 插画（`assets/cards/v3/*.png`），卡面文字由 `CardFaceView.paint()` 运行时绘制。此前卡面正文读 `UiContentText.card_summary()`，即按效果定义自动生成的短句；文本编辑器里的“说明 / 战斗说明”只影响悬停、`I` 详情与局外详情面板，卡面与玩家改过的文案不一致。

## 实现

- 新增 `CardDisplayModel.face_summary(face, definition_id)`，正文改读 `UiContentText.describe_card()`（用户覆盖 → 内置默认 → 源文本）。
- 过滤卡框已表达的行：首行类型/费用/目标表头、`使用条件：`（卡面已有“需：”前缀）、`打出前提：`、`触发条件：`、`触发时机：`、`正常合作：`、`支援：`、`章节常驻：`、`不可主动打出`、`打出后按顺序结算：`，以及底部署名行 `消耗 / 保留 / 固有`。
- `持续能力：…；同名不叠加` 压缩为“从下回合生效”，保留能力牌生效时机。
- 过滤后为空回退到原自动摘要；正文沿用卡面既有 4 行额度与“… I 查看完整条件与效果”提示，版面不变。

## 实测

346 张真实卡面（基础 + 升级）：旧自动摘要 318 张完整显示、28 张超限；新说明文本 288 张完整显示、58 张超限。战斗说明实测 9–35 行，远超卡面 4 行额度，因此卡面正文统一使用“说明”，战斗说明继续作为战斗内悬停/`I` 详情文本。

证据（本地，`artifacts/verification/` 已被 `.gitignore` 排除）：`artifacts/verification/card-face-text-20261126/`，含旧/新卡面对照、P01 种子 42 真实首战 1280×800 与 960×600 实渲、完整 UI 套件日志；采集脚本 `tools/capture_card_face_text.gd`。

## 验证

完整 UI 套件结果为既有 3 项失败（`shop content really scrolls` 与 2 项 `battle pointer`），单独运行 `test_ui_battle_pointer` 通过（failures 0），与 `AGENTS.md` 记录的基线一致；本改动未新增失败。
