# 菜单、查阅与饰品深化设计

对应根计划§0.20.13、UIR-068，细化UIR-063。用户已要求继续实现；本批未修改人物，独立人物实践按§0.20.14追踪。

核对发现：地图菜单没有记录入口；帮助为连续长段；战斗饰品按钮调用牌组浏览，而其卡牌渲染分支并未展示末尾饰品文字；替换页固定写三个槽且只有文字；菜单提示仅悬停可见，保存门控在成功时仍附“尚未开始冒险”。这些均属于本批修正范围。

采用共用的游戏内查阅浮层，直接延续已归档二代顶部资源与装备、右侧导航、暗色覆盖层及固定关闭入口。比较过继续扩写旧长文弹窗、跳转独立页面和原地共用浮层：选择原地浮层，保留当前地图/战斗控件、手牌、预选、滚动与焦点。四个分页为饰品、规则帮助、战斗记录、冒险信息；仅改变查阅内容，关闭后恢复先前合法状态。

- 菜单所有页面提供记录、帮助、冒险信息、设置、保存及主页；战斗保留现有演出控制。标题区展示真实人物/难度，保存行直接展示可保存状态或原因。设置走现有GameShell路由，返回原场景；主页不自动结束当前局。
- 顶栏三个装备位（旧规则按实际槽数显示，顶部最多三个缩略位）使用现有定义图片，点击直接选中该饰品；总入口显示实际件数。空槽可打开饰品册并解释装备来源，不伪造初始饰品。
- 饰品册按真实slot排列，显示名称、实际槽号、定义图、完整触发/限制/地图效果。空槽与满槽有明确文案；领取/商店/事件继续共用原预选确认，替换前显示所失去的完整旧效果和图片。只读查看不提交装备操作。
- 规则分胜负与资源、出牌与地图操作、饰品与保存等小节；从公开只读数据展示当前值，不补造未实现数值。
- 记录使用SessionView.event_log，说明最多保留1000条的边界。显示真实来源/目标、事件名及实际before/after，按一次命令分组；提供搜索、战斗/全部筛选与新旧顺序，空结果可恢复。不把地图事件称作本场战斗，不伪造回合或伤害。
- 专注重绘为圆形金属装置和蓝色内芯，数值居中且尺寸适配；只显示player.focus。规则/记录/保存图标统一笔画与实体轮廓。

浮层以实际窗口布局，头部与关闭固定，全文独立滚动。背景指针、快捷键和焦点隔离；关闭恢复真实disabled/focus_mode和原焦点。规则/记录/饰品不重建手牌或节点、不改变GameSession状态/RNG/revision；保留地图二次点击、卡牌类别/费用、悬停0.7秒/I固定、基础×4/减少动态与终局等待。
