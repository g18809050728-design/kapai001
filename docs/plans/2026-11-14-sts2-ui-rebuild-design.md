| 手牌/牌框 | 底部重叠扇形，悬停抬高；费用独立徽章、上方牌名/中部插画/下方清晰正文，类型和稀有度有层次；专注装置与抽/弃牌堆分居两侧 | 有效面、费用、长文与0.7秒/I固定保持；拖拽/点击/键盘都可用 |
| 地图 | 大幅暖纸路线、深墨节点与虚线、当前/可达有手绘圈记；右侧较窄图例/预告 | 冻结拓扑、三层真实预告、单击预选/双击进入、返回定位 |
| 菜单/选角 | 全屏背景；菜单大标题与竖向文字选择；选角大幅人物占位与底部四选项，左侧角色说明 | 只建四学年，种子/起手/被动与旧局确认保留 |
| 奖励/浏览 | 暗化场景上方横幅与中央大卡，底部独立继续/跳过；详情集中到选中对象 | 候选不重抽、预选不提交、确认一次、真入组 |
| 商店 | 桌面/铺面承载商品，卡牌/物件价签依附商品，离开在右下 | 报价/售罄/目标和替换校验保持 |
| 事件/休息 | 情境画面占大部，侧方正文和长条选择；休息使用图示行动 | 真正代价/收益预告和二步确认保持，不能假造恢复 |

1280×800与960×600使用同一构图；字号可改变文本区和详情滚动，不能退回后台列表。模态详情、强制待选和设置沿同一深色控件体系。现有效果归入场景锚点，不能挡卡文或意图。
