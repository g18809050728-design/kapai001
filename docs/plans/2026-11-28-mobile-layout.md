# 手机 Web 界面适配（UIR-096）

2026-11-28 用户确认以横屏游玩为主。后续版本的竖屏入口改为转向提示，横屏战斗按 UIR-097 优化。[最新方案](2026-11-28-landscape-battle.md)

沿 G7 与根计划 §0.20.6、§0.20.86 实施，复用已接入的场景、角色、纸面地图、费用图标和中文字体。沿二代官方战斗、地图和选角资料中采用的场景主体、意图在敌方上方、手牌在下方、墨印路线与分隔明确的操作区，重排手机屏幕中的信息。配色沿用夜蓝 #172731、栏板 #2c414d、铜金 #c9a86b、纸白 #f4eedf、危险红 #c85d5b。标题沿用项目的中文衬线，数值和控制文字沿用中文无衬线。

- 竖屏使用浏览器安全区内的完整画布。选角和情境版面上下排列，地图预览与确认分区，横屏用较宽的并列布局。手机浏览器可选全屏，切换方向应保持当前对局及已选择的操作。
- 手机战场直接使用可用窗口尺寸，保留角色、意图、进度、状态和六种费用符号。横滑手牌，点牌及高亮目标，长按可看卡牌全文和术语。竖屏的专注、牌堆、回合操作在手牌下方，横屏的回合操作在侧边。
- 触屏滚动沿用 Godot 的取消点击机制。地图预选与进入沿用当前规则，战斗内地图保持只读。教程仍指向真实控件。操作使用原有 GameSession 命令，保留存档、权限、桌面及原整版阶段出口。
- 用手机尺寸与桌面路径验证发布候选，保留实际画面和上一公网版本。
