# 2026-11-13 上一轮可玩表现实现设计

**历史适用范围**：本文记录根计划 §0.19.2 的上一轮原型实现设计，实际覆盖见[实现记录](../UI表现重制实现记录_20261113.md)。用户最新选择为“尽量贴近《杀戮尖塔2》的整体观感，再做校园题材转换”，当前文字目标见[需求 v3](../../动作或者图片描述/整体表现重制需求_20261113.md) §4～§8。本文保留有效面、稳定ID、真实事件、候选／报价、命令与生命周期等业务和交互约束；旧视觉、布局、动作分镜、时间及技术提案须重审，不作为本轮默认续实施指令。本轮仅登记文字需求，详细设计、资源制作和实现留待后续阶段。

当时依据 ui-plan v2（现入口为[文档分工](../../ui-plan/README.md)）与[根计划 §0.19.2](../../实施计划与验收基线.md) 实施。该轮目标是让玩家从路线、牌面和作用反馈理解决策，而非增加独立面板数量。

统一卡面从 GameSession 已解析有效面生成类别费用角标、时点/目标、完整短摘要和去向。按用户“看到剑就知道是伤害牌”的追加反馈，直接用可识别物件替换原费用圆球：攻击为带剑柄、护手与剑刃的剑，防御为盾，功能为齿轮，场地为校园建筑，能力为闪电，负担为破损纸页。不能仅用抽象尖角或不同底色表达类型。角标内的数字只表示专注费用，随物件的内部留白定位并描边；取消其下独立效果徽标，插画恢复完整宽度。须实渲检查32像素、灰度与常规卡面，确认费用不掩盖物件的识别特征。战斗命中与局外候选继续用原 Button 适配器，图形不执行规则。

类别仅为展示字段 `category`，原 `kind/type` 不改。对当前有效面依次检查：负担；建立场景；注册能力；即时 `complete/status_complete/remove_shield/trigger_erosion/trigger_induced/paper_publish`；即时 `relax/heal/partner_heal`；其余功能。检查 pre_effects 与 effects，不将驻留、能力触发或下一张增益当成立即攻击/防御。混合牌即时攻击先于防御；考试替代后的场景/合作牌按已解析效果归类。未替代的工作牌以攻击兜底。原规则类型和目标在图下语义行保留，所有效果量、多段、条件、支付、持续/章节和去向仍由正文及原 I 详情说明。标准手牌尺寸与原位命中保持。

地图保留当前逐年生成器和旧档 next_ids，采用向上推进画布、独立侧预览、13种节点图形、真实后3层机会、当前/可达/走过/错过状态。只经过的相邻完成边标为已走，缩略图只定位，进入永远需要确认；本地选择不提交业务。

房间保留场景底图，在局部阅读区域放行动/结果；商店商品直接读效果与价格，宿舍一进门显示人物与行动，事件保留所有已知代价。确认条固定，所有动作仍由 GameSession 校验。共享窄导航替换重复工具排，保存错误独立通知。

战斗拆分实体画面与 HUD/命中。纸张任务具有独立轮廓与作用点，角色原型复用已核对插画，并叠加可独立行动的笔/页/盾层。来源实体起手、真实目标作用、资源徽标及进度条并行；未知来源只给局部结果。新资源事件在实际变化处记录 before/after/delta/source/reason，不用命令末净差推断先得后耗。维持基础×4、逐张抽牌、强制待选、终局等待和一次消费。

G6 本轮样本为已有背景/人物/卡图及程序绘制图标和实体，人工最终资源签收仍待后续；不声称已有完整角色骨骼动作。验证使用隔离用户目录，保存真实命令、事件trace、规则/RNG/revision对照、旧图/密图和两尺寸三字号截图。先完成两个闭环，再扩大代表卡和页面；自然四年、真人可用性、正式声音与发布出口分别报告。
