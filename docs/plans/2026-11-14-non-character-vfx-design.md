## 选择与G6资源边界

继续使用旧图集需要五项重新生成且尚无选用结果；新增网上特效包仍需题材和许可核对。本批采用原创原生绘制，先解决可观察的事件语义及作用点，能独立于人物资源推进。全部图形由本项目代码绘制，不取用商业游戏纹理；不调用图像API、不增加图片订单。旧12张候选仍selected=false，其五项返工只由本批运行图形承担对应原型用途，不反写旧材料已合格。

G6子项核对：逐项保留用途、对应事件、形状、深浅底以及连续采样。只有代码编译和资源依赖闭包可验证后进入G7子项；人工审美保留待办。整版G6人物、代表组合、全量覆盖和许可门槛不被此批豁免。

## 图形与事件

| 真实事件/变化 | 原生表达 | 可观察条件 |
|---|---|---|
| pressure_applied | 沿来源至目标飞行的批注短线与纸签，局部压痕 | 无火焰；来源未知只在目标显示结果；仅被放松吸收不播精力受损 |
| completion_applied | 方向笔锋与局部落笔，按实际工作量损失区分轻重 | 只有屏障变化时只播抵挡/破防；零结果不伪造命中收益 |
| unit_healed / vitality_changed正变化 | 柔和短弧从外部向目标聚合，随后上升的圆点 | 只读真实before/after，达到上限的零恢复不播成功 |
| focus/synergy/paper资源增加 | 多个分离的笔尖/纸片向目标收束，闭合定位标 | 获得与支付在形状、方向上均不同，逐事件而非净差 |
| 同类资源减少 | 已聚拢的笔片向外散出并划去短线 | 不从角色发出假攻击，不显示收益颜色或向内流 |
| relax增加 / 被压力消耗 | 开口折面弧生长 / 弧上局部碰撞；耗尽时两半分开 | 防护不盖脸/HUD；获得、吸收、破防独立形态 |
| status_gained/changed/removed | 附着批注括号与小纸签；减层时缩退；解除时向外剥离 | 不画斩击；原有持续状态文字继续作为权威，无事件不伪造周期结算 |
| task_advanced / task_transformed | 局部纸页翻换和前后两页错开，横向落定线 | task_advanced明确使用new_task_id，不能把旧/新两目标画成两次阶段切换；与任务完成退场、整战结束分开 |

状态只在附着事件时显示一段带循环节奏的标记，不新增无限Tween或每回合收益，不将一次短循环宣称为完整持续状态材质系统。阶段效果只负责局部翻页，不调整敌怪身体结构。

## G7接入与收尾

`BattleStageEffects`负责事件到图形的映射；`BattleImpactView`负责来源轨迹；独立局部效果控件只持有图形种类、位置、强度和归一化进度。来源坐标用现有只读注册表，目标反馈坐标用目标实体中心，拒绝未知目标回退到玩家。局部图形使用非交互控件，限制亮区、避让血条意图；不改`BattleActorView`。

实渲追加：吸收、资源变化及伙伴召入不再额外调用旧身体`guard`提示，它在紧凑容器中会放大为遮住实体的宽盾。上述事件由本批局部材质表达；真实行动/受损继续沿用既有姿态，人物文件和资源不改。

数字和局部作用在事件消费时开始；来源轨迹作为短笔触连续建立方向，不延迟真实数字或声音。时长复用现有0.32/0.35秒轨迹与0.9～1.1秒反馈预算，再除基础×4及用户倍率；轻重改变形状/幅度，不新增队列阻塞。全部Tween归入`BattlePresentation._tweens`，生命周期元数据沿现有清理入口。减少动态或关闭动画不创建瞬态；正常、倍速与关闭动态必须有同一领域/RNG/revision终态。
