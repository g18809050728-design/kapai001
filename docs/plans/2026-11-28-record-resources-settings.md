# 战绩资源与设置存档（UIR-102）

游戏记录在列表直接展示可查的剩余精力与金币。详情顶部固定显示剩余精力、金币、完成节点、已结算战斗，切换路线、牌组、饰品时保留。正常结算读取实际结算状态，战斗中的重开使用当时战斗精力和上限，金币以本局实际持有为准。早期详情按已有路线计算可确定的计数，旧摘要只显示其中实际保存的值。账号列表从已有详情列提取精简资源字段，原权限与存储分区保持。

设置沿游戏现有深青界面、暖金选中状态和高对比正文，加入画面、声音、存档页签。横屏保留大片阅读区，顶栏固定返回，底栏显示已应用或待应用状态并固定应用。存档并列显示当前档案与上一份本机备份，保留手动保存、恢复、已有账号云存档和隐私入口。手机横屏与桌面共用控件和写入口，保留音量试听、字号、动态与自动保存语义。

## 验证与发布

Godot 战绩 179 项、设置 107 项及账号入口、首页路径、战斗设置、种子与存档四套回归通过。覆盖 568×320、844×390、1280×800 和 100%、125%、150% 字号。隔离 MySQL 复核结算精力、金币、零值、旧摘要和账号权限。Chromium 触控模拟复核设置切换、音量调节、应用及返回。实体手机实测待完成。
