# 手机横屏图鉴、选人与地图（UIR-099）

沿 G7 核对用户截图、已归档的《杀戮尖塔 2》选人画面，以及现有正式骨架、卡面和墨印路线资源。手机选人使用并排的角色与可滚动介绍，上方切换角色，下方选择难度或开局。图鉴把导航与筛选压入两行，网格依据可用高度排卡。详情并排展示牌面或模型与可滚动正文。

手机路线图扩大纸面可视区，保留预选、再点进入、定位和全图。底部直接打开所选节点的正文与后续路线，关闭后回到原位置。手机和桌面在原放弃按钮的同一点击区显示二次确认，并在上方提供取消。仍通过正式放弃命令及现有门控结算。

对照官方选人画面的主角与内容区比例，以及官方地图的纸纹、印章和虚线。校园场景与骨架继续使用游戏现有资源。手机地图的详情放入可按需打开的纸面，适应用户截图中的短横屏。[选人参考](../../output/playwright/mobile-layout/official-reference.jpg) · [官方地图](https://www.megacrit.com/images/map_qol.jpg)

以 568×320 到 932×430 的横屏窗口、100% 到 150% 字号核对完整牌面、介绍和控制区。单独核对地图节点定位、触控拖动、详情返回和手机与桌面的确认位置。保留上一个公网版本供回滚。[实测与发布](../../artifacts/verification/landscape-pages-20261128/README.md)
