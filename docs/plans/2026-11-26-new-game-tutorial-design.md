# 新游戏新手教程设计与验证（UIR-082）

2026-11-26

## 来源与目标

用户要求：在新游戏开始时出现新手教程，提示各种数值的作用，以及如何使用卡牌、结束回合等操作。

本批只增加首局引导层，不改变卡牌、任务、战斗、地图、经济、RNG、命令、存档 schema 或正式入口规则。教程文案最初为固定界面文案；UIR-094 已把 6 页文字接入文本编辑器的「教程」分类，详见[教程文本实体](2026-11-27-tutorial-text-entities.md)。

## 触发与流程

1. 公网档案首次成功开局（`ui.start_run` 成功）后，地图页立即显示 3 页教程：
   - 三个数值：精力、金钱、DDL；
   - 路线：预选 / 再次点击进入、可达与不可达、学年结算；
   - 战斗准备：专注 3、上限 10、每回合抽 5 张、手牌上限 10、点击/拖动/1—9、牌堆位置、结束回合。
2. 完成开局教程后，进入本局第一场战斗时自动继续 3 页战斗教程：
   - 任务意图、屏障、完成量、DDL、精力与放松；
   - 专注装置与费用；
   - 出牌、目标、结束回合与回合结算顺序。
3. 战斗教程只在本局第一场战斗出现一次。开局教程选择“跳过教程”时不会在战斗里再次弹出。
4. 主菜单新增「新手教程」入口，可随时重看；重看只影响显示，不改变是否已看过、不写存档。
5. 教程打开时阻止鼠标和页面快捷键落到下层；`Esc` 跳过，`←` / `→` 切换，`Tab` 只在教程按钮间移动。程序化页面操作（自动测试、截图工具）视为显式跳过，避免阻塞既有工具链。

## 页面与交互

- 首局教程使用 `UiTutorialOverlay`：遮罩 + 金色描边 + 深色说明面板。
- 会指向真实控件：
  - 地图：第一个可达节点；
  - 战斗①：任务意图标签与顶部 DDL；
  - 战斗②：左下专注装置；
  - 战斗③：右下结束回合。
- 面板会避开高亮区域；高亮位于屏幕下半部时优先把面板放到上方，避免挡住手牌和结束回合。窗口尺寸或字号变化时每帧重新取锚点与布局。
- 说明区域可滚动；内容超出时显示「↓ 滚动查看更多」。当前 6 页在 1280×800 的 100% 下大多可一屏读完；150% 字号或用户编辑后的较长页面使用滚动，不隐藏文本。
- 源文案保持「标题 + 正文 + 3—4 个词条」的短结构；用户已在文本编辑器编辑并作为内置默认（UIR-095），默认文本可长于源文案，超出时滚动。
- 主要按钮高度 44 像素，触控模式 52 像素；字号按 100/125/150% 文本设置缩放。焦点始终留在教程内部，关闭后恢复到打开前的控件（若仍存在）。

## 内容边界

- 讲解数值与规则以现有规则书、`data/four_year/definitions/rulesets.json` 和 `UiGlossary` 为准：专注自然 3 / 上限 10，每回合抽 5，手牌上限 10，精力跨节点、压力先扣放松，DDL 归零仍有任务则失败。
- 不新增“教程奖励”“首胜加成”或规则例外。
- 原版每次新开一局都会出现。自 [UIR-093](2026-11-27-mobile-touch-first-play-design.md) 起，只在公网档案首次成功开局时自动提示，并使用现有 `profile.tutorial_flags.first_play_tutorial_started` 记录；本地、继续冒险及后续开局不自动提示，主菜单重看不受影响。

## 实现位置

- `src/ui/tutorial_content.gd`：6 页原始文案、稳定 UID 与运行时文本覆盖解析。
- `src/ui/text_library.gd` / `src/ui/text_entity_library.gd`：「教程」分类的扁平条目与 6 个实体。
- `src/ui/text_editor_page.gd`：文本编辑器的「教程」页签。
- `src/ui/tutorial_overlay.gd`：遮罩、描边、面板、分页、键盘/焦点、滚动与布局。
- `src/ui/game_shell.gd`：新局触发、首战触发、跳过状态、重看入口、外部操作自动收起。
- `src/ui/experience_page.gd`：主菜单「新手教程」按钮；地图可达节点锚点。
- `src/ui/battle_screen.gd` / `src/ui/battle_layout.gd`：任务意图、DDL、专注、结束回合等真实控件命名与锚点。

## 验证

- 定向测试：`tests/run_ui_tutorial_tests.gd`（套件 `tests/suites/test_ui_tutorial.gd`）通过，覆盖新局出现、翻页/上一页、地图与战斗锚点、跳过、重看、外部操作收起、教程后战斗仍可结束回合。
- 文本实体：`tools/run_text_editor_tests.gd` 通过，9061 项；「教程」页签含 6 个实体、60 个字段，编辑后教程立即读取新文字，恢复回到源文案。详见[教程文本实体](2026-11-27-tutorial-text-entities.md)。
- 实渲：`artifacts/verification/tutorial-20261126/visual/` 与 `visual-150/`，含 1280×800、960×600 的开局、地图、战斗三页及关闭教程后的战斗画面，覆盖 100% 与 150% 字号。
- 完整 UI：本批加入教程套件后运行 `tests/run_ui_tests.gd`，退出码 1；失败为既有的商店滚动 1 项和完整套件顺序下的战斗指针 4 项，同次运行无教程相关失败。战斗指针套件单独运行通过。未把完整 UI 结果写成通过，也未据此修改商店布局或战斗指针逻辑。
- 证据与命令见 `artifacts/verification/tutorial-20261126/README.md`；不以单张截图替代行为验收。

## 待办 / 边界

- 用户最终视觉签收。
- 若需要“永久不再自动显示”，应设计档案字段写入、云档合并与旧档迁移，不在本批偷偷写入。
- 固定按钮「跳过教程」「上一步」「下一步」与页眉「新手教程」仍不可编辑；6 页章节、标题、正文、词条与末页主按钮已经进入「教程」分类，见[教程文本实体](2026-11-27-tutorial-text-entities.md)。
- 用户编辑后的较长页面在 150% 字号或 960×600 下需要滚动；滚动条与「↓ 滚动查看更多」保留，不裁掉文本。
