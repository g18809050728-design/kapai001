# 测试房间编辑器 UI 设计（v1.1）

日期：2026-11-12｜状态：设计已实施并实渲验证（1280×800、960×600、150% 字号）；125% 与手柄/触屏未验证。v1.1 增加“自由调用”能力。

关联：[测试房间功能设计](../测试房间功能设计.md) §8、[实现记录](../测试房间实现记录_20261111.md)、`src/ui/test_editor_panel.gd`、`src/ui/test_ui_tokens.gd`。

## 1. 设计目标与约束

编辑器是**高频操作型工具界面**，不是卡牌展示页。目标：在保留游戏“纸墨/校园水彩”品牌的前提下，让玩家像用属性面板一样快速定位对象、修改数值、预览并一次性应用。

约束：

- 复用现有 `UiStyle` 主题与卡牌/人物资源，不新增 AI 图片。
- UI 只经 `GameSession` 读写；草稿、搜索、滚动属于 UI 本地状态。
- 1280×800 右抽屉，960×600 或 125%/150% 自动全屏；鼠标 + 键盘均可操作。
- 不使用 emoji 作为图标；不引入暗色主题（与纸墨品牌冲突）。

设计来源：`ui-ux-pro-max` 的极简/密集工具布局、焦点可见、内联校验、破坏性操作确认、键盘可达性规则；`design-system` 的三层 token 架构。其默认“深色开发者工具 + JetBrains Mono”建议因与纸墨卡牌游戏品牌不符而未采用，仅保留结构与无障碍规则。

## 2. 设计原则

1. **纸墨为底，金色为行动**：面板用米白纸面，墨色承担文字与主按钮，金色只做选中/强调边框，不作正文颜色。
2. **一屏一事**：顶部分页 = 编辑对象类别；中部 = 当前类别列表；底部 = 草稿与应用，滚动区不藏主操作。
3. **草稿先行**：所有修改先进入“待应用”草稿，统一预览、应用或丢弃；不可逆操作（关闭、丢弃、截断）必须确认。
4. **状态可读**：选中、草稿、待选、错误、禁用都有文字 + 边框/底色，不只靠颜色。
5. **密集但不拥挤**：8px 间距体系，行高 36，分页/区块/行三级层次；长列表滚动，主操作固定。

## 3. 设计 Token（三层）

实现：`src/ui/test_ui_tokens.gd`（语义层），组件只引用语义名，不写裸 hex。

### 3.1 语义色

| Token | 值 | 用途 | 对比度（纸面/面板） |
|---|---|---|---|
| `SURFACE` | `#fffbf1` | 编辑器面板 | — |
| `SURFACE_ALT` | `#f8f3e6` | 次级表面 | — |
| `PAGE` | `#f4eedf` | 页面纸底 | — |
| `INK` | `#1f3a44` | 主文字、主按钮底 | 10.4 / 11.6 |
| `INK_SOFT` | `#4e615b` | 次要文字、说明 | 5.7 / 6.4 |
| `ON_INK` | `#fffbf1` | 墨底上的文字 | 10.4（反向） |
| `ACCENT` | `#dda957` | 选中/强调边框（**不作正文**） | 1.8（仅装饰） |
| `ACCENT_TEXT` | `#8a6420` | 需要文字化的金色信息 | 4.6 / 5.2 |
| `DANGER` | `#9c4f49` | 错误、破坏性操作文字 | 5.0 / 5.6 |
| `TINT` / `TINT_DANGER` | `#f3e7c9` / `#f6e0dc` | 选中/警示底 | — |
| `LINE` / `LINE_STRONG` | 墨 16% / 30% | 分隔线、输入边框 | — |
| `SUCCESS` | `#3f6b5c` | 成功状态文字 | ≥5 |

规则：金色永不作正文；红色错误文字用 `DANGER`；选中分页用墨字 + 2px 墨边框 + 金色底，而非金色文字。

### 3.2 字号与间距

| Token | 100% | 用途 |
|---|---|---|
| 10 | 10 | 眉题（TEST ROOM / EDITOR） |
| 11 | 11 | 徽章、元信息 |
| 12 | 12 | 提示、错误、草稿说明 |
| 13 | 13 | 按钮、行内操作 |
| 14 | 14 | 行标签、输入 |
| 16 | 16 | 区块标题 |
| 22 | 22 | 面板标题 |

字号统一乘 `UiStyle.text_scale`（100/125/150%）。间距：4/8/12/16/24；行高 36；主按钮 40；面板宽 520；标签列 128。

### 3.3 组件 token

- 面板：纸面 + 1px 墨 30% 边框 + 14 圆角 + 轻阴影。
- 按钮：`primary` 墨底纸字；`secondary` 纸底墨字 + 1px 边框；`ghost` 透明；`danger` 警示底 + 红边红字；`tab` 透明，`tab_active` 金底 + 2px 墨边。
- 输入：白底 + 1px 墨边 + 8 圆角；聚焦 2px 墨环。
- 徽章：胶囊，纸面/金色底 + 墨/金文字。
- 提示条：金色/红色浅底 + 对应边框。

## 4. 布局

```
┌ 状态条（战斗页）────────────────────────────────────┐
│ 测试身份 · 分支/rev/干预 · 暂停 编辑器 撤销 重做 保存 退出 │
├ 编辑器（1280 右侧 520 / 960 全屏）──────────────────┤
│ TEST ROOM / EDITOR        分支 0  REV 1  草稿 1  关闭 │
│ 测试编辑器                                            │
│ [角色][牌区][资源][敌人][伙伴饰品]                     │
│ [状态][时间随机][规则覆盖][检查点]                     │
│ ── 滚动区 ────────────────────────────────────────── │
│ 战斗资源 ───────────────────────────────────────────  │
│ 精力 72                          -1  +1  [72]  设为   │
│ ...                                                   │
│ ── 固定底栏 ────────────────────────────────────────  │
│ 待应用 1 项                     预览  应用  丢弃草稿   │
│ 基于 rev 1 · 草稿只在本次编辑器内生效                  │
└───────────────────────────────────────────────────────┘
```

- 1280×800：抽屉 520px，右侧；960×600 或字号 >100%：全屏，顶栏高 46×scale，面板起始于顶栏下方。
- 分页 5 列 × 2 行；960 下仍为 5 列，150% 时间距加大。
- 滚动区独立；底栏固定，不随内容滚动；底栏以 1px 分隔线与内容分开。

## 5. 组件与状态

| 组件 | 默认 | 交互/状态 |
|---|---|---|
| 分页按钮 | 纸底墨字 | 悬停浅墨底；选中金底 + 2px 墨边 + 墨字；焦点 2px 墨环 |
| 行 | 标签左、控件右 | 标签列 128；数值行 `-1 / +1 / 输入 / 设为`；控件右对齐 |
| 主按钮（应用） | 墨底纸字 | 悬停加深；无草稿禁用；焦点环 |
| 次按钮（预览） | 纸底墨字 | 无草稿禁用 |
| 幽灵按钮（关闭/丢弃） | 透明墨字 | 悬停浅墨底；有草稿时丢弃需确认 |
| 输入 | 白底墨字 | 聚焦墨环；非法输入内联错误“请输入整数”；越界提示“已限制到 …” |
| 状态徽章 | 纸底/金底胶囊 | 草稿数 >0 时出现“草稿 N” |
| 状态条 | 浅金底 | 成功/提示用墨绿；错误用红底红字 |
| 确认条 | 浅红底 | 关闭有草稿、丢弃草稿、待选截断 |
| 空态 | 次要文字 | “该牌区为空…”“当前没有状态”等，不显示空表格 |

确认规则：关闭编辑器时若有草稿，先显示“丢弃草稿并关闭 / 继续编辑”；丢弃草稿始终二次确认；`truncate` 使用红色按钮并保留说明。

## 6. 交互与键盘

- `F2` 开关编辑器；`Esc` 关闭（有草稿先确认）；`/` 聚焦搜索；`Ctrl+Z` / `Ctrl+Shift+Z` 撤销/重做（输入框聚焦时不拦截）。
- Tab 顺序按视觉顺序：顶栏 → 分页 → 搜索 → 行控件 → 底栏；所有按钮/输入有可见焦点。
- 编辑器打开时战斗输入被禁用；应用成功后保持编辑态，关闭后恢复。
- 搜索即时过滤（本地，最多 24 条），无结果给空态；数值输入点“设为”或回车提交。
- 单次应用最多 100 个操作；失败时保留草稿并显示错误，不发布半套状态。

## 7. 无障碍检查

- 文字对比度：主文字 10.4:1、次要 5.7:1、金色文字 4.6:1、错误 5.0:1，均达 4.5:1。
- 金色只作边框/底色；选中状态同时有墨色边框与文字，不依赖颜色。
- 禁用按钮使用独立的浅底/弱字，且不响应点击。
- 焦点环 2px 墨色，覆盖按钮、分页、输入。
- 150% 字号下切换全屏，文字不裁切；未验证 125%（设计按同一缩放逻辑处理）。
- 触屏 44×44 目标未针对本桌面编辑器验证；当前按钮高 34–40（桌面鼠标/键盘）。

## 10. 自由调用（v1.1）

目标从“可调用现有内容”扩展为“可调用任何内容并任意编排”。

### 10.1 默认自由模式

- 新增 `FREE_SWITCHES`：`allow_zero_vitality`、`allow_empty_tasks`、`infinite_focus`、`no_cost`、`ignore_limits`、`ignore_relic_unique`、`ignore_relic_slots`、`ignore_unit_slots`、`ignore_chapter_slots`、`keep_hand` 默认开启；冻结/手动单步保持关闭。
- 规则页顶部“全部解除限制 / 恢复默认限制”一键切换；“自定义定义”按钮滚动到 JSON 编辑器。
- 容量：牌区 500、卡 1000、任务 100、单位 64、状态 1000、饰品 128、章节 24、定义 500。
- 搜索结果不再截断（174 卡、56 任务、53 遭遇全部可翻）。

### 10.2 任意时间

- 时间页新增回合/DDL 精确输入 + `设为`，保留 `±1`；回合降低时自动把任务 `eligible_round` 夹到新回合。
- 阶段下拉（准备/玩家行动/敌方行动）+ `切换`。
- seed 支持四流或仅战斗流重置。

### 10.3 任意怪物

- 任务行“详情”打开内联面板：阶段下拉切换、完成量/上限/屏障精确输入、下一条意图 JSON 编辑。
- “设为下一条意图”接受任意 JSON 对象；“清空”写入 `{}`。
- 任务可按 ID 加入；遭遇可按名称搜索替换（含自定义遭遇）。
- 自定义任务定义创建后，可搜索/按 ID 调用，阶段下拉从定义读取。

### 10.4 任意卡牌/道具/状态/伙伴/场景

- 每类都有“按定义 ID 加入”输入：卡牌可入手/弃牌/章节，饰品/单位/状态/场景同样按 ID 调用。
- 卡牌页新增章节区：可加入、移回手牌、升级、移除；章节卡计入结构校验且不占普通牌区。
- 搜索结果每行提供“加手/弃牌/章节”；`_clear_results` 同步清理 UID，避免旧结果命中。
- 场景区支持按场景 ID 加入/清除；随机准备场景以空 pending 结果进入，后续按引擎规则推进。

### 10.5 自定义定义

- 规则页 JSON 编辑器：类型（card/task/relic/status/unit/encounter/scene）、ID（必须 `TEST.`，自动写入 `definition.id`）、JSON 对象。
- “创建/覆盖”生成 `upsert_definition` 草稿；“删除定义”生成 `remove_definition`。
- 应用后重建选项缓存，自定义内容可立即搜索/按 ID 调用；撤销/读档通过 `_adopt_state` 同步 catalog overlay。
- 定义格式由作者负责；引擎校验失败会在底栏显示错误，草稿保留。
