# 主菜单账号与记录入口整理

用户要求登录状态放在右上角，退出游戏与退出登录各有用途；存档承载云同步，对局及游戏记录独立展示，管理统计成为独立管理能力。对应根计划 §0.20.51 / UI-ACCOUNT-02。

主菜单右上角显示身份，点击打开精简账号面板。主选项保留游戏入口，并增加「游戏记录」；管理员另有「管理统计」。设置与存档提供云同步、冲突处理及恢复。游戏记录展示当前身份在本机保存的结算摘要，登录玩家可另查账号历史。账号面板移除云档、历史和统计的混合导航。

退出登录先确认；当前冒险须完整保存并关闭，失败保留身份和当前冒险。取消不保存、不切换身份。退出游戏仅在进度与有效磁盘快照不同或有未保存编辑时提示；正常已保存状态直接退出。浏览器结束运行后显示重新进入入口，保留账号会话。资源复用当前主菜单背景、字体与游戏按钮，弹窗沿用现有配色。无新美术或局外 HTML。新增路由及展示只读，保存仍经 GameSession。
