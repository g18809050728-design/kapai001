# 上一轮校园手绘界面视觉打磨方案

**历史适用范围**：本文保留根计划 §0.19.3 对上一轮原型的设计背景。用户最新选择为“尽量贴近《杀戮尖塔2》的整体观感，再做校园题材转换”，当前文字目标见[需求 v3](../../动作或者图片描述/整体表现重制需求_20261113.md) §4～§8。下文校园手绘、深墨导航、暖纸卡面／手册及具体构图为历史方向，须按 v3 重审，不再作为优先风格约束或本轮开工依据。业务和交互约束继续有效；本轮仅登记文字需求，详细设计、资源制作和实现留待后续阶段。

2026-11-13，上一轮记录。用户当时认为实现仍然丑，要求继续编码；当时实施边界见根计划§0.19.3。该轮解决构图与材质主次，沿用当时校园手绘方向和语义费用角标。

当前实渲主要问题：浅色头尾面板覆盖面积过大；全宽灰绿按钮没有行动主次；地图空白与节点显得像流程图；卡牌顶部、图像、正文割裂且文字偏小；角色半身插画与简笔纸怪缺乏共同尺度；960窗口退回带整块文字底板的工具页面。以上判断来自上一轮layouts-e实际画面。

该轮选定方向为深墨色细导航、暖纸制卡面与手册、清晰保留的校园场景。当时基于已有插画判断，全屏深色主题会损失手绘气氛，因而把深色用于导航、确认带和画面阴影，强调色集中给主要行动与预选。这些取舍属于当时方案，本轮不据此排除贴近二代整体观感的候选方向。

1. 统一按钮、面板、字体层级、描边和阴影。主行动用墨绿/黄铜强调，普通行动用浅纸，次要导航缩小；页标题使用已有系统宋体字形，规则正文保持清晰无衬线。UI样式不参与业务。
2. 局外缩减满屏浅底，导航与标题分层，确认条固定且尺寸受控；选角/事件/休息保留人物与真实场景，行动内容集中。商店陈列与奖励牌面露出完整卡框，避免卡外再套厚白框。菜单有明确标题、焦点插画与单列行动。
3. 共用卡面采用窄深色标题带、宽插画、薄纸正文、类别边饰、稀有度小标与清晰数字。剑/盾/齿轮/建筑/闪电直接组成原费用角标。文字按实际字体测量，长内容沿原完整说明入口，不丢额外代价/弃牌/持续语义。所有入口共享渲染，不改原点击区域。
4. 地图放在有封边、页码/层位和简洁分区的行程手册中。节点有层次和可入强调，路径线及地图状态保持当前公开拓扑；侧预览增加对应情境与明确标题，三层真实预告仍完整可读。背景只提供空间，不编造路径/收益。

用户追加：地图节点支持双击直接完成预选并进入。单击/键盘聚焦仍只读，原底部确认入口保留；双击仅对当前公开可达且预览通过的节点有效，复用同一`map:enter`草稿、run/revision门控和GameSession写口。旧渲染回调不提交；不可达节点双击不前进；通过真实指针事件核对两次点击只产生一次进入。
5. 战斗保留实体/HUD独立，人物统一落在舞台基线上；原生产任务插画派生为透明任务对象，取代通用简笔纸怪，缺图有原生纸张退化。意图、任务名、阶段、工作量与状态层级清楚。精力/专注、回合与DDL、结束回合有可扫读的分组。小窗口保持场景与局部阅读区，删除每行文字的厚浅色底板。

派生资源另存`assets/art/presentation-v3/`，保留源文件、算法、哈希与图像检查/实际看图记录。先制作及检查样本，满意后只扩展本轮任务范围，不调用新生图。

验证包括：最新原生导入；完整UI回归（命中、hover/I、终局、待选与小窗口）；376有效面检查；生产双闭环仍可正常提交；1280×800、960×600、1920×1080及大字号关键页面的前后实渲。规则/地图不变由现有回归核对；截图与实际看图不等于真人体验或整版签收。输出保存在独立`visual-cohesion-20261113`证据目录，保留旧失败与旧图。
