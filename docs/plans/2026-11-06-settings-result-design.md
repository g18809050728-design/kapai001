# 设置状态与战斗结算后转场设计

日期：2026-11-06｜需求：FY-UX-025、FY-UX-024-B3｜来源：用户要求保留现状速度，仅改善设置的已选/当前状态，以及怪物死亡后等待卡牌动作完成再跳转。范围依根计划 §0.14.2。

状态：已实现，完整 UI 回归与双尺寸 40 张实渲通过；代码、命令、证据与边界见[实施记录](../设置状态与战斗转场实施记录_20261106.md)。

FY-UX-025：所有设置选项使用一致的“✓ 已选”、浅绿底色和金色边框，不依赖悬停或焦点显示选择。文字与动态面板显示字号、动态模式、动画倍速的当前生效摘要；固定底栏显示已生效或尚未应用，草稿仍经“应用设置”保存。自动保存和声音开关沿用相同标记。音量继续即时试听，滑动时更新待应用提示。减少动态开启时说明动画实际关闭、倍速偏好仍保留；不调整默认值、倍速算法或动作时长。

FY-UX-024-B3：采用保留原战斗页面的方式，任务面板、手牌及牌堆位置均保留，等待当前命令的全部事件与实际 Tween 完成，再刷新到已发布奖励/总结。替代“先跳转再覆盖特效”；不额外加入固定停顿，也不延迟 GameSession 的领域发布。等待期间锁定指针、快捷键与命令提交，避免旧页产生过期操作。关闭动画/减少动态直接进入结果；尺寸变化或关闭演出可收尾一次并进入结果，不重发命令。

验收：1280×800、960×600 核对已选标记和当前值；改选但未应用时当前值不变、待应用提示出现，应用后与重开设置页一致；减少动态准确说明实际关闭。真实最后一击后规则已进入奖励而 UI 保留战斗，扣血与原位弃牌均完成后才跳转一次，等待期间额外提交无副作用；动画关闭/减少动态即时跳转，关闭演出与调整尺寸不挂住。比较完整领域状态、revision 和 RNG；完整 UI 回归及双尺寸截图保留命令、引擎、输入哈希和原始日志。验证结果另记，不替代整版 G0/G6/G8。
