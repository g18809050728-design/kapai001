# UI 体验改善实施设计

日期：2026-11-04｜依据：用户执行 [FY-UX 改善方案](../../动作或者图片描述/UI体验与布局改善方案_参考杀戮尖塔2_20261104.md) 的指令。当前状态：A–D 已实施并通过相关自动回归及渲染；实际命令、结果、截图与覆盖边界见[实施记录](../UI体验改善实施记录_20261104.md)。

采用方案中“对象为主、分层显示信息”的推荐方向，按 A→B→C→D 实施。复用已有 174 张卡图、人物/伙伴/饰品/任务图片和校园场景；沿用米白、水彩、深青文字与金色选中标记，不新增生图请求。资源来源沿用根计划 §0.8～0.10 的映射与核验记录，正式人工审美/许可出口保留。

## 组件与数据流

- `UiPage` 将标题、固定导航、独立滚动主体、确认栏分开。局外卡牌使用公共对象组件，卡名、类型、费用和图片常显；悬停/键盘焦点显示完整说明，可固定阅读；点击仅预选。卡牌本体保持稳定命中区域，抬升发生在视觉子节点。
- `UiExperiencePage extends UiFlowPage` 负责页面选择状态及公开命令草稿。奖励默认三张居中；学年奖励先选类别；升级/移除复用实例选择网格与直接可读的结果比较。商店和事件只在进入对应服务后展示目标牌组。
- 地图组件只画视图中 `next_ids` 的连接，用状态和文字标记节点。节点预选与进入分离；未确定普通/精英遭遇标明随机，不能按地图标题猜测具体敌人。
- `UiContentText` 统一描述已解析卡面中的条件、动态量、能力触发、章节常驻与关联对象。战斗任务状态直接显示；角色专属摘要来自 GameSession 的只读语义字段，详情目标明确。
- `GameShell` 保留业务结果反馈，持久化状态单独显示。页面提交绑定渲染时的 run_id/revision，同一版本只能提交一次；旧视图刷新后须重新预选。动画只呈现结果。

## 只读接口约定

`RunService.make_view` 补充 campaign 奖励/服务/方向/去向的结果预览，包括实际回复、金钱、服务费用、饰品折算及已知终局影响。预览复制状态再走现有服务验证，不消费 RNG，不发布状态，不引入新规则。地图公开预告、终局原因与战斗专属信息均由服务/会话层返回，UI 不推算未公开结果。

设置增加可选 `presentation`（`text_scale` 为 100/125/150，`reduced_motion` 布尔，`animation_speed` 为 0/1/2/4），旧设置缺失时使用默认值；不改变玩家局存档 schema。大字号使用紧凑卡牌和独立详情滚动，确认栏保留在可视范围。战斗宽度 <1100、高度 <700 或字号 >100% 时使用原生两栏目标/手牌布局；标准布局保留扇形与拖拽，紧凑布局支持点击和数字键。卡牌按实际换行后的最小高度适配；鼠标跨入详情保留 180ms 离开缓冲。

## 验证与边界

每批保留可审阅的代码和测试。覆盖 AC-01～15 的相关行为：真实 UI 预选/确认、浏览前后领域/RNG/revision 相同、实例和候选冻结、重复及过期提交、强制待选、保存失败只重试保存、动画终态一致。渲染核对 1280×800 / 960×600、三种字号、长文和缺图。使用隔离 APPDATA；保留命令、版本、输入 SHA256、原始输出、退出码与截图。

自动化和 AI 看图不替代 G8 自然四年完整游玩、真人体验、G6 人工最终资源/许可或打包性能验收；未覆盖项在执行记录中明确列出。

## 追加：战斗遮挡与叠牌入口（FY-UX-006）

来源：用户提供 `image.png`，指出操作提示遮住手牌卡名，并要求牌组、记录、抽牌堆和弃牌堆改为卡牌形式、悬停介绍用途。消耗堆沿同一方式展示。此项沿根计划 §0.12 的 UI 实施授权，不新增玩法、资源生产或状态字段。

标准 1280×800 战斗把操作提示放到手牌下方的独立底栏，保留完整 168×244 牌面与悬停放大。收紧扇形角度和横向跨度，为底栏、专注和右侧操作留出空间；任务剩余量、任务状态与玩家状态分别避开牌名。紧凑布局继续使用固定操作栏及独立滚动。

使用公共 `BattlePileButton` 绘制米白叠牌、公开数量、名称和聚焦边框；保留 `battle:deck/log/draw/discard/exhaust` UID、点击动作及 D/L 快捷键。所有入口通过同一战斗摘要面板介绍用途，悬停/聚焦不提交命令，点击才打开原有只读详情。抽牌堆只解释作用并显示公开数量，不泄露顺序或未公开内容。强制待选和详情覆盖层保持原有输入锁。

验收：用实际鼠标输入检查五入口的悬停、点击、关闭及完整状态/RNG/revision 不变；检查标准五张与十张手牌的实际旋转四角、悬停放大后的范围不与提示/结束回合相交；覆盖 1280×800、960×600、100/125/150% 字号和强制待选。当前追加已实施，完整 UI 回归及 46 张实渲通过；最终命令、输入/日志 hash、视觉观察与适用边界见[实施记录](../UI体验改善实施记录_20261104.md)。
