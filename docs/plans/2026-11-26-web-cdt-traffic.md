# Web 下载与 CDT 节流计划

11 月 21 日至 26 日 15:38 的 Nginx 公网响应正文累计约 7.92 GB，资源包约占 96%。当前游戏首次完整下载约 250 MB，账号、记录和云存档接口累计约 1.1 MB。云计费用量以阿里云 CDT 控制台为准。

| 顺序 | 改动 | 验收 |
|---|---|---|
| 1 | 按 8 MiB 分块并预压缩，用原始内容 SHA-256 作为资源 URL。引擎和音频脚本单独按内容版本缓存 | 解压重组与原包 SHA-256 一致。在 Nginx 核对 gzip、MIME、缓存头和缺失响应 |
| 2 | 浏览器通过 Cache Storage 复用资源块。成功加载后回收旧块，缓存不可用时继续从网络启动 | 记录首次、刷新、浏览器重开和模拟更新传输量。核对同源游客续档和账号入口 |
| 3 | 接入 Web 导出流程。本次部署沿用现有发行包，保留旧发布目录和已发布的哈希资源 | 环回浏览器验证通过后切换原 HTTPS 入口，核对正式入口和回滚路径 |
| 后续 | 按依赖清点 Web 包，测图片适配尺寸、字体子集和字体回退。按访问量比较 CDN 费用 | 验证角色、敌怪、图鉴、旧档和管理员工具并测首次下载量 |

上线后从 Nginx 日志按 `/game-assets/`、旧 `/index.pck` 和账号接口汇总每日响应量，再与同一时段的 CDT 公网流出和费用核对。浏览器清除数据、回收存储或更换设备都会产生新下载。更新后可复用字节相同的块，资源排布变化可能使较多块重新下载。

## 2026-11-26 实施与验证

18:09 已切换正式 HTTPS 入口到 `20261126-cdt-cache`。发布使用当时线上游戏包，资源解压后整包 SHA-256 一致。后续构建通过 `tools/export_web.sh` 生成内容哈希资源，发布步骤见 [screen 部署指南](../screen部署指南.md#62-发布已经验证的-web-构建)。

| 测量 | 结果 |
|---|---|
| 游戏包首次下载 | 238,345,152 字节降至 230,360,093 字节，减少 3.35% |
| 首次加载总量 | 游戏包和引擎合计约 240.50 MB，另有少量启动页面和脚本 |
| Chromium 关闭后重开 | 29 个游戏资源块从浏览器缓存读取，Nginx 发送游戏包 0 字节，全部响应 10,538,161 字节 |
| 模拟更新和缓存失败 | 加载器测试通过单块更新、旧块回收、关闭存储、配额不足、HTTP 404 和响应被截短 |
| 正式入口 | 环回 HTTPS 核对 29 块响应、资源缓存头、解压兼容、HTML 重新校验及账号会话接口 |

浏览器进入了登录菜单，显示正常，持久化数据库名仍为 `/userfs`。本轮没有对真实游客档执行续玩回归。测试服务器内存不足时浏览器测试进程被终止，最终浏览器复开在可使用现有交换空间的临时 cgroup 中通过。验证见[记录](../../artifacts/verification/web-cdt-20261126/README.md)。

磁盘满导致 Nginx 访问日志在改动前停止写入。清除 DNF 下载缓存并核对五组历史内测包与发布包字节一致后，使用硬链接共享包数据，回收约 1.19 GB 已分配空间。线上访问日志已恢复。旧版路径和 Nginx 配置记录在 `/etc/kapai001/web-cdt-20261126-backup/`，可按部署指南切回旧版。

## 第二批 Web 资源压缩

继续处理 §0.20.71。以当前线上版本作为对照，在导出后压缩包内的大型图片，保留尺寸和精确透明度。图片重编码须通过像素差异阈值并检查代表性画面。字体使用无损重压缩并逐字节比对。其余 PCK 资源继续按原路径与原内容导出。上线前核对 Godot 资源可读、浏览器中文和首局、实际传输量，并保留前一发布目录。

2026-11-26 已上线 `20261126-cdt-slim`，使用前一版的游戏内容重新打包。782 张 Web 贴图保持原尺寸与透明度，重编码的颜色有少量变化。两套中文字体改用较大的 Zstandard 压缩块，解压数据逐字节一致。2497 个资源路径全量保持，另 1713 个资源字节一致。

| 实测项目 | 结果 |
|---|---|
| 游戏包传输量 | 230.36 MB 降到 87.41 MB，减少 62.05% |
| Chromium 首次打开 | Nginx 响应合计 97.95 MB，含 10.14 MB 引擎 |
| 游客刷新并续玩 | 续玩回到原地图，存档哈希相同，游戏包发送 0 字节 |
| 正式 HTTPS | 12 个资源块、gzip 回退、整包 SHA-256 与账号接口核对通过 |

后续 `tools/export_web.sh` 同样执行压缩。回滚指向见 `/etc/kapai001/web-cdt-slim-previous-release`。图片对照、Godot 资源核查及浏览器原始结果见[验证记录](../../artifacts/verification/web-slim-20261126/README.md)。
