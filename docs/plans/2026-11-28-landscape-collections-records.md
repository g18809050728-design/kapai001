# 横屏牌组、随身查阅与游戏记录（UIR-100）

- 地图牌组沿现有卡面画廊，手机把标题、搜索、排序与关闭放入同一条顶栏，余下区域留给完整首排及滚动。保留卡牌类型费用图标、详情与键盘入口。
- 随身查阅把四个页签与关闭放入同一条顶栏。饰品栏显示全部三个常用槽位，右侧独立滚动效果。规则用可滚动主题条目，战斗记录把筛选合并在一行，冒险信息在宽横屏并列显示当前资源、保存及路线信息。
- 游戏记录共用一个游戏内入口。记录列表按最近对局排序，详情分页签显示路线、结算牌组及饰品。保留角色肖像、游戏原有字体、深青底、暖金强调和所选条目焦点。网页版账号按服务端会话读取与分页，游客按当前标签页的本次游客登录保存，刷新延续该会话，退出即清除。原有继续进度独立于战绩。旧记录展示已有摘要。
- 在正式对局结算时从实际运行状态截取卡牌定义与升级等级、饰品定义与槽位、已走过的节点及当前节点。服务端以对局归属限定读取，原子写入结果和详情，重复结算幂等。继续旧存档后正常结算会记入详情。测试房间和试验入口不产生正式记录。保持现有存档格式与账号权限。
- 验收包含横屏三档字号、真实触控返回和滚动、桌面列表与详情、身份隔离、旧记录兼容、版本化发布。
