# 地图质感与情境导航设计

对应根计划§0.20.11、UIR-019/063。用户已明确要求实现，人物工作继续暂停。本批输入在`artifacts/verification/map-material-feedback-20261114/before.json`冻结，旧证据不回写。

已实际查看官方`map_qol.jpg`及`map-rest-sequence.jpg`：主体为有不齐边缘的纸质地图，路径由节奏稳定的短虚线连接墨印轮廓，信息图例作为独立纸片位于侧方。2024开发画面与2026商店宣传剪辑只证明可见结构，不声称获得当前构建的完整交互规范。联网工具本次未返回可用正文，沿用有来源/hash的归档。当前实渲的差距是平色渐变、细线图标、流程图式重线和深色整块侧栏。

比较三种方案：仅叠噪点仍保留原平面感；为整张图绘制静态插画不能适配真实随机路线；采用原创纸张纹理与原生墨印控件，可保持真实路线、动态状态与稳定输入。本批选择第三种，纹理离线固定生成，与游戏RNG无关。

`MapPaper`共享原生材质组件负责纤维纹理、不齐边缘、阴影和折痕；`UiRouteCanvas`保留真实节点位置和路径计算，绘制有节奏的虚线、清晰的已走线和预选后继。`MapNodeGlyph`改为更有重量的实心墨印，`MapNodeStamp`保留原生Button、76像素宽及稳定标注，选中红圈、当前/可入/已过与焦点不只靠颜色。纸面节点不进行位移/缩放动画。

导航地图背景压暗；预览从深色矩形改为有厚度的纸片，标题和状态固定，长路线预测继续独立滚动。二代参考仅用于布局/材质观察，运行资产全部原创，不提取商业素材；已有房间缩略图复用。

顶栏新增情境选项：`show_map=false`只在地图页使用，不创建隐藏的重复按钮。M在地图页复用原有`map:overview`，菜单中的M先收起菜单再切换概览；其他页面/战斗仍按原UID打开只读浮层。GameSession写入口、run/revision、稳定UID、卡牌六类费用角标、0.7秒全文/I固定、演出及存档边界均不改。

验证覆盖两尺寸三字号的地图/菜单/概览、密集后期路线及房间只读浮层；保留原完整UI和真实鼠标输入验证。逐张检查纸面层次、节点识别、路径对比、文字/按钮边界，自动化只能验证行为。任何失败及返工独立留证；不宣称人物/整版G0/G6/G8或用户审美验收完成。
