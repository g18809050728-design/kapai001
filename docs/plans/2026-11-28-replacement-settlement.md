# 牌组滑动与重开结算（UIR-101）

牌组和战绩滚动区独立追踪手指位移，移动达到阈值或容器开始滚动后取消当次卡牌或战绩的点击。范围包括短划、碰到滚动边缘、划回起点和随后正常点按。

沿已确认的重开动作，在替换旧局前准备旧局的真实摘要和详情。替换档写入成功才发布旧局的「重开结束」与新局开始；失败时旧局仍可继续。持久化待发条目绑定新局 ID，刷新后按当前身份恢复并重试。首页返回、正常继续、旧终局、校验失败及试验房间沿用原有处理。已失去原始旧档的历史记录保留可核实状态，不推算路线、牌组和结局。

检查无存档、仍在地图或战斗、只在磁盘、写入失败、同一条目重试、账号与游客隔离、旧包识别、服务端读取重试和触控实渲。正式站沿已有版本发布并保留回滚。
