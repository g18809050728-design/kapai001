# 管理员 XLSX 与数据库维护 · 2026-11-27

沿 G7 和既有管理员角色，在反馈管理、统计概览和对局明细加入导出当前筛选结果（不只当前页）。工作簿使用北京时间，数字保留数值类型，玩家文本按文本写入，不导出截图本体或账号凭据。超过 5000 行提示缩小范围。

数据库维护提供普通玩家显示昵称的真实数据库修改：按昵称、登录名或账号编号查询，确认新旧值及填写原因；每次修改记录审计和旧值，可撤回上次修改，拒绝覆盖已变化的数据。不开放自由 SQL，也不编辑角色、权限、密码、会话、邮箱或存档。反馈处理和统计修正沿用现有工具。

只加表，不改旧数据；通过隔离 MySQL、工作簿内容检查和 Chromium 下载/维护流程验证，再版本化发布。同一事务保存昵称、旧值与审计记录。

## 验收与上线

- 隔离 MySQL 全套集成测试通过：真实昵称修改、旧值/版本冲突、撤回、审计、权限撤销、三类 XLSX、跨页导出、超限拒绝以及用户文本保持为普通单元格。
- Chromium 实际下载三种 XLSX，核对工作簿文件名、工作表和筛选内容；测试受控资料修改、确认、历史、撤回及普通玩家账号读取新/旧昵称。
- 正式站已发布 `20261127-admin-data`。上线前留存正式库压缩备份，备份目录仅 root 可读。迁移前后核对 7 个账号昵称、7 条反馈、12 条对局，原数据未变化；未在生产对任何账号试写昵称。正式站匿名访问管理员导出和维护均被拒绝；Chromium 正式入口加载引擎与全部 12 个资源块。
- XLSX 运行依赖 `XlsxWriter==3.2.9` 安装在此版后端发布目录内，未更新共享虚拟环境。
- 实渲、测试下载样本和公网验证：`artifacts/verification/admin-data-20261127/`。
