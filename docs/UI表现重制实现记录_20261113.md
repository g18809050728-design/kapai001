## 当前实现与观察

卡框直接将原费用圆球换为攻击剑、防御盾、功能齿轮、场地校园建筑、能力闪电和负担破损纸页。剑具备剑刃、护手和剑柄，费用数字按图案留白定位并描边，下面不再另叠效果徽标。战斗、奖励、商店、牌组与比较等入口共用CardDisplayModel/CardFaceView；原按钮适配器保留UID、命中与预选。已查看[同源卡面](../artifacts/verification/ui-remake-20261113/layouts-e/card-categories-1280.png)、[40/32/24像素样图](../artifacts/verification/ui-remake-20261113/layouts-e/category-icons.png)和[灰度图](../artifacts/verification/ui-remake-20261113/layouts-e/category-icons-grayscale.png)。费用不是伤害或放松量；正文和I详情继续表达实际结果。

类型由当前有效面结构决定，不从牌名或颜色猜测。174定义、376基础/升级/考试面全部检查；基础面分类为攻击45、防御53、功能57、场地2、能力17。混合牌按确定性顺序分类，原工作/策略/合作等规则类型保留。考试替代后同步更新类别；额外精力支付、强制弃牌、章节/能力触发和多段效果仍按有效面说明。长正文按字体高度限制摘要，完整内容沿原0.7秒悬停/I固定入口查看。

路线按已保存的`nodes/next_ids`向上显示，区分当前、可达、经过与未来，采用避开标签的曲线和13类节点图案；右侧展示真实三层机会，全图只用于定位。新局逐年密图与旧档拓扑均保留，未生成学年不提前构造。房间共用窄导航和固定确认条：商店分层陈列商品，事件/休息将情境与行动分开，选角按机制、起手等标签浏览。可查看[小窗口地图](../artifacts/verification/ui-remake-20261113/layouts-e/map-960.png)、[奖励](../artifacts/verification/ui-remake-20261113/layouts-e/reward-1280.png)与[战斗](../artifacts/verification/ui-remake-20261113/layouts-e/battle-1280.png)。

战斗实体与HUD/命中区分离，复用现有插画生成4主角、3伙伴透明原型，并绘制纸张任务实体、笔/纸行动层及目标作用点。动作和命中反馈消费真实事件，未知来源仅显示目标结果。放松、专注、协同、论文的逐次变化包含before/after/delta及真实来源，先得后耗不会被净差吞掉；零变化不显示收益。来源表覆盖卡、角色、任务、单位与能力。音频按实际事件映射并沿用节流。基础×4、用户倍速、逐张飞牌、强制待选与终局等待真实Tween继续有效。

这些角色是可动原型：已有透明人物、独立笔/纸/盾和局部位移动作，不等于最终完整分层角色动画。场景仍复用旧插画；没有调用付费生图。资源来源和哈希见[人物原型清单](../assets/art/presentation-v2/manifest.json)。

## 失败修复与证据边界

此前类别角标仅使用抽象尖角/星形，未满足用户“图案直接表达类型”的反馈，最新`layouts-e`已替换为实物语义图案，旧`layouts-a～d`不作为本次图案结果。旧图、失败日志和用户删除的样图状态均保留，不静默覆盖。

UI检查曾遇到64×64无头视口导致地图几何断言不成立，以及点击辅助器假设所有卡都属于页面滚动容器。已让几何测试显式使用1280×800、点击辅助器寻找真实滚动祖先并点击可见交集；V1全套通过。规则检查曾报告Boss阶段文字缺失，现恢复准确阶段数与下一阶段说明，V2通过。对照工具早期缺输入/来源断言的问题已修正，最终V3单独通过。

生产闭环首轮工具错误地监听`battle_won`并重复选择已解决的事件，导致`ALREADY_RESOLVED`。实际生产事件为`battle_finished/result=won`；工具已改为先离开已解决节点、商店完成真实购买后再离开。只改检查工具，不改领域行为；首轮报告`session-loops.json`和最终`session-loops-b.json`均保留。

目前不宣称WP-03/06/07全部正式资源完成，也不宣称32项整体验收全过。待完成：正式分层人物和敌怪动作、174插画人工评级及资源许可、全状态图形与稀有度/新版卡背、全部生产组合的视觉闭包、1920专项、真人辨认与操作比较、连续录像、参考机性能/内存、自然四年完整可见路径及Windows导出/干净环境。整版G0/G6/G8剩余出口沿根计划执行。
