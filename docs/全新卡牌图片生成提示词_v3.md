# 全新卡牌图片生成提示词 v3

日期：2026-11-04｜174 张卡图采用 **22 张八格图集**生产。172 张永久牌 + 2 张论文衍生；升级面共用插画。实际生成/选用数见下方生产状态与资源记录。

本方案以“有真实校园动作的纸感插画”统一四个角色。卡牌插画只表达主题，不把数值、费用、稀有度或效果文字画进图片；这些信息继续由游戏 UI 清晰排版。

## 使用方法

使用[八格生产方案](八格卡图生产与接入_20261104.md)及[22 条图集任务](art/card-atlas-jobs-v3.jsonl)，每条任务一次只生成一张图，内含8个不同素材，不用 n=8 生成八张收费图片。统一版使用CLI edit上传同一参考图；JSONL记录operation/reference_image，不直接交给generate-batch以免丢失图像输入。完整可复制图集提示词位于 `docs/art/atlas-prompts-v3/`。逐牌完整提示词仍保存在[JSON](art/card-art-prompts-v3.json)，仅供局部返工与索引；首次不逐牌出多候选。

统一版本使用现有游戏K01/K02/K04/K05卡图与P01/P04肖像组成参考图，实际上传到同一模型的edit端点，以图像约束线条、米白留白、水彩铺色和人物外观；不得复制参考图的3×2排列。P02/P03缺少已选立绘，使用手部/背影构图，不声称人物身份已锁定。[画风约定](art/card-art-style-v3.md)记录具体标准。首轮纯文字候选偏暗/背景过密，已经停止，未接入。

## 统一画风

严格匹配当前游戏的明亮二维校园水彩插画：纤细清楚的深青墨线勾勒，简化平面水彩铺色，轻微米白纸纹，大面积暖米白负空间；鼠尾草绿、深青与少量暖黄/砖红。成年大学生自然比例，单一动作或物件，背景仅少量轮廓，平静漫射日光，柔和且稀少的阴影。禁止摄影、写实渲染、电影暗调、密集材质、高反差体积光或复杂实验室。克制的抽象思考点缀，整体保持原有手绘清爽感。每格横向4:3独立插画，只画插画，不画卡框、文字或界面。

图集1024×1536，2列×4行；每格512×384，四周内裁16/12像素后为480×360。主体居中60%，四边至少10%安全区；UI卡框自行处理。缩至120×90仍可辨认主体。输出RGB PNG，无字、无框、无水印。单图负面词的‘拼贴分屏’只约束格内，不禁止图集的八格结构。

负面提示词：文字，字母，数字，公式，水印，校徽，品牌标志，卡框，卡名，说明栏，UI，二维码，密集小字，乱码，拼贴分屏，过多主体，主体被裁切，模糊，低清，夸张广角，畸形手，多指，复制肢体，塑料3D质感，血腥，武器，真实毒品。

## 角色视觉锚点

- 公共校园池：公共校园系列：暖米白、橄榄绿与柔金；以校园空间、日用品和自然动作表现，不绑定角色。
- 林序：林序系列：深青与铜橙；方格纸、流程卡片、调试灯和有序连线作为母题。成年男大学生，蓬松黑短发、细圆框眼镜、深青外套与米白内搭。优先手部和桌面近景。
- 许知微：许知微系列：墨蓝与淡紫；书页、书签、引用丝线和三层书页结构作为母题。优先成年学生手部、肩后或背影构图，不新增固定面部身份。
- 沈见章：沈见章系列：墨绿与紫红；墨迹、放大镜、证据线和渐扩涟漪表现侵蚀与诱发。优先成年学生手部、肩后或背影构图，不新增固定面部身份，不画生化武器。
- 唐以宁：唐以宁系列：赤陶橙与湖蓝；双手协作、交接夹板、轮转弧线与汇合光带作为母题。成年女大学生，黑色高丸子头、米白开衫、鼠尾草绿内搭、红棕挂绳。优先手部与协作物件近景，伙伴避免面部特写。
