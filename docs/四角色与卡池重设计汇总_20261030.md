# 四角色与卡池重设计及文档更新汇总

日期：2026-10-30｜设计版本：v3.1｜范围：仅文档、设计JSON及Excel。当前程序、运行数据和测试仍为v1。

## 1. 本次结果

保留林序、许知微、沈见章、唐以宁四人，重做角色内核、被动和每人40种专属卡。四人分别围绕出牌顺序、论文结构、任务负面状态、伙伴驻场时间进行决策，避免前三人只是换名积累额外资源。

永久卡共172种：四人各40、公共12；另有许知微的2种论文衍生。每组10种，组前均有通俗的设计思路、典型联动及特色取舍；完整基础/升级文本、14种考试面和六章常驻均已写入[卡表v3](校园卡牌设计表_v3.md)及[Excel](../artifacts/redesign-20261030/校园角色与专属卡池_v3.xlsx)。机制维护源为[角色设计v3](角色与专属卡池重设计_v3.md)。本次毒师与公共功能增补详见[专项修订](沈见章毒师与全角色通用功能修订_20261030.md)。

四人共11条主流派、16个功能分组，流派在同一人物内自由混搭。许知微只有两条真正改变收益方式的路线，另外两组明确为衔接和支持，不用牌名差异凑第三路线。

## 2. 四人内核、被动与路线

### 林序：安排顺序，复用方法

被动“步骤复用”：每回合首次合法相邻策略→工作结算后，可取回前一永久策略；取回仍支付原费用，不刷新限次。没有合法前策略不占机会，满足条件后放弃或满手仍消耗机会。取消旧编译资源，出牌顺序本身就是人物特色。

| 分组（各10） | 选牌与操作 | 代表联动和取舍 |
|---|---|---|
| 交替连携 | 选择低费工作和足够策略，交替打出多次连携 | 快速定位→小步实践取回策略，检查输入→分步运行继续衔接；收益依赖相邻顺序 |
| 策略复用 | 选择值得反复使用的防护/抽牌策略 | 断点休息→复用验证取回，再用同实例承接结果核验/方法沉淀；输出密度可能较低 |
| 集中执行 | 多张准备配少量重费工作 | 列执行步骤、预留时间→集中运行；群体用整体验收。准备上限12、减费上限1，坏起手会卡准备 |
| 通用衔接 | 补过牌、防护、保留和多目标工具 | 交接备注留关键牌，联调通过连接复用和集中；不是第四路线 |

三路线共享顺序内核，区别在多次小输出、反复功能牌、少量大输出。校园动作采用调试、验证和方法沉淀，避免靠额外计量条塑造身份。

### 许知微：发表成果，或维持研究

被动“论文记录”：开题后，不同牌名首次打出进度+1，重复名引用+1；同名每回合最多打一次。进度上限10、引用上限5，第3/4/5引用额外付1/2/3专注，付不起不加层改抽1。取消旧数据资源，论文归属许知微。

| 分组（各10） | 收益方式与操作 | 代表联动和取舍 |
|---|---|---|
| 发表构筑 | 不同牌名、引用、修正经营完成度，再一次发表 | 检索目录铺名、交叉引证/定稿检查补足；DDL紧可提前交可用版，等待满分可能受压 |
| 章节引擎 | 最多三章按槽序，从下回合自动提供抽牌、防护和直接完成量 | 引言章过牌、方法章防护、结果章/结论章输出；选牌偏检索/部署/生存，收益持续 |
| 路线衔接 | 跨回合同名、增幅、换题和撤章转修正 | 章节回看隔轮取引用、阶段总结撤章转发表；没有独立胜利闭环 |
| 通用支持 | 生存、抽牌、有限透支及再开题 | 赶工/通宵直接失精力且耗尽；发表后收拢材料取回开题 |

两主路线的取舍是“集中准备一次兑现”与“部署后持续运转”。发表清本篇并把全部章节退回弃牌，不能同时保留完整持续引擎；这使选牌、操作和节奏产生实际差异。

### 沈见章：组合负面，改变触发方式

被动“复合反应”：每回合首次由卡牌正文给已有另一种负面的目标新增一种负面，正文后该新状态额外+1层。加厚旧状态不触发，群体牌只强化一个目标；强化不递归。起手为破题追问、削弱论势，可直接体验侵蚀与混合减压。

| 分组（各10） | 选牌与收益方式 | 代表联动和取舍 |
|---|---|---|
| 侵蚀增殖 | 施毒、加厚、增殖与频率提升，收益在后续任务阶段 | 圈出疑点→疑点滋生→提前验算；追踪记录自动铺毒，加速剖析增加结算次数，短DDL会压缩收益 |
| 诱发连打 | 先挂反应毒，再用低费和过牌在本回合多次触发 | 设下追问→短句反问/翻页核证→二次追问；检索连锁将抽牌转为侵蚀，循证爆发奖励施毒批次，每目标诱发最多4次 |
| 混合抑制 | 虚弱/乏力减压、脆化削防、易伤助工作，读取种类数直接进攻 | 削弱论势→拆解防线/公开前提→论点交锋；维持不同负面比堆厚单毒重要，输出不消耗状态 |
| 通用衔接 | 抽牌、防护、纠错、回收和保留 | 整理思绪找启动，留待答辩留配方，配方笔记承接被动；不是第四路线 |

侵蚀20、诱发3、脆化3、乏力4、虚弱3、易伤3；六种各有作用。侵蚀自然结算后减1，诱发行动结束清；三种计时负面各自压力窗口后减1，乏力在任务实例内保持。易伤/虚弱全角色可用；专属优势来自混合效率和触发配套。六负面是校园原创扩展，参考边界见专项修订。

### 唐以宁：分工、轮换与独立作答

被动“分工默契”：每回合首合作正文后得1协同、2放松，协同上限6，考试面仍保留合作类型。伙伴每次支援→协作→自身失1精力，归零暂离；卡文额外行动每实例每回合最多一次，同样消耗续航。

| 分组（各10） | 选牌与操作 | 代表联动和取舍 |
|---|---|---|
| 分工推进 | 建多伙伴场面，以工作和有限指挥兑现数量 | 室友搭把手→分工清单→各做一题，全组研讨加速；爆发会缩短驻场 |
| 接力轮换 | 恢复重要伙伴、管理短驻场与交接 | 临时补位、轮换排班、轮值支援维持续航；主动撤回不退牌、不靠牺牲收益 |
| 备考内化 | 少依赖人数，保留协同门槛或消费终结 | 分工内化/独立演练启动，分工已内化维持输出，独立交卷一次兑现；考试表现个人作答 |
| 通用衔接 | 补启动、筛选、防护和群体交付 | 约定进度、保留意见、重排任务、共同里程碑；积累协同本身不完成任务 |

保留伙伴题材，强化正常/额外行动与短驻场上限的边界。考试使用完整逐牌替代面，不表现为现场找同学代答。

## 3. 论文参考保留与新增

参考规则保留：不同名字首次进度、重复引用和分档专注支付；完成度C=clamp(7×进度+6×引用+修正,0,100)；发表主目标C+10、其他floor(C/2)，100时全体再+20；增幅只加白名单正向数值；换题成功重置一个名字且修正-1。

| 新增/细化 | 设计影响 |
|---|---|
| 三个有序章节槽，下回合起自动运行并允许直接完成量 | 明确替代参考“中间牌不直接产生完成量”，使章节成为独立持续路线 |
| 手动章节只基础+记账，自动不算出牌；额外激活每实例每回合一次 | 避免自动输出叠加牌名收益或递归运行 |
| 发表关闭论文、退全部章节；之后可合法重新开题 | 发表付出持续引擎代价，同战可再研究但需重新抽到/取回开题 |
| 唯一发表不升级/复制/耗尽，不进永久；临时借名固定 | 不靠无限新名字或复制发表绕开规则 |
| 增幅上限5，强化正文首个白名单数值后全部消耗 | 不强化完成量/发表/修正/自动/被动，章节综述供后续用牌 |
| 赶工/通宵加入耗尽，直接失精力仍可失败 | 限制重复透支，不改变原本风险语义 |

论文引用只属于许知微，和沈见章旧资源已分离。引用转修正会失去原引用6点贡献；换题不退已得进度/引用，也不刷新本回合同名限次。完整来源差异见[论文修订说明](论文路线卡牌修订与实现草案.md)。
