# 《交大四年：DDL战争》统一设计文档

版本：v3.1｜日期：2026-10-30｜状态：当前文档设计，待新版G0冻结；程序仍为v1。

## 1. 设定与目标

四位学生面对相同的校园作业与期末，用不同的方法解决问题。对手是任务与截止时间，同学是伙伴；完成任务、吸收压力与选择交付窗口构成策略。第一学期完成是本期终点，不表现为完整四年毕业。

本文件已直接替换旧卡池、旧被动、旧伙伴/场景/饰品目录及八学期投放表。改前原文保存在本轮字节备份及Git历史，当前目录不再并列两套生效规则。现有程序与历史证据仍对应v1。

## 3. 人物与卡池

| 人物 | 被动与核心 | 主流派 | 专属永久起手 |
|---|---|---|---|
| P01林序 | 步骤复用：首个相邻策略→工作可取回前策略 | 交替连携、策略复用、集中执行 | R3-P01-01/02 |
| P02许知微 | 论文记录：新牌名进度、重复名引用；选择发表或持续章节 | 发表构筑、章节引擎 | R3-P02-01/11 |
| P03沈见章 | 复合反应：给已有另一种负面的任务建立新负面后，该新状态额外+1，每回合一次 | 侵蚀增殖、诱发连打、混合抑制 | R3-P03-01/21 |
| P04唐以宁 | 分工默契：首合作得1协同2放松 | 分工推进、接力轮换、备考内化 | R3-P04-01/02 |

四人各40种专属、公共12种，共172种永久；另2种P02论文衍生，不含遭遇负担。每人四组各10，P02后两组为桥接与支持，全体11主流派。普通20/进阶15/稀有5。同人物可混搭、没有跨人物永久授牌。

起手为公共写作业×4、伸个懒腰×4、整理书包/喝水调整各1，加两专属，共12。P02开题固有占首次抽5的一格，开题才生成唯一发表。正常精力72、生活费60、专注3、基础抽5、手牌10。论文精确公式与同名约束按角色设计，不由概览推算。

## 4. 校园伙伴、场景与章节

| 定义 | 精力/协作或时长 | 特性 |
|---|---|---|
| R3-U01复习搭档 | 3/2 | 无支援、无护卫 |
| R3-U02资料同学 | 4/1 | 每次协作前主角获得2放松 |
| R3-U03项目搭档 | 5/3 | 护卫，承接默认单体压力 |
| R3-S01自习室 | 后续两次准备 | 每次3放松，升级5 |
| R3-S02专题自习 | 后续两次准备 | 每次抽1，升级再放松3 |

最多3伙伴，正常合作阶段每实例一次，特定卡可额外一次；每次支援→协作→失1自身精力，归零暂离，胜利不扣续航。短驻场按实例上限恢复，换班不退卡。最多1场景，第二次后移除，替换重计2次。14个完整考试面先转换再校验。

P02论文区独立最多3章，不占伙伴/场景槽。从下回合起按槽序自动运行，有抽牌、防护和直接完成量，手动重用只基础与记账；发表则全部退回弃牌堆。固定考场不禁论文区。

首期无新版饰品投放。校园物件只作故事意象，未来机制另立设计，不恢复旧装备目录。

## 5. 第一学期任务原型

以下保留既有遭遇的基础原型，供新版G0评估，不代表已与本版160种重设计专属牌平衡；尤其论文满分发表130/70远高于旧阶段工作量，必须重平衡。A→B→C循环；缺项只循环已有项。压力默认主角，任务屏障在敌方准备清除。

| ID | 名称 | 未完成量/DDL | 意图循环与限制 |
|---|---|---|---|
| N01 | 课后习题 | 24/8 | 压力5→压力7 |
| N02 | 英语小作文 | 28/8 | 屏障5→压力8 |
| N03 | C语言练习 | 30/8 | 压力6→加入X01至弃牌堆并压力4 |
| N04 | 实验预习 | 32/8 | 主角焦虑1→压力9；首期候选，不继承旧学期过滤 |
| Q01 | 随堂小测 | 38/6 | 独立作答；压力7→屏障6→压力10 |
| B01 | 高数期末 | 20/25/25，总DDL10 | 极限→积分→证明；独立作答+固定考场；每阶段压力7→屏障5→压力9 |

X01分心消息：遭遇注入的临时负担，不可打出，回合末正常弃置，无被动扣费，不进172种永久牌或随机奖励统计。其他未来负担不因旧目录存在而进入首期。

阶段切换先建立下一任务实例；不刷新回合、专注、牌堆、资源、单位、场景或DDL，超额完成量不结转。不得把击破第一阶段当作整场胜利。

## 6. 六层地图与教学

| 层 | 节点 | 教学与人物体验 |
|---|---|---|
| 1 | 普通作业 | 解释精力/专注/放松/DDL，直接展示连携、开题、侵蚀与混合减压或伙伴入口 |
| 2 | 事件或普通作业 | 学习筛选奖励与人物成长，不发跨人物专属牌 |
| 3 | 商店 | 3专属+1公共库存，展示完整效果与价格 |
| 4 | 普通或精英 | 提前公开独立作答，可选择不打精英的路线 |
| 5 | 休息 | 恢复、升级与合作双面预览；数值和具体选项待G0 |
| 6 | 期末 | 三阶段共享DDL，合作/场景转为内化知识，结束后总结 |

共8个候选节点对象，每条路线经过6节点，分支最多2项。地图背景不会自动建立规则场景。角色核心机制、能力与合作不能推迟到后续学期才解锁，否则首期无法体现角色差异。

## 7. 获取、事件与总结

所有永久卡来源统一使用“当前人物+公共”资格过滤。普通战/精英奖励、商店价格、稀有度权重与空池回退以角色设计§8为准；基础R3-C-01/02、论文衍生与临时副本不进入奖励。每人实际可见奖励池为40专属+6非基础公共=50种。

旧事件显式授卡、送饰品与跨专业奖励已退出当前正文。新版采用交流方法、调整学习计划与四人故事候选，故事主题见角色设计§8，事件以互斥选项形式设计；事件名单、生活费、恢复及服务费用须在新版G0冻结，当前不沿用旧V事件收益。

期末为第一学期终点，直接显示完成/失败/放弃与本局统计，不再发没有后续用途的构筑奖励。第二学期、履历及毕业去向留作后续候选。

本版卡/单位/场景用R3命名空间，人物P01～P04沿用叙事ID，内容版本必须独立；不覆盖R2或K定义，不自动改读旧局。旧Excel和机器登记保留历史。未来R3-T01～23见角色设计§9，包含论文双路线、自然/额外结算、考试、奖励和存档，全部未执行；文档一致性不代表新版G0、可玩性或G8通过。

## 9. 后续任务候选（未入首期）

原《小怪设计草稿》合并于此；临时N13～N21编号、旧12普通任务冻结数、旧术语和未实现操作草图删除。原文见[字节备份](../artifacts/redesign-20261030/before-v3.zip)。下列仅保留创意，不能据此投放或实现。

| 候选 | 可保留的教学点 | 需要先裁决的问题 |
|---|---|---|
| 课后作业/数学基础 | 基础压力、困倦和多任务结课联动 | 与N01重叠；完成后作用需有存活目标 |
| 程序 | 出错后的补考缓冲 | 完成/终局优先序，不能让已胜利任务复活 |
| 预习 | 惊喜与惊吓的可读切换 | 受工作/轮末切换是否冲突，规则需独立设计 |
| 文献阅读 | 完成后返还专注 | 终局后不发无用收益，短DDL的价值 |
| 英语作文 | 有限一次防护 | 与现有屏障的关系，侵蚀/诱发与新获屏障如何交互 |
| 项目 | 蓄力与群体压力 | 预告清楚，伙伴与护卫的边界 |
| 六级词汇 | 多任务联动和有限复制 | 数量上限、目标顺序、压力与状态归属 |
| 考前复习 | 持续任务对长期生存的压力 | 是否真的需要削上限；避免额外永久惩罚 |

所有候选均先单独立规则、ID与范围，再按G0～G8推进，不加入本轮172种卡或六遭遇原型。
