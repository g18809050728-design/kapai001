# 地图图标与路线整体构图修正

日期：2026-11-14。用户纠正的是图标与线条组合出的整体美感，上一批纸张材质不能视为解决。范围为UIR-019/063、[根计划§0.20.12](../实施计划与验收基线.md)，方案见[本批设计](plans/2026-11-14-map-composition-feedback-design.md)。

本轮重画13类校园墨线符号，统一绘制空间、笔画、光学大小和内部留白；普通作业、服务、补给和高风险节点保留可辨的校园语义。节点沿冻结列序作稳定的层间错落，地图展开宽度与各层漂移共同组织留白。路径从旧的侧廊折返改为一条连续柔和曲线，在文字下裁出短空隙，避免绕字产生流程图式折线。收敛虚线/实线粗细和预测朱线分量，移除不可达叉号与远期短弧，保留当前、已过、可入、预选与焦点的区分。详细地图、概览和只读浮层复用相同符号与投影。

可直接打开[前后实渲对照](../artifacts/verification/map-composition-feedback-20261114/review/index.html)，或看[1280默认字号对照](../artifacts/verification/map-composition-feedback-20261114/review/comparison-1280-100.png)与[960大字号对照](../artifacts/verification/map-composition-feedback-20261114/review/comparison-960-150.png)。官方归档分别是2024年开发截图和2026年宣传连续帧，未声称最新构建；未从商业资源提取图标。

实际查看全部60张最终PNG的10张总览，并单独查看默认地图、小窗口150%字、后期密图和全图。相较上一批，节点笔画与图形分量一致，路径减少了机械拐点；小窗口大字号仍能区分当前与预选，节点身份和固定确认保留，路线正文独立滚动。全图缩放后的图标细节弱于详细图，需点击检查或返回详细图；中文字标签及13类校园语义也与二代图例结构有差异。**没有把AI观察、机器通过或纸张效果写成用户审美签收。**

本轮不改领域、生产内容、地图生成算法、RNG、旧档和卡牌类型费用图案，原始纸纹和顶栏实现也保持原字节。人物继续暂停，§0.21冻结文档及ZIP保持原字节；核对结果见[一致性记录](../artifacts/verification/map-composition-feedback-20261114/consistency.json)。原整版G0/G6全量资源/人工/许可与G8出口仍未关闭。
