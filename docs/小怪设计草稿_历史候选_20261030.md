## 术语约定

- **我方**：严格指玩家方——主角、合作单位、牌组、专注、放松、精力、生活费。
- **敌方**：严格指玩家的对立面——任务/小怪，及其屏障、未完成量、压力。
- 所有效果一律**从玩家视角**书写，不使用「敌人视角」的相对称呼。

## 术语转换

| 草稿原词 | 本项目术语 | 说明 |
|---|---|---|
| 攻击 / 造成伤害（对我方） | 施加**压力** | 规则书要求「承受压力X」 |
| 攻击（敌方意图） | 施加**压力** | 敌方没有「攻击力」字段，压力写在意图里 |
| 能量 | **专注** | 出牌资源统一称专注 |
| 生命值（我方） | **精力** | 玩家资源统一称精力 |
| 生命值（敌方自身） | **未完成量** | 任务的「血量」 |
| 降低我方攻击力 | 施加**困倦** | 困倦：下次玩家行动工作第一段每层 -1，上限 2 |
| 增加我方攻击力 | 我方**工作输出+N**（本战持续） | 我方没有「攻击力」字段，需新增可叠加的持续增益 |
| 降低敌方防御力 | 降低**屏障** | 任务的防御是屏障 |
| 受到致命伤害 | **被完成** | 任务不会死亡；未完成量归零是完成，多阶段任务进入下一阶段 |
| 回复生命值（敌方自身） | **恢复未完成量** | 完整设计已有先例：N08「恢复未完成6」 |
| 群攻 | **群体压力** | 对我方主角和全部合作单位 |
| 死后 | **被完成时** | 同上 |
| 分裂 / 复制 | 生成新任务实例 | 需引擎支持战斗中生成任务 |
| 必须被优先攻击 | **强制目标**（嘲讽） | 仅单体攻击牌必须选它；群体、回复等无视；多个时由我方选一 |
| 蓄力 / 倒计时 | **延迟触发** | 到达指定回合仍未满足条件时结算 |
| 自身死亡 | **自身被完成** | 任务不会死亡；未完成量归零即离开，不视为击杀 |

## 待确认

1. **结课效果需要多阶段或双任务才有意义**：N14/N15/N23 若为单阶段任务，完成即结束战斗，触发效果会被 [END-001] 跳过。建议改为两阶段，或放进双任务遭遇。
2. **编号扩充**：N13～N38 会突破冻结的 12 个普通任务，需先更新 G0 范围与内容清单。
3. **与现有任务重叠**：课后作业≈N01、英语作文≈N02、预习≈N04、文献阅读≈N08。需决定是**替换**现有定义还是**并存**。
4. **需要新机制的条目**：N14/N20 降低敌方屏障、N16 反应式切换、N18 免疫一次、N19 群体压力、N20 相邻/复制、N21 削减精力上限、N22 强制目标/嘲讽、N23 分裂、N24 递增压力、N25 限时削减专注上限、N26 抽牌削减与「签到表」废牌、N27 动态缩放压力、N28 在场加费、N30 屏障联动、N31 永久增攻/降上限/死亡恢复、N32 动态压力、N33 屏障不清零、N34 出牌后随机弃牌、N35 死亡时群体压力、N36 施加拖延、N37 延迟触发/自身移除、N38 按牌型触发强化。这些在 MVP 引擎中均未接线，实现前需先补规则与契约。
5. **N27 与「独立作答」的冲突**：独立作答下我方没有合作单位，按原设计压力会翻倍；需确认这是刻意设计还是需要例外。
6. **N33 与现有规则冲突**：任务屏障在敌方准备时清零（[ENM-001]），「屏障不清零」需要显式例外，不能靠实现悄悄绕过。
7. **N31 需要两个新状态**：「永久增加我方攻击力」而我方没有攻击力字段，需定义为工作输出增益；「降低血量上限、死后恢复」需要一个可逆的上限削减机制，不能复用困倦。
8. **N38 小组互评偏针对构筑**：合作牌越多越强，会惩罚单位流；与 [EXM-002] 独立作答叠加时可能需要单独裁决。
