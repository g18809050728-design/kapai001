# 首领机制与 N26 讲座考勤修复实现记录（2026-11-20）

范围：为四学年首领（FY_B1–B4）与毕业路线首领（FY_ROUTE_job/exam/research/abroad）加入可玩机制；修复 N26「讲座考勤」声称塞「签到表」却塞入「最后检查」的问题。
数据包：`campus_four_year`（生产默认），同步 `campus_v3` 的卡池与 N26 引用。规则、存档结构、随机数、难度曲线均未改动。

## 1. N26 讲座考勤修复

问题：卡面意图写「手牌加入 1 张签到表」，但运行时 `N26` 的 `add_card.card` 指向 `R3-C-07`（最后检查，一张正常的工作牌），且 `X03 签到表` 根本没有进入四学年卡池，所以玩家永远拿不到签到表。

修复：
- 把 `X03 签到表`（`unplayable` 临时牌）加入 `data/four_year/definitions/cards.json` 与 `data/v3/definitions/cards.json`。
- 在 `campus_four_year` 与 `campus_v3` 清单 `enabled.card` 中启用 `X03`。
- `N26` 的 `add_card.card` 改为 `X03`。
- 回归：`test_boss_mechanics` 断言 `N26` 引用 `X03`，并实跑一回合确认签到表进入手牌。

## 2. 首领机制（用户选定的四项）

### 2.1 召唤第一组嘲讽小怪（带击杀奖励）

- 每位首领在**第一阶段第一个意图**召唤 1 只小怪，`summon_tasks: [{task, count:1, taunt:true, work_percent:60}]`。
- 召唤实例带嘲讽：只要它在场且可选，所有「目标=任务」的牌都只能指向它——必须先清掉小怪才能继续做首领。
- 召唤的完成量按 60% 缩放，避免小怪变成整阶段级的体力墙。
- 选用第一组（priority）中带结课奖励的小怪，保证「强制击杀」不是纯惩罚：
  - `N14 数学基础`：结课对其它任务（即首领）−4 完成量、−4 屏障。
  - `N17 文献阅读`：结课我方 +2 专注。
  - `N29 校园网发力`：结课我方 +3 专注（在场期间我方每回合少抽 1）。

### 2.2 负面状态最多两个

每位首领通过 `gain_status` 只施加两种负面状态（含其召唤小怪自带的），实现见 §4 校验。例：
- FY_B1 / FY_B4：焦虑 + 困倦
- FY_B2 / job / research：焦虑 + 拖延
- FY_B3：困倦 + 拖延
- exam：困倦 + 焦虑；abroad：拖延 + 困倦

### 2.3 按玩家状态缩放

第一个压力意图带 `pressure_per_vitality: 1, pressure_vitality_step: 30`：我方精力每高出 30 点，该段压力 +1（约满血 +2，低血自然回落）。缩放基于玩家当前精力，属于自适应难度，低血时更宽容。

### 2.4 塞废牌 + 削精力上限

第三个意图同时：`pressure`（原值）、`player_reduce_max_vitality: 1`（精力上限 −1，当前精力随之夹紧）、`add_card: {card:"X04 修改意见", count:1, zone:"discard"}`（废牌入弃牌堆稀释牌组）。
- 新增废牌 `X04 修改意见`（`unplayable` 临时牌），标签 `special/temporary`。
- 该意图在一个阶段内每循环触发一次，约每场减 2–3 点精力上限、塞 2–3 张废牌，控制在「有压力但不致命」。

## 6. 限制与待办

- 以上为按用户选项实现的第一版数值，未经真实试玩平衡验证；「不要太难」的最终手感需人工确认。
- 召唤小怪固定 1 只、60% 完成量；若后续觉得过轻/过重，只需改 `summon_tasks[].work_percent` 与任务选择，无需改引擎。
- 图鉴不显示废牌（设计如此）；如需在图鉴查看废牌，需补插画并放开 `get_candidates` 的 `special/temporary` 过滤。
