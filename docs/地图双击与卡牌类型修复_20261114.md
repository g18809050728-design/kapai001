# 地图双击与卡牌类型标识修复

日期：2026-11-14；授权及阶段例外：[根计划§0.20.7](../实施计划与验收基线.md)。对应UIR-019/031/050/058。人物工作仍暂停，二代整体UI目标持续执行；本批复用已有图案，无新资产生产。

## 设计与验收

地图保持纸面路线、墨色节点和右侧预览。单击仅原地更新预选：同一节点Button、点击位置、滚动与焦点保持，路线预告、图案圈记和底部确认同步变化，不重建整页。双击原位置的未预选可达节点直接沿同一确认草案提交，保留规则预览和过期/重复门控。节点图案与下方文字都能激活；右键、未来节点、过期回调均不进入。主动拖动、滚动不能冒充双击。

卡牌恢复共享绘制器已有的类别费用图形：攻击剑（含剑柄/护手）、防御盾、功能齿轮、场地校园建筑、能力闪电、负担破损纸页。保留当前卡框、标题/插画/类别/正文层级，角标承载有效面真实费用，适配标题留白；不另加重复效果徽标。战斗、奖励、商店、牌组和弹层共用，类别不改规则kind。

验证先复现原位置连续点击，再覆盖跨帧点击、未预选目标、两尺寸/大字号、标签命中、未来节点、过期事件、重复提交与原确认/键盘；只读预选对照领域/RNG/revision。卡图核对全部有效面语义，双尺寸实渲查看全部类别、小牌/放大和灰度，保留原始日志、输入hash与观察记录。

## 根因与实现

旧地图节点的`pressed`调用通用`_choose`，继而`refresh_local → render → reset_page`，删除全部节点后重建。第一次释放后，第二次按下可能仍被发送给已移除的控件；即使跨帧重新命中，重建/延迟滚动也会打断连续操作。原测试在每次点击前重新寻找节点并`ensure_control_visible`，且先完成一次预选再发送带`double_click`的事件，没有覆盖同坐标紧接的两次点击。

`UiExperiencePage._select_map_node`现直接在原按钮上更新预选、原确认入口草案、右侧预览和地图路线，不调用整页重绘。`UiRouteCanvas.select_node`只更新只读路线投影并重画，保留拓扑、按钮和几何。底部选中说明固定一行，完整内容保留tooltip，避免长节点名/大字号改变页脚高度。图例由错误的“金环/青线”改为实际“红圈/粗线”，可达节点提示单击预选/双击进入。双击仍走原`map:enter`和GameSession门控；不在树内的旧页面、过期generation和非可达目标拒绝进入。

`CardFaceView.paint`恢复调用已有`paint_category_badge/paint_category_cost`，直接替换本批误改的费用圆徽章。剑柄/护手等原几何及随图形调整的费用中心保持；标题在角标右方，类别文字保留，战斗/奖励/商店/牌组自动共享。未修改`CardDisplayModel`、规则kind、有效面或费用算法。
