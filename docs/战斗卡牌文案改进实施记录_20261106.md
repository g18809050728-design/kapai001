# 战斗卡牌文案改进实施记录

当前卡牌介绍交互以本文末尾 FY-UX-026-B 为准：同卡停留展开，移出收起，I 切换单份固定，介绍位于卡牌左/右侧。前文为原文案批次记录，其旧自动长介绍交互已被本次用户澄清覆盖。

日期：2026-11-06｜需求：FY-UX-026｜状态：实现、全量卡面检查、最终导入、规则/UI 回归及双尺寸实渲已通过。

用户确认采用“卡面短句 + 通俗详情”。本轮按[根计划 §0.15](../实施计划与验收基线.md)、[界面契约 §0.6](界面层契约.md)、[需求台账](../动作或者图片描述/需求台账.md)与[设计](plans/2026-11-06-battle-card-copy-design.md)实施，覆盖当前四年模式全部 174 张卡牌。卡面保留短摘要；战斗中的悬停、聚焦、`I` 固定详情及牌组/公开牌堆详情使用白话说明。

## 实现与可观察结果

| 范围 | 实现与核对 |
|---|---|
| 效果说明 | [UiContentText](../src/ui/ui_content_text.gd) 新增 `describe_battle_card`，先显示有效费用、目标与使用前提，再按原效果顺序编号。递归解释随后、成功消耗后及最后的收益，说明条件不成立会跳过、同段加值、多段不转移目标及动态计算依据。 |
| 时机与次数 | 解释持续能力从何时生效、章节自动运行、每回合/具体副本限次、消耗/保留；附上当前卡文出现的完成量、连携、侵蚀、诱发、协同、论文等词义。消耗协同/引用不会附带卡牌耗尽释义。 |
| 说明准确性 | 首张工作加值作用于正在结算的牌；加速剖析的摘要与详情均说明轮末侵蚀自然结算次数及逐次减层。P01 被动取回条件如实注明满手也计入机会，未改变已有规则偏差。 |
| 当前卡面 | [BattleScreen](../src/ui/battle_screen.gd) 使用只读手牌的当前 `face` 与有效专注/精力费用，补充该面实际引用的伙伴/场景资料；不再用牌组基础面覆盖实际效果，也不拼接成普通效果与考试效果同时执行。 |
| 阅读交互 | [BattleLayout](../src/ui/battle_layout.gd) 的悬停正文取消四行截断，改为滚动阅读；移入说明区保留卡文。标准战斗按 `I` 切换固定详情，紧凑战斗聚焦后按 `I` 固定、`Esc` 关闭；固定卡牌预览期间隐藏背景悬停。 |
| 共用预览 | [UiPage](../src/ui/ui_page.gd) 提供文案扩展点，由战斗页选择新说明；局外页面保留原有详情入口。卡面仍使用短摘要，加速剖析仅修正原先与实际规则不符的旧提示。 |

例如，条件加值不再只写内部条件短语，而是说明“上一张成功打出的牌是策略牌，当前牌是工作牌”，以及“额外完成量 +5，与基础值合并为同一段完成量”。放松说明为“获得5点放松，用来抵挡压力”，并解释触发条件、执行顺序与使用次数。显示中的整数去掉无意义的小数点，只转换显示副本。

## FY-UX-026-B：停留展开、单份固定与卡侧定位
