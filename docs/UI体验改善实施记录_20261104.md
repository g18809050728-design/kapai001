## 已知边界

1280×800、标准字号保留扇形手牌和既有拖拽。宽度不足 1100、高度不足 700 或字号大于 100% 时使用原生紧凑战斗：目标与手牌分区滚动，点击/数字键选牌，操作固定；紧凑布局未接入标准扇形手牌的拖拽手势。其余页面以独立主体/网格/详情滚动保障文字和操作可达，没有整体缩小界面。

现有引擎中 `modify_erosion_window` 不应用数值修正，详情如实提示；P01 自动取回且尚无主动放弃选择等既有规则偏差仍见[卡牌契约](卡牌实现契约_v3.md)，本次没有借文案改规则。检索章节、限时负面上限、协同不足时跳过等说明按实际引擎行为呈现。

人工完整鼠标/键盘路径、四角色多种子自然四年游玩、全部生产组合的阅读体验、手柄/触屏及完整无障碍仍需后续验证。正式音乐/环境音/混音、最终美术与许可、参考机性能、Windows 导出和干净环境验收继续保留在 G6–G8；当前自动化、受控截图与模型视觉复核不能替代这些出口。
