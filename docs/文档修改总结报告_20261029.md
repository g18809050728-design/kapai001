# 角色与卡牌体系文档修改总结

日期：2026-10-29｜范围：文档与研究 Excel｜核验范围：文档、Excel、备份、保护文件与隔离旧基线；最终结果见本报告§5。

按用户确认，保留林序、许知微、沈见章、唐以宁，改为人物专属卡池加小型公共池。原有文档已直接同步为v2，旧正文归档；新版是可评审提案，未改程序；现有 v1 仍可按旧生产包运行。入口已集中到[README](../README.md)，阶段与版本权限见[根计划 §0](../实施计划与验收基线.md)。

## 1. 设计结果与新旧差异

| 主题 | 原有设计/当前程序 | 本轮 v2 提案 |
|---|---|---|
| 人物与卡池 | 四人叙事，当前生产仅 P01/P04；获取规则未按四人专属池重构 | 保留四人，每人40种专属，三条流派各10种加通用衔接10种，另有公共 8 张 |
| 起手 | 共用基础 10 张加角色 2 张 | 每人永久 12 张；P03 每战首次准备额外生成唯一临时草稿，不计永久牌数 |
| 人物差异 | 被动、起手和初始饰品承担部分差异 | 编译、数据、引用/稿件、协同驱动各自闭环；首期退出 v1 饰品投放 |
| 考试 | 旧统一合作/场景替代值 | 七张合作牌、两张单位目标策略和公共场景分别写完整基础/升级考试面 |
| 获取 | 旧奖励/事件显式池与旧稀有度 | 奖励、商店、事件、变化统一过滤当前人物+公共资格，不跨角色授牌 |
| 版本 | v1 K/F/L/A ID、旧存档和既有 G0–G7 证据 | 新 R2 命名空间；旧 K01–K60 概念映射仅供设计，不能自动转换存档 |

| 人物 | 三条流派 | 校园表达 |
|---|---|---|
| 林序 | 编译爆发、短循环、定式引擎 | 拆解、验证、解释与交付 |
| 许知微 | 采样筛选、对照验证、重复测量 | 接受误差，保留记录，验证结论 |
| 沈见章 | 引用证据、修订迭代、按时交付 | 引证与有限修订，选择提交窗口 |
| 唐以宁 | 分工推进、接力轮换、备考内化 | 合理分工，考试转化为个人作答 |

共 **168 种永久牌 + 1 张唯一临时牌**，12 条校园流派。保留任务完成量、精力、专注、放松、DDL 和第一学期结构；不照搬杀敌、星、充能球或灾厄斩杀。升级列为完整文本，资源上限、触发顺序、0 费限次、能力不叠加、草稿不可复制/耗尽等约束已写明。完整内容见[主设计](角色与专属卡池重设计_v2.md)、[逐张卡表](校园卡牌设计表_v2.md)和[校园 Excel](../artifacts/redesign-20261029/校园角色与专属卡池_v2.xlsx)。

根据用户追加的40种要求，本轮在每人原18种基础上各增加22种，共新增88种；原81条设计（含公共牌和草稿）的卡面字段保持。每人按三流派各10种与通用衔接10种组织，稀有度为普通20、进阶15、稀有5；通用衔接仍为该人物专属，不另算第四流派。公共牌、升级面、临时草稿均不充入40种。每人的奖励资格为40种专属加6种非基础公共，共46种；永久起手仍为12张。

新增牌补充低费启动、防护、筛选、有限回收、资源支付、多任务推进和流派衔接。重复测量按实例封顶计次，有限回收不刷新限次与费用；临时保留和短驻场伙伴的保存责任已同步至规则、战斗及存储契约。考试替代面现共10个：7种合作牌、2种单位目标策略和1种公共场景，均提供完整基础与升级面。

起手均有角色机制入口；沈见章的列提纲可消耗引用增加稿件，搭配读文献即可触发被动并准备提交，不必等待奖励牌才能消费引用。此为设计层闭环复核，数值表现仍待实际游玩验证。

逐张卡表已在四个人物标题之后、各自完整卡表之前，补齐三条流派与通用衔接共16组导读。按用户追加要求，设计思路改为通俗的游戏设计表述：先用“蓄力爆发、低费连招、引擎构筑、弃牌联动、战斗内成长、召唤构筑”等术语说明核心玩法，再解释操作与收益；表头补充过牌、输出、防御等术语的简明解释。每组保留具体出牌例子、校园特色及构筑取舍，并说明能力下回合生效、首次触发、实例计次和考试替代等条件。导读来源为 `card-group-guides.json`，生成器支持 `--markdown-only`；此次介绍修订未改牌数、卡面、两份Excel或游戏程序。
