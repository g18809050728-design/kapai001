## 术语约定

- **我方**：严格指玩家方——主角、合作单位、牌组、专注、放松、精力、生活费。
- **敌方**：严格指玩家的对立面——任务/小怪，及其屏障、未完成量、压力。
- 所有效果一律**从玩家视角**书写，不使用「敌人视角」的相对称呼。

## 术语转换

| 草稿原词 | 本项目术语 | 说明 |
|---|---|---|
| 攻击 / 造成伤害（对我方） | 施加**压力** | 规则书要求「承受压力X」 |
| 攻击（敌方意图） | 施加**压力** | 敌方没有「攻击力」字段，压力写在意图里 |
| 能量 | **专注** | 出牌资源统一称专注 |
| 生命值（我方） | **精力** | 玩家资源统一称精力 |
| 生命值（敌方自身） | **未完成量** | 任务的「血量」 |
| 降低我方攻击力 | 施加**困倦** | 困倦：下次玩家行动工作第一段每层 -1，上限 2 |
| 降低敌方防御力 | 降低**屏障** | 任务的防御是屏障 |
| 受到致命伤害 | **被完成** | 任务不会死亡；未完成量归零是完成，多阶段任务进入下一阶段 |
| 回复生命值（敌方自身） | **恢复未完成量** | 完整设计已有先例：N08「恢复未完成6」 |
| 群攻 | **群体压力** | 对我方主角和全部合作单位 |
| 死后 | **被完成时** | 同上 |
