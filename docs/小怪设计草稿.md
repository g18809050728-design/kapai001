## 术语转换

| 草稿原词 | 本项目术语 | 说明 |
|---|---|---|
| 造成伤害 / 攻击 | 施加**压力** | 规则书要求「承受压力X」，不使用「攻击/伤害」 |
| 能量 | **专注** | 出牌资源统一称专注 |
| 降低攻击力 | 施加**困倦** | 困倦：下次玩家行动工作第一段每层 -1，上限 2 |
| 降低防御力 | **清除放松** | 敌人没有「防御」属性；降低防御用清除主角放松表达 |
| 受到致命伤害 | **阶段/任务被完成** | 任务不会死亡；未完成量归零是完成，多阶段任务进入下一阶段 |
| 回复生命值 | **恢复未完成量** | 完整设计已有先例：N08「恢复未完成6」 |
| 死后为我方回复能量 | 完成时主角获得专注 | 与 N17 同一机制 |
| 群攻 | **全体压力** | 包括主角和全部合作单位 |
