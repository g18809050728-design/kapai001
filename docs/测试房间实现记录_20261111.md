## 4. 未实现与已知偏差

- **开关未接入**：`no_cost`、`infinite_focus`、`ignore_limits`、`keep_hand`、`freeze_enemy`、`manual_rule_steps` 仅保存值；`set_player_lock` 为占位。
- **章节牌区**：`chapter` 区域编辑未实现（返回 `TEST_UNSUPPORTED`）；部分 `v3` 字段通过 `set_definition_field` 而非专门操作。
- **待选策略**：`rollback` 已用真实待选战斗验证；`truncate`、`cancel` 与旧 choice/branch 请求失效仍未测。
- **重放/记录**：可保存与载入记录，但无重放执行、首差异定位与导入文件选择器；设计中的 `TEST_REPLAY_MISMATCH` 尚未产生真实证据。
- **编辑器 UI**：已按[编辑器 UI 设计](plans/2026-11-12-test-editor-ui-design.md)落地 token、分页、草稿底栏、关闭/丢弃确认、空态与 150% 全屏；仍缺“实例/整类”范围徽标、筛选芯片、卡片搜索结果的分页与按稀有度/费用过滤，以及 125% 实渲。
- **待选 UI**：`rollback` 已用真实待选验证；`truncate`/`cancel` 的按钮路径与视觉未测。
- **导出计数与导入**：未统计“测试到正式持久化调用为 0”的自动计数，仅以文件不存在与正式视图未变为证据。
- **性能/打包**：未测。
