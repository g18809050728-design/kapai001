| FY-UX-016 卡牌拉长 | `offer_card.gd` 的上移动画同步设置上下偏移，避免聚焦时保留重建期间的临时高度；统一边框宽度。原诊断复现了按钮高 286、卡面高 968，修正后跨帧均为 286。真实指针反复切换奖励/商店候选及 100/125/150% 字号检查通过。未固定说明放在候选网格外侧，进入说明的窄间隙保留当前卡文；固定详情隔离焦点，关闭后恢复。 |
| FY-UX-017 地图 | `experience_page.gd` 中当前节点深青底优先于完成状态；等待布局、滚动恢复后，以下一可达层中心定位。只有实际居中后才记入作用域；本地预选保留手动滚动。受控中段及真实生产商店→定期饰品→地图返回，两尺寸中心误差 ≤2px。 |
| FY-ART-003 餐食 | 单张校园餐食生成并接入 `campus_meal`，见下方来源；实际生产商店货架与预选截图显示完整餐盘，选择不改库存/领域/RNG/revision。 |
| FY-AUD-003 音效 | 18 条重制为低通纸张/木质/正弦短音；峰值 0.025–0.17，逐条峰值/RMS 均低于旧音效，无削波、首尾为零、确定性一致。悬停/普通状态静音；同音 180ms，战斗组 160ms、UI 80ms，重要提示后安静 220ms，3 个 SFX 槽；个人音量/静音继续保留。突发反馈抑制与恢复实测通过，听感仍待用户实际体验。 |
| FY-UX-018 候选保留 | 事件、饰品、服务和升级/移除预选保留原候选，用勾选/金边标记；替换槽和比较附加在同页，底部确认。学年类别选择后保留紧凑类别导航。全部本地查看与预选通过领域/RNG/revision 指纹检查。 |
| FY-UX-019 空白选择页 | 方向/去向各用四张已有插画与等宽图文面板。960×600 标准字号压缩图高和间距，四个学习方向均处于可视区域；大字号保持滚动与固定确认。 |
| FY-UX-020 循证爆发 | 用户所称“循环爆发”对应当前 R3-P03-19「循证爆发」。其立即效果为空而持续能力实际存在；`UiContentText.card_summary` 补能力摘要，并让战斗卡面/悬停/选择读取同源说明。核对下回合生效、成功施加侵蚀第 3 次触发、所有任务完成量基础 4/升级 6、每回合一次；P03 回归验证部署当回合不触发、第 3 次触发、第 4 次不重复。未修改规则数据或引擎。 |
| FY-UX-021 战斗控件 | 标准与紧凑布局的记录/规则换位；`BattleActionButton` 统一纸面/青绿/暖金专注计数与结束回合，保留 UID、当前 run/revision、键盘及门控。既有手牌避让、拖拽与待选回归继续通过。 |
| FY-UX-022 卡面牌堆 | GameSession 新增稳定排序的公开抽牌成员集合，按定义/升级/实例 ID 排序；实际抽取顺序不公开。抽牌/弃牌/耗尽以可滚动卡面网格展示，点击打开固定完整说明，模态锁后台；测试逆转秘密抽序后公开结果相同，查看前后领域/RNG/revision 不变。 |
| FY-UX-023 继续/新局 | `inspect_saves` 只将有效未结束会话/存档标为可继续；无档与终局灰显禁用。无未结束旧局直接开始；终局重开仍经内部归档/摘要合并。未结束、损坏、未知旧档保留替换确认与原件保护。原存档与终局测试按新语义更新并通过。 |
