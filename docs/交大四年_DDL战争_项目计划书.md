# 《交大四年：DDL战争》项目计划书

版本：v3.1｜日期：2026-10-30｜状态：文档重设计，待新版 G0 冻结与实现。

## 1. 项目定位

单人、离线、校园题材的回合制卡牌构筑游戏。玩家选择一位交大学生，用不同学习方式完成作业、应对压力、准备期末。任务未完成量、精力、专注、放松与 DDL 构成基础决策；同学是合作伙伴，失败是错过截止时间或需要重新尝试。

面向喜欢构筑决策、校园轻喜剧和可中断单人体验的玩家，中文与 Windows 键鼠优先。发行平台、售价、团队规模、成本和交付日期均未冻结，不沿用旧稿估算作为承诺。

当前工作区已有 Godot 工程及 v1 阶段证据。当前程序仍为 v1；本轮只改文档和研究交付，不改代码、运行 JSON、测试、图片或玩家存档。实施顺序与例外以[根计划](../实施计划与验收基线.md)为准。

## 2. 核心体验与评审问题

选人决定专属卡池，同一人物内选择发展流派。公共校园牌补充基础工具，人物卡负责顺序、论文、负面状态与伙伴各自的操作闭环。流派允许混搭，不设置局外转职按钮。

| 评审目标 | 将来如何验证 |
|---|---|
| 四人有不同决策 | 比较相邻连携、发表与常驻、持续毒、反应毒与混合减压、伙伴续航的具体选择 |
| 初始即可体验身份 | 四人起手即可连携、开题、侵蚀与混合减压或召入伙伴 |
| 普通牌能成构筑 | 包含未取得稀有牌的路线，记录废牌与关键牌依赖 |
| 考试可用且符合校园语义 | 合作转为备考内化，考试面单独检验，没有现场召人 |
| 新手能理解压力和时间 | 试玩者复述精力、专注、放松、DDL并记录误解 |

这些是未来评审与测试目标，没有实测时不填写胜率、时长或性能成果。

## 3. v3 首期目标范围

### 3.1 一学期切片

| 类别 | 当前设计目标 |
|---|---|
| 人物 | P01林序、P02许知微、P03沈见章、P04唐以宁，保留四人 |
| 永久卡牌 | 172种：四人各40种专属，公共12种；每人四组各10；全体11条主流派，P02两路线另配桥接/支持 |
| 临时牌 | P02解题发表R3-T201与旁听笔记R3-T202，不进永久/奖励 |
| 起手 | 每人永久12张；P02开题固有占首次抽5一格，开题后生成唯一发表 |
| 单位/场景 | R3-U01～03三伙伴、R3-S01/02两场景；另有P02三槽论文区 |
| 饰品 | v3首期不装备、不投放v1饰品 |
| 地图 | 第一学期6层、8个候选节点对象，每条路线经过6节点 |
| 遭遇 | 暂沿用N01～N04、Q01、B01的任务原型，数值需重新评估；精英E01～E02仅候选，不入本期清单 |
| 事件 | 交流方法、调整学习计划及四人故事候选；具体名单与费用待新版G0 |
| 闭环 | 选人、地图、战斗、奖励、商店、事件、休息、期末、总结、保存/继续 |

上述为新版 G0 的待冻结目标，不能替代现有 `campus_mvp` 清单。逐张内容维护于[卡表](校园卡牌设计表_v3.md)，人物与获取数值维护于[角色设计](角色与专属卡池重设计_v3.md)，不在项目计划重复卡文。

### 3.2 范围外与未来候选

本次不制作第二学期、四年毕业流程、跨人物专属牌、多人与联网、排行榜、每日挑战、内容编辑器或新饰品系统。四年成长保留为题材方向，不能以旧八学期内容规模要求本期实现。未来扩展须先证明一学期循环成立，再独立裁决范围。

## 4. 研究与校园转译

已下载的[杀戮尖塔2参考Excel](../artifacts/redesign-20261029/杀戮尖塔2_卡牌参考与流派分析.xlsx)用于研究资源闭环、抽弃筛选、持续能力、伙伴续航与终结窗口。来源是第三方公开快照，包含非奖励牌，游戏补丁版本未确认；来源与缺失字段见[研究说明](杀戮尖塔2卡牌研究与校园转译.md)。

校园方案采用学习动作、合作分工与按时交付，不将原卡数值或外观直接作为本作定义。设计Excel供筛选评审，不是游戏运行数据。
