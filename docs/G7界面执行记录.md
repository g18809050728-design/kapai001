## 实现与边界

| 内容 | 实现 | 可观察行为 |
|---|---|---|
| 启动与路由 | `src/app/main.gd`、`src/ui/game_shell.gd` | 启动显示菜单；新局、继续、设置及局内页面由公共会话视图路由 |
| 局流程 | `src/ui/page_flow.gd` | 选人/难度/seed、地图、奖励、商店、事件、休息、总结；稳定 UID 触发真实按钮 |
| 战斗 | `src/ui/battle_screen.gd`、`battle_screen.tscn` | 手牌/任务/同学、资源、目标预选/取消、效果内选择、公开牌堆、规则与日志 |
| 事件演出 | `src/ui/battle/battle_event_animator.gd` | 只消费发布事件；开关/加速只影响展示时间，日志独立刷新 |
| 素材与控件 | `src/ui/ui_style.gd`、`ui_page.gd`、`ui_labels.json` | 46 张 RGB 实底图作插画显示；系统中文字体回退，米白底板及悬停原因 |
| 保存反馈 | `GameShell` → `GameSession` | 区分当前局保存、长期进度合并、标记清理；失败保留内存局供重试 |

UI 只调用 `GameSession` 公开 API，不访问领域引擎、可写状态或存档文件。`GameSession` 补充非出牌战斗 preview（在副本模拟后仅返回合法性），并提供引擎报价的专注/精力代价及有效卡面；不更改生产规则与内容。实际验证入口为 `tests/run_ui_tests.gd`。

进入节点后战斗已由会话创建，VIS-009 合并到战斗页的继续、保存及菜单交接。终局只有结果为 `won` 才显示学期完成，解锁只在 Profile 合并成功时显示。G2/G4 已登记的 F03 层数和部分饰品触发缺口保留，G7 不替代 G8 的完整生产玩法、平衡、性能或打包验收。
