# G7 界面与交互执行记录

日期：2026-10-15｜状态：G7 本期界面出口已通过；G8 未开始。沿用根计划登记的 G6 本地接入例外，人工视觉签收及来源许可仍待发布前补齐。

本次按用户反馈改善重开与逐层衔接：进行中局可随时进入新局配置，明确确认后替换；奖励、事件和休息完成后自动前进，分支保留选择，商店主动离开。此前已完成底部扇形手牌、悬停放大、点击/拖拽出牌、合法目标高亮和居中卡面待选。本地资源交接与人工审阅的边界以[根计划](../实施计划与验收基线.md)为准；[G6 记录](G6资源准备执行记录.md)保存 46 张选定素材、来源链及 AI 核图证据。[详细设计](../动作或者图片描述/G7界面与交互设计.md)覆盖 VIS-001–013、ACT-001–003，VIS-010/011 因本期只有第一学期而不适用。

| 进行中重开 | `GameSession.restart_run`、`GameShell`、`UiFlowPage`、待选模态 | 配置与返回保留旧局；确认后先校验、合并旧终局摘要、写入新局快照再发布；写盘失败保旧，待选半条效果不写盘 |
| 自动前进 | `GameShell._advance_completed_nodes` | 全部奖励/事件/休息处理完，经 preview 和公开命令离开；唯一下一站自动进入，多分支停地图；商店购买后仍停本页 |

UI 只调用 `GameSession` 公开 API，不访问领域引擎、可写状态或存档文件。`GameSession` 补充非出牌战斗 preview（在副本模拟后仅返回合法性），并提供引擎报价的专注/精力代价及有效卡面；不更改生产规则与内容。实际验证入口为 `tests/run_ui_tests.gd`。

进入节点后战斗已由会话创建，VIS-009 合并到战斗页的继续、保存及菜单交接。终局只有结果为 `won` 才显示学期完成，解锁只在 Profile 合并成功时显示。G2/G4 已登记的 F03 层数和部分饰品触发缺口保留，G7 不替代 G8 的完整生产玩法、平衡、性能或打包验收。
