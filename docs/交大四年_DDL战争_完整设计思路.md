## 1. 产品定位

### 1.1 一句话定义

《交大四年：DDL战争》是一款以大学四年为时间轴的单人回合制卡牌构筑游戏：玩家要在有限精力和DDL压力下完成学习任务，通过选择学习方式、合作对象、学习场景和人生方向，形成自己的毕业路径。

### 1.2 玩家扮演的角色

玩家不是拥有超能力的“考试机器”，而是一名刚入学、逐渐找到学习方式的普通学生。卡牌不是魔法，而是行动习惯：写作、查资料、复盘、熬夜、运动、求助和合作。

游戏不评价哪一种人生选择更高贵，也不把失败表现为角色死亡。失败代表精力耗尽、错过DDL、延毕或需要重新规划；胜利代表完成一个阶段，结局则回应玩家四年的选择。

### 1.3 体验关键词

| 关键词 | 设计要求 |
|---|---|
| 可计划的压力 | 任务意图、DDL、卡牌费用和考试限制尽量公开 |
| 有代价的努力 | 熬夜、冲刺和高效输出可以救急，但会消耗精力或带来焦虑 |
| 找到自己的方法 | 不同人物和构筑都有明确的操作体验，而不是只换数值 |
| 同学是伙伴 | 合作单位提供帮助，但需要管理槽位、精力和考试转化 |
| 四年有回声 | 事件、履历、路线和结局互相回应 |
| 失败也有信息 | 失败总结告诉玩家是精力、DDL、构筑还是路线选择出了问题 |

### 1.4 不做什么

- 不做现实课程知识问答，避免把游戏变成考试模拟器。
- 不做联网排名、每日签到和强制重复游玩。
- 不用复杂随机掩盖规则，关键压力应可预测。
- 不把所有校园地点都做成战斗场景；食堂、导师办公室和操场可以是事件。
- 不用大量永久属性叠加替代构筑决策，传承只解锁选择。

## 2. 核心设计循环

### 2.1 整体循环

```text
选择人物与起始习惯
  ↓
进入学期地图
  ↓
选择要面对的节点与机会成本
  ↓
完成作业、处理事件、购买资源或休息
  ↓
获得卡牌、升级、饰品和履历
  ↓
面对学期首领与新的规则限制
  ↓
进入下一学期，形成更明确的学习方式
  ↓
完成毕业答辩并选择结局
```

### 2.2 一场战斗的循环

```text
观察任务意图与DDL
  → 计算本回合专注和手牌
  → 决定完成、休息、求助或准备资源
  → 处理合作单位与场景
  → 承受任务压力
  → 评估是否进入下一轮
```

每场战斗的核心问题不是“能不能把数字打完”，而是：

1. 本回合要优先完成任务，还是为下回合准备资源？
2. 当前有限的专注应该用在工作、放松、抽牌还是求助？
3. 是否值得为了短期效率承受熬夜、焦虑或单位暂离？
4. 当前考试限制是否要求把平时构筑转成独立作答？

### 2.3 一个学期的循环

学期不是六场互不相关的战斗，而是一次小型成长故事：

- 前几节点让玩家获得方向线索和基础补强；
- 中段让玩家在商店、事件和休息之间选择机会成本；
- 学期首领检查玩家是否真正理解本学期的新机制；
- 结算给出恢复、方向奖励和下一阶段的能力变化。

### 2.4 一整局的循环

整局由四个问题贯穿：

1. **我擅长什么？**——人物和前期卡牌形成初始倾向。
2. **我愿意为效率付出什么？**——精力、钱、合作关系和时间。
3. **我接下来要往哪里走？**——科研、竞赛、实习或升学履历。
4. **我能否在最终限制下独立完成？**——考试和答辩转化前期积累。

## 3. 决策空间设计

不同时间尺度提供不同决策，且每层决策应影响下一层。

| 决策层级 | 玩家问题 | 典型选择 | 主要代价 |
|---|---|---|---|
| 一张牌 | 现在使用、保留还是弃掉？ | 工作、放松、抽牌、积累资源 | 失去另一张牌的机会 |
| 一个回合 | 要输出还是准备？ | 完成任务、获得放松、存资源 | 下轮承受压力或错过DDL |
| 一场战斗 | 先处理哪个问题？ | 主任务、伴生任务、屏障、负面状态 | 任务意图和压力叠加 |
| 一个节点 | 选择收益还是安全？ | 战斗、精英、商店、事件、休息 | 放弃其他节点 |
| 一个学期 | 形成什么能力？ | 升级、删牌、合作、方向奖励 | 未来牌池与路线倾向 |
| 四年 | 想成为什么样的人？ | 科研、竞赛、实习、升学 | 可获得的事件和结局 |

### 3.1 决策质量标准

一个选择只有在以下条件至少满足两项时才值得存在：

- 有清晰的短期收益差异；
- 有可理解的长期影响；
- 有真实机会成本；
- 在特定构筑中更有价值；
- 会改变后续叙事或结局。

如果“恢复精力”在任何时候都比其他选项好，休息系统就失去选择意义；如果“拿一张卡”永远优于跳过，奖励系统也不成立。

## 4. 人物与身份体验

人物不只是初始数值，而是玩家理解游戏的第一种方式。四名人物都可以完成完整游戏，但会鼓励不同的决策节奏。

| 人物 | 核心体验 | 玩家主要思考 | 失败风险 |
|---|---|---|---|
| 林序·系统拆解者 | 规划、连锁、精确执行 | 如何安排代码牌和编译的顺序 | 手牌和费用断档 |
| 许知微·实验记录者 | 积累、观察、等待窗口 | 现在消耗数据，还是等实验成功 | 启动慢、前期压力大 |
| 沈见章·论证组织者 | 组织、回收、修改 | 如何让引用同时支持输出和防护 | 资源堆积但转化不及时 |
| 唐以宁·小组协调者 | 分工、管理、协作 | 哪个单位值得占用槽位和精力 | 考试时合作收益下降 |

人物设计必须满足：

1. 被动能改变行动顺序或资源规划，而不只是单纯加伤害。
2. 初始牌能展示人物的核心玩法，但不会锁死后续路线。
3. 人物短板能通过节点选择和卡牌构筑改善。
4. 人物在考试、普通作业和首领战中都能体现差异。

## 5. 构筑设计

### 5.1 构筑的六段骨架

每条主要路线不只需要“主题牌”，还需要完整的功能闭环：

```text
启动 → 资源积累 → 资源转化 → 过牌/调整 → 防护/恢复 → 终结
```

| 路线 | 启动 | 资源 | 转化 | 终结 | 主要短板 |
|---|---|---|---|---|---|
| 代码 | 编译 | 编译层数与手牌顺序 | 优化、审查 | 上线部署 | 断连后效率下降 |
| 实验 | 记录数据 | 实验数据 | 高通量、图表 | 实验成功 | 需要等待积累 |
| 论文 | 读文献、引言 | 引用 | 方法章节、返修 | 接收通知 | 资源消耗时序复杂 |
| 合作 | 组队、求助 | 单位与槽位 | 协作阶段 | 多单位持续输出 | 依赖单位存活 |
| 竞赛 | 低DDL窗口、熬夜 | 专注与剩余时间 | 重构等输出牌 | 临时抱佛脚 | 容错低 |
| 考研 | 错题本、模拟考试 | 战内复习与心流 | 防护与复习转化 | 专业课复习 | 早期爆发低 |
| 求职 | 实习节点、商店规划 | 生活费与履历机会 | 购买、删牌、升级 | 稳定牌组通过面试与考试 | 依赖商店和事件 |
| 混合 | 跨路线基础牌 | 两种资源 | 组合触发 | 灵活终结 | 卡位和资源冲突 |

### 5.2 主路线与副路线

- **主路线**：代码、实验、论文、合作。负责战斗内主要输出和资源循环。
- **副路线**：竞赛、考研、求职。分别利用短DDL窗口、战内复习积累和局外经济机会，不新增“倒计时”“机会”状态，也不延长考试时限。
- **混合路线**：允许两个主路线共享一部分通用牌，但必须承担启动牌、资源上限或输出牌位不足的成本。

不强制玩家在某个学期选择唯一职业。路线选择通过奖励权重、事件机会和履历表达，而不是把牌组锁成职业树。

### 5.3 卡牌设计语法

每张牌至少回答四件事：

1. 什么时候想打它？
2. 它与哪类牌形成关系？
3. 它为玩家提供什么决策，而不是只提供数值？
4. 它在考试或压力变化下是否仍有用途？

设计限制：

- 白牌提供稳定基础行为，蓝牌提供明确方向，紫牌提供构筑转折，金牌提供终结或重大改变。
- 一张牌可以有多个效果，但必须有一个清晰主用途。
- 免费牌必须有耗尽、回合限次、战斗限次或明确负面代价。
- 抽牌、专注和费用折扣不能同时无条件叠加到一张低费用牌上。
- 负面状态牌必须提供相应收益或明确是任务施加，不用无法处理的纯惩罚填充牌池。
- 卡牌说明按“条件→目标→效果→去向→持续时间”书写。

### 5.4 构筑修正机会

玩家不应因为前两次奖励拿错就无法完成游戏。后续地图评审目标是每学期尽量提供以下机会，而非在现有固定节点上额外免费发放：

- 一次稳定升级或恢复机会；
- 一次删牌或处理特殊负担机会；
- 一次看到不同路线牌的机会；
- 一条不经过精英的安全路径。

但修正不能无代价完成。商店价格、事件支付、节点机会和牌组空间共同构成成本。

## 6. 资源与数值设计思路

### 6.1 五类核心资源

| 资源 | 作用 | 设计含义 |
|---|---|---|
| 精力 | 跨战斗生命与生活状态 | 长期生存、熬夜代价和休息价值 |
| 专注 | 本回合出牌资源 | 回合内决策和费用管理 |
| 手牌 | 当前可选行动 | 选择质量、牌组循环和弃牌机会 |
| DDL | 剩余轮数 | 时间压力、爆发窗口和风险 |
| 生活费 | 战斗外购买力 | 商店、事件和路线机会成本 |

状态资源如编译、实验数据、引用和复习属于构筑专属资源，不应在所有流派之间共享成一条万能能量条。

### 6.2 资源价值的相对基准

首轮平衡采用相对预算而不是绝对真理：

- 1专注约等于一张基础行动的使用机会；
- 1费工作牌约完成6～8；
- 1费放松牌约获得5～8放松；
- 抽1通常弱于直接输出，抽2以上需要费用、耗尽或其他代价；
- 1点精力比1点放松更珍贵，因为精力跨战保留且会影响失败风险；
- 单位的价值由“累计协作＋支援＋承压能力”共同计算，不能只看单次协作量；
- 场景是持续收益，必须附带建立成本、替换机会或风险；
- 饰品提供跨战构筑方向，不应重复提供大量基础专注或直接输出。

这些是调优起点，不是可以绕过试玩的数学证明。所有异常牌先调整自身费用、触发窗口和出现频率，再考虑修改全局资源。

### 6.3 牌组成长节奏

目标不是每个节点都拿牌，而是让牌组在关键学期形成清晰骨架：

| 阶段 | 主要内容 | 设计目标 |
|---|---|---|
| 大一上 | 基础牌、通用策略、少量代码/合作 | 学会牌组循环和删牌 |
| 大一下 | 单位、场景、负面状态 | 开始形成第一个方向 |
| 大二 | 主路线牌集中出现 | 让玩家从主题走向构筑 |
| 大三 | 副路线和混合资源 | 允许根据履历转型 |
| 大四 | 低容错、高限制、终结牌 | 检查构筑是否成熟 |

正式平衡目标：完整局牌组应逐渐从12张基础牌变成约18～26张，包含至少一组防护/恢复、2～4张过牌或调整牌、1～3张终结牌。这个范围需用试玩验证。

## 7. 战斗与任务设计

### 7.1 任务不是换皮敌人

每种任务要有一个主要教学目标和一个压力方式：

| 任务 | 主要教学目标 | 压力来源 |
|---|---|---|
| 课后习题 | 学会稳定输出 | 普通压力 |
| 英语小作文 | 学会先防后攻 | 屏障 |
| C语言练习 | 处理临时干扰 | 生成分心消息 |
| 实验预习 | 处理负面状态 | 焦虑 |
| 数据结构作业 | 处理多段压力 | 连续攻击 |
| 电路实验报告 | 处理查重 | 查重护盾 |
| 数据库项目 | 处理额外要求 | 强化压力 |
| 文献综述 | 处理长线回复 | 恢复未完成量 |
| 竞赛练习 | 处理短DDL | 高压力 |
| 实习笔试 | 处理时间和拖延 | 抽牌削减 |
| 开题材料 | 处理阶段防守 | 大屏障 |
| 毕设修改 | 处理复杂负担 | 特殊牌与多段压力 |

### 7.2 战斗目标多样性

在“降低未完成量”之外，战斗可以评审以下目标，但每场最多引入1～2个附加目标。限时、考试限制和多任务是现行机制；保护合作、连续达标及新失败条件属于后续候选，不能直接作为本版胜负依据：

- **限时完成**：DDL短，鼓励爆发；
- **先处理屏障**：要求玩家安排净化或持续输出；
- **保护合作**：单位全部暂离会失败或损失奖励；
- **连续达标**：连续两轮完成指定量；
- **控制负面**：带有额外要求或查重护盾时，完成效率下降；
- **多任务排序**：不同任务的意图相互影响，决定先后；
- **独立作答**：禁止合作，测试牌组的基础能力；
- **固定考场**：禁止场景，测试玩家的即时资源管理。

每个新目标必须说明：如何获胜、如何失败、玩家能从哪里看见、哪些牌能应对。不使用只靠隐藏规则造成难度的目标。

### 7.3 难度曲线

每学期引入一个主要新机制，再深化一个旧机制：

| 学期 | 新机制 | 深化机制 | 玩家应掌握的能力 |
|---|---|---|---|
| 1 | 专注、意图、DDL | 基础输出和放松 | 计划一个回合 |
| 2 | 合作单位、场景 | 防护和恢复 | 管理持续收益 |
| 3 | 专业资源 | 牌组循环 | 建立主路线 |
| 4 | 双任务 | 合作与全体压力 | 处理目标优先级 |
| 5 | 履历分支 | 混合构筑 | 根据方向改变拿牌 |
| 6 | 查重、返修 | 长线资源 | 控制资源消耗 |
| 7 | 高压考试 | 资源收束 | 用较小牌组稳定输出 |
| 8 | 答辩多阶段 | 全部系统 | 在限制下完成综合验证 |

如果某学期同时引入超过两个核心机制，下一学期应先提供复习和稳定奖励，不继续叠加复杂度。

## 8. 八学期内容与成长节奏

### 8.1 学期设计模板

每个学期固定包含：

1. 一个生活主题；
2. 一个新玩法机制；
3. 一个主要构筑机会；
4. 一个普通任务组合；
5. 一个首领检查；
6. 一个学期结算选择；
7. 一项对后续履历或事件的影响。

### 8.2 八学期完整意图

| 学期 | 叙事阶段 | 玩法教学 | 结尾问题 |
|---|---|---|---|
| 大一上 | 入学与适应 | 基础牌、意图、DDL | 能否完成第一次真正的DDL？ |
| 大一下 | 找到节奏 | 单位、场景、负面状态 | 是否开始知道如何求助？ |
| 大二上 | 专业深入 | 代码、实验、论文资源 | 选择哪种学习方式？ |
| 大二下 | 小组大作业 | 多任务、合作管理 | 能否合理分工而非包办？ |
| 大三上 | 方向选择 | 科研、竞赛、实习事件 | 想把时间投入哪里？ |
| 大三下 | 结果与返修 | 查重、修改、长线压力 | 能否接受并修正错误？ |
| 大四上 | 资格与去向 | 高压考试、资源收束 | 能否独立完成关键任务？ |
| 大四下 | 毕业与告别 | 答辩、多阶段综合战 | 四年选择是否形成自己的答案？ |

### 8.3 学期结算的意义

学期结算不是简单回血和发卡，而是让玩家回顾刚才的选择：

- 恢复精力代表从一个阶段恢复；
- 升级代表方法变熟练；
- 删除特殊负担代表整理生活；
- 方向奖励代表下一阶段倾向；
- 履历增加代表行动留下长期记录。

这些奖励不应让玩家完全重置问题，而应让下一学期更像“带着上一学期的后果继续生活”。

## 9. 地图、商店、休息与事件的机会成本

### 9.1 节点价值

| 节点 | 提供 | 机会成本 |
|---|---|---|
| 普通作业 | 生活费、卡牌候选、熟悉机制 | 消耗精力和DDL |
| 精英任务 | 高品质奖励 | 更高压力和失败风险 |
| 商店 | 定向买牌、饰品、删牌 | 消耗生活费，错过其他节点 |
| 休息 | 精力、升级、删负担、训练 | 放弃即时奖励和路线机会 |
| 事件 | 高波动选择和叙事 | 可能支付精力、钱或加入负担 |
| 首领 | 学期奖励与方向推进 | 必须通过当前学期检验 |

### 9.2 休息不能永远最优

休息设计为安全但机会成本高：

- 精力严重不足时，恢复是合理选择；
- 牌组方向不清时，升级或删牌更有价值；
- 单位路线需要强化时，训练合作牌更有价值；
- 精力充足时，休息应让玩家犹豫是否放弃商店或事件。

### 9.3 商店设计

商店解决的是“定向修正”，不是随机奖励的替代：

- 奖励让玩家发现路线；
- 商店让玩家补关键缺口；
- 删牌让玩家降低牌组噪声；
- 饰品让玩家改变长期策略。

商店库存有限且不补货，避免每次都能等到完美牌。当前价格固定，生活费收入按学期成长。若后续评审要增加动态价格，须另写规则并验证购买力，不能从本文推导商店自动涨价。

### 9.4 事件设计模板

每个事件至少包含：主题、出现学期、前置条件、2～3个选项、即时收益、即时代价、长期影响、是否重复、相关履历和反馈文本。

事件选项尽量形成不同价值观：

- 安全但收益小；
- 现在承担代价换长期收益；
- 放弃资源换叙事或履历；
- 接受负担换钱或稀有机会。

事件不能只是“支付25生活费换一张卡”的菜单。即使奖励相同，也应通过场景、人物关系或后续标记产生不同感受。

## 10. 履历、叙事与结局

### 10.1 履历不应只是结局开关

后续完整设计目标是让科研、竞赛、实习、升学履历连接三类内容；现版已有部分事件条件与结局门槛，履历定向奖励池尚属扩展候选：

1. **事件池**：开放导师、竞赛、实习和报名事件；
2. **奖励池**：提供对应路线卡牌或饰品；
3. **结局**：决定可选择的毕业去向。

履历只提供方向，不提供无限战斗属性。玩家在战斗中做出的学习方式选择，应该通过事件和奖励反馈回局内构筑。

### 10.2 主线结构

```text
入学引子
→ 第一次DDL
→ 找到学习方式
→ 专业与社团选择
→ 科研/竞赛/实习方向分岔
→ 论文、面试或考研压力
→ 毕设冲刺
→ 毕业答辩
→ 结局回顾
```

固定主线负责让每局有完整的四年结构；随机事件和路线履历负责让每局的具体经历不同。主角的变化不是“属性越来越高”，而是可用的方法越来越清楚，同时承担的选择后果越来越明显。

### 10.3 结局表现

结局界面应包含：

- 结局名称与简短正文；
- 四年履历图；
- 主要卡组路线；
- 获得过的关键饰品或单位；
- 重要事件选择回顾；
- 最终答辩表现；
- 可解锁的新人物、故事或开局选项。

同时满足多个去向时全部展示为可选结局，由玩家主动选择；自由探索作为保底结局。失败总结显示具体原因：精力归零、DDL超时、某次首领战失败或主动放弃，并给出“下一局可以尝试的方向”，不直接替玩家判断人生价值。

## 11. 教学、信息与UX

### 11.1 教学节奏

| 教学阶段 | 只引入的内容 |
|---|---|
| 第一战 | 完成量、压力、放松、结束回合 |
| 第二战 | 专注、抽牌、手牌和弃牌 |
| 第三战 | 意图、DDL、优先级 |
| 第一个事件 | 生活费与选择代价 |
| 第一个商店 | 买牌、删牌、饰品槽 |
| 第一个单位 | 合作单位和换班 |
| 第一学期首领 | 独立作答、固定考场和替代卡面 |

该表按机制教学单元组织，不要求新增三场首学期战斗，也不把休息升级搬进商店。现行P04起始就有单位牌，首战须按实际牌组解释单位；教学提示可跳过或重看，关键费用、限制和失败原因始终可见。

### 11.2 信息公开分级

| 信息 | 可见性 |
|---|---|
| 费用、当前专注、精力、DDL | 完全公开 |
| 当前任务意图、阶段、考试限制 | 完全公开 |
| 目标是否合法、出牌后的确定数值 | 完全公开 |
| 奖励品质、商店库存与价格 | 完全公开 |
| 宿舍下一次随机效果 | 生成后公开，建立前不必预知 |
| 抽牌堆顺序 | 默认隐藏，允许查看时按规则展示 |
| 尚未触发的随机事件内容 | 事件进入前隐藏 |
| 未来路线全部内容 | 地图候选公开，具体事件效果不提前泄露 |

核心压力不隐藏，随机感来自选择和结果组合，而不是玩家看不见的敌方意图。

### 11.3 文本与术语规范

- 使用“完成6”，不使用“造成6未完成”。
- 使用“承受压力5”，不使用“敌人攻击5”描述任务作用。
- 使用“恢复3精力”表示正向恢复；“失去3精力”表示代价。
- “放松”是临时防护；“精力”是跨战生命，两者不能混用。
- “暂离”是单位因精力归零离场；“换班”是玩家主动替换，两者必须分别显示。
- “弃牌”只指手牌主动或回合流程进入弃牌堆；“打出后进入弃牌堆”不自动触发弃牌效果。
- “玩家行动阶段”指可主动出牌的阶段；“完整轮末”指任务行动之后的轮末；“本战”指当前作业或考试。“本回合”效果必须注明计数重置与到期事件，不能仅凭术语统一提前清除规则书明确写轮末清除的效果。
- 卡牌文本顺序固定为：条件→目标→主要效果→附加效果→去向/持续时间。

所有数值变化在动画前显示来源和前后值；颜色不是唯一表达方式，必须同时有图标或文字。

## 12. 设计验证与迭代

### 12.1 体验问题诊断

| 现象 | 可能原因 | 优先调整 |
|---|---|---|
| 玩家每回合只打最高数字 | 任务意图或资源机会不足 | 增加准备、目标排序和资源转换价值 |
| 合作单位总是不用 | 单位收益低或考试断崖 | 调整备考面、单位支援和获得节奏 |
| 休息永远最优 | 节点机会成本不足 | 提高商店/事件定向修正价值 |
| 所有牌组都混成一套 | 路线资源差异不够 | 增加专属转化和资源冲突 |
| 事件像菜单 | 没有长期反馈 | 增加履历、后续事件和叙事标记 |
| 玩家不理解失败 | 信息隐藏或结算反馈不足 | 增加意图、DDL预告和失败总结 |
| 后期只是在堆数字 | 学期机制没有变化 | 增加限制、目标类型和转化考验 |

### 12.2 试玩指标

重点记录：

- 玩家是否能复述精力、专注、放松和DDL；
- 每回合主动操作数和无意义等待比例；
- 各路线牌的拿取、使用和跳过率；
- 单学期完成时长和重复游玩意愿；
- 普通、精英、首领的精力损失；
- 单位实际行动次数和考试转化次数；
- 失败原因分布；
- 事件选项选择是否集中在单一最优解。

目标通关率25%～40%只是正常难度熟悉玩家的初步目标，不能替代体验访谈和局内决策分析。

### 12.3 设计评审门槛

新增系统或内容必须回答：

1. 它增加了哪一种玩家决策？
2. 它与校园主题有什么关系？
3. 它改变了哪个时间尺度的循环？
4. 它提供了什么机会成本？
5. 它如何被教学和UI解释？
6. 它如何在考试或首领中被检验？
7. 它是否需要新增永久资源、状态或接口？

答不出其中两项以上时，优先合并到已有系统，而不是新增机制。

## 13. 后续完整设计的交付顺序

本文件只解释体验主线和未来候选，不维护另一套开发门槛。[根实施计划](../实施计划与验收基线.md)是唯一 G0–G8 顺序：G0 统一来源和范围，G1–G5 建立与无头验证规则/内容/局流程/存档，G6 核对图片，G7 详细设计和实现 UI，G8 验收一学期 MVP。

本稿新增战斗目标、履历奖励关联及八学期教学安排保持候选；它们不要求本次 MVP 实现。MVP 验收后，才用试玩证据重估 M3–M6 的路线骨架、任务难度、完整事件/结局和批量资产。每次扩充先更新范围、规则、内容定义和追踪，再按同一门槛验证。

当前图片和动作需求仅在根目录[需求台账](../动作或者图片描述/需求台账.md)写文字；不得依据旧“先画四张线框”条款提前制作 UI。T01–T20 与 RB-01–RB-14 在 G3/G5 等对应阶段转为真实测试，当前只是预期。
