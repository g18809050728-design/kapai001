# 《交大四年：DDL战争》完整设计思路

版本：v3.1｜日期：2026-10-30｜状态：设计理由，未进行游戏平衡实测。

## 1. 人物差异来自操作

保留四人和校园故事，每人40种专属加12种公共。角色区别应体现在选牌、出牌和节奏：林序安排顺序，许知微组织论文或章节，沈见章组合不同负面并选择触发节奏，唐以宁安排伙伴在场与交接。专属池绑定人物，同人物可混搭，不用新增货币替代人物内核。

四人面对相同课程和期末，不按专业限制任务；学习方法决定解题方式，不决定能否参加课程。公共工具体现写作业、休息与自习室经验。

## 2. 主流派如何分开

| 人物 | 构筑与操作差异 | 校园成长 |
|---|---|---|
| 林序 | 连携追求多次策略→工作；复用优先取回高价值策略；集中执行用数张准备换少量重输出 | 从做出结果到解释、验证并复用方法 |
| 许知微 | 发表重视不同牌名和一次兑现；章节重视部署、顺序与持续输出，发表会拆引擎 | 在完成成果与维持研究之间取舍 |
| 沈见章 | 侵蚀增殖等后续持续；诱发连打在本回合多次触发；混合抑制靠不同负面减压削防并用工作推进 | 发现问题后学会组合证据和有节制地论证 |
| 唐以宁 | 分工重伙伴数量与有限指挥；轮换重精力与交接；内化重主角协同门槛与个人输出 | 从包办到分工，再独立作答 |

P02两主流派已足够；牌名覆盖与跨回合重复只是论文内部选择，不另起“mini路线”。四人共11主流派、16功能分组，不追求形式对称。每组设计思路、典型联动和取舍写在[完整卡表](校园卡牌设计表_v3.md)中。

## 3. 论文新增设计的理由

参考稿保留首次牌名进度、重复引用、分级付款、完成度公式、增幅白名单和换题代价。单独的引用循环与完成度经营仍指向同一发表，选牌与收益方式不足以分流。

本版因此允许章节常驻直接完成任务：三槽有序、下回合启动、自动不算出牌。发表一次兑现且把全部章节退回弃牌，玩家明确放弃后续引擎收益。该规则替代参考稿“中间牌不直接输出”，是新增方案而非原参考已包含的行为。保留与改动详见[论文修订说明](论文路线卡牌修订与实现草案.md)。

## 4. 借鉴与校园特色

[研究说明](杀戮尖塔2卡牌研究与校园转译.md)与独立研究Excel记录公开来源和局限。借鉴的是启动、续航、循环与兑现的结构，校园方案自行定义顺序、论文、任务状态和合作，不直接套原卡数值、图标或角色。

六种负面代表任务在持续核查、追问与拆解后的不同变化，状态挂任务实例；易伤与虚弱作为基础工具向全角色开放；章节代表研究结构，伙伴代表有限精力的同学。伙伴暂离需要休息，主动撤回不牺牲获利；考试合作面表现已内化知识。

## 5. 控制复杂度与教学

起手先教一个可操作闭环，常规牌即可启动，不依赖指定稀有牌。升级、衍生和考试面不充40种永久卡数量。能力同名不叠，回收不减费不刷新限次；章节、伙伴与侵蚀有独立自动窗口，诱发在成功出牌后结算，预览说明来源。

第一普通战教基础数字与本角色入口，奖励再解释主流派，事件表现人物矛盾；精英前公开独立作答，期末前能查看完整升级考试面。无需背全部卡表，也不做现实知识考试。

## 6. 未来候选与验证问题

四年成长、履历、毕业选择、更多场景与物件保留候选；本期仅第一学期四人。先比较坏起手、无稀有牌、短DDL、单/多任务与考试，记录完成轮数、精力损失、废牌与机制误解。

论文满分爆发、章节持续输出、侵蚀频率、诱发连打和混合减压与伙伴额外行动都需要重做任务数值评估。上限和耗尽只能约束设计，不能证明已经平衡或没有无限组合。未来R3-T01～23见[角色设计§9](角色与专属卡池重设计_v3.md)，均未执行；实施顺序以[根计划](../实施计划与验收基线.md)为准。
