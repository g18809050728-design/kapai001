# 《交大四年：DDL战争》完整设计思路

版本：v2.0｜日期：2026-10-29｜状态：当前设计理由与未来候选，未进行平衡实测。

## 1. 为什么让卡池绑定人物

四人共享大卡池会使人物差异集中在开局与被动，后续选牌容易趋同。现在采用四人各40种专属与8张公共：选人决定可遇见的机制，局内仍可在同人物三条流派间混搭。公共牌提供写作业、休息调节、整理书包和自习室等共同校园经验，专属牌表现不同的学习方法。

彻底按专业隔离任务会让人物无法参与同一校园主线，因此四人都完成相同课程与期末。身份决定解决问题的方式，不决定能否参加课程。

## 2. 四个人物的构筑与成长

| 人物 | 三条流派如何互相支持 | 校园矛盾 |
|---|---|---|
| 林序 | 编译爆发积累并兑现；短循环安排工作牌顺序；定式引擎用准备时间换持续收益 | 从“我修好了”走向“别人也能理解和接手” |
| 许知微 | 采样筛选找合适牌；对照验证把数据投入防护或推进；重复测量平衡存量与提交 | 接受失败记录，区分真实误差和只保留好结果 |
| 沈见章 | 引用证据提供资源；修订迭代积累稿件；按时交付在不完美时兑现 | 文章可以继续修改，DDL却不会等待 |
| 唐以宁 | 分工推进建立合作；接力轮换照顾伙伴；备考内化让同一牌组适应考试 | 从全部包办到合理分工，再独立交卷 |

精确被动、资源上限和起手只在[角色设计](角色与专属卡池重设计_v2.md)维护；逐张效果在[卡表](校园卡牌设计表_v2.md)，这里不再重复旧牌表。

## 3. 借鉴的机制与校园改写

借鉴《杀戮尖塔2》的资源闭环、筛选、持续能力、伙伴续航、单一载体成长与兑现窗口。公开数据和分析口径见[研究说明](杀戮尖塔2卡牌研究与校园转译.md)，不把研究标签当作官方流派。

编译强调拆解和部署，数据强调复核，引用强调证据，稿件强调修订，协同强调分工。它们都服务于任务完成量与时间取舍。伙伴精力下降表现为需要休息而暂离，主动换班是交接，不以牺牲同学获利。考试合作牌转化为先前内化的知识，不出现现场召入同学帮考。

## 4. 控制复杂度

每人只有自己的资源，跨角色专属牌不混入奖励。常规牌负责启动与防护，稀有牌提高上限，不能设计成没有指定稀有牌就无法启动。起手须展示核心闭环：例如读文献→列提纲消耗引用→唯一草稿交付，拿牌前已经有可理解的目标。

能力从下回合生效，同名不叠加；0费与取回有明确限次；草稿本战唯一、消耗稿件后仍可循环。有限场景不需要额外随机预告或复杂持久库存。上限与限制是设计约束，尚不能证明没有无限连招。

## 5. 第一学期的教学顺序

普通作业先教基础资源与人物启动，第一奖励提示同人物三种发展方向，事件表现人物矛盾，商店帮助补齐构筑。精英前公开独立作答，期末前允许查看升级双面。所有人物机制在第一学期即可接触，不等到后续学期解锁。

避免把教学变成现实知识测试，也不要求玩家背诵全部卡表。预览解释当前费用、资源支付、目标与考试面；故事只提供决策动机，不改写规则。

## 6. 暂缓的扩展

四年成长、跨学期履历、毕业选择与校园物件仍是后续候选。先验证一学期四人体验，再决定扩展哪些故事；旧八路线与大规模目录已退出当前方案。完整版本不以重复八次同一地图代替成长，也不以更多资源叠加代替角色深度。

未来若加入跨人物学习、更多场景或物件，必须重新评估资源归属、考试可用性和信息负担，不能凭旧稿恢复。数量、经济与实现次序以[项目计划](交大四年_DDL战争_项目计划书.md)和[根计划](../实施计划与验收基线.md)为准。

## 7. 接下来要用真实游玩回答什么

比较四人坏起手、无稀有牌、短DDL、多任务与考试表现，记录废牌、资源溢出、完成轮数和精力损失。观察玩家是否理解资源兑现，是否存在始终优于其他选择的套路，以及故事能否通过实际选择表现人物成长。具体未来用例见角色设计§11；当前没有这些实测结果。
