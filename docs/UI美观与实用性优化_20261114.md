已打开本批地图/选中/150%滚动前后、奖励选中/150%、商店正常与150%滚动、战斗正常/150%实渲，并查看[流程页一](../artifacts/verification/ui-beauty-usability-20261114/flow-0.jpg)/[流程页二](../artifacts/verification/ui-beauty-usability-20261114/flow-1.jpg)核对菜单、选角、事件、休息、大奖励、升级、牌组、只读地图、饰品和总结。地图摘要未随全文消失；奖励选择有文字勾选、暖金轮廓与主要确认；商店正常字号餐食/价格完整，150%需滚动查看全部货品，底部确认独立固定。长卡文仍由原详情阅读，不删条件。
