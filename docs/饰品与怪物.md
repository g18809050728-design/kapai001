# 饰品与怪物候选设计

日期：2026-10-30｜状态：内容草案，未进入 G0 冻结清单，未做数值平衡或运行验证。

本文以当前 [v2 统一设计](交大四年_DDL战争_统一设计文档.md)、[规则书](交大四年_DDL战争_游戏规则书.md)和[小怪设计草稿](小怪设计草稿_历史候选_20261030.md)为依据，提出**后续扩展候选**。这里的“怪物”均是作业、考试、项目等任务对手：玩家降低任务的未完成量，任务对玩家或合作单位施加压力。A25–A52、N13–N42、Q05–Q10 只是本目录的临时索引，不是 v2 运行 ID，也不进入新版首期的 N01–N04/Q01/B01 清单。当前 v2 首期明确没有饰品装备或掉落；本目录不改变该决定。现有可运行程序仍为 v1，旧饰品 A01–A24 仅供机制对照，不自动续接到 v2。

## 共通边界

- 饰品为装备，不是卡牌。暂按同名唯一、战斗外换装设计；槽位数、来源、品质权重、价格和人物资格均留给将来的 G0 冻结，不能直接沿用 v1 的六槽或掉落池。本目录不设计初始饰品，也不向 v2 首期商店或奖励加饰品。
- “每战首次”“每回合首次”按对应周期和饰品实例计数；预览、失败命令、存档恢复、换区和开关界面不刷新次数。费用折扣最低为 0。准备阶段的收益发生在自然专注计算后、基础抽牌前；写明“结算后”的收益不能倒付该牌费用。
- A31/A44 只在原报价至少为1且实际减免1时消耗对应限次；0费牌不浪费折扣额度。饰品叠加、角色被动和场景同窗口的总顺序须在未来 G0 冻结。
- 表中“现有语义”仅指旧版程序或 v2 规则已有可参考的动作概念，**不表示 v2 的饰品 schema、hook 或运行处理器已经存在**。“扩展”还需新增规则语义。两类都要在未来 G0 明确触发窗口、内容结构、保存字段及用例后才能实现。
- 任务意图在玩家行动前公开。A→B→C 依次循环；未写 C 时按 A→B 循环。压力默认指向主角，护卫按现行规则承接；“全体压力”同时影响主角和当前合作单位。未完成量与 DDL 为普通难度的初始提案，未乘难度或双任务缩放。

### N20 / N21 扩展规则草案

- **N20 词条分身**：仅在本战首次 B 意图中生成 1 个任务实例，未完成量8、无屏障、无意图、不再复制。它与本体共享战斗 DDL，必须一并完成才能获胜；本体提前完成也不能清掉分身。此后每次 B 均改为压力8，即使分身已经完成也不再次召唤。分身完成不触发额外收益。任务实例创建顺序、任务总数上限及胜负检查须在 G0 冻结后才能实现。
- **N21 本战精力上限侵蚀**：每次该任务实际完成敌方行动后累计减1，最多3；先降低上限，再把当前精力裁到新上限，不直接按压力扣血。战斗结束恢复原上限，当前精力不自动回复；保存/恢复须保留原上限与累计层数。若降低后当前精力会变为0，仍按正常失败检查，不提供隐性保命。这个机制涉及跨战属性与存档，目前不可投放。
