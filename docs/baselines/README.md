# 基线适用版本

[g0.json](g0.json)是v1的历史机器登记，包含旧campus_mvp范围、采用来源hash、旧用例、数值绑定与裁决。现有程序、数据和G0–G7证据仍对应该版本；本轮不修改其字节或重新解释旧ID。

当前同名的四份上游和技术文档已经直接改写为v2；登记中的旧hash与章节不再指向这些文件的当前正文。需要复核v1时，从改写前的Git提交检出所需文档到隔离目录后核验，不在当前根目录执行旧文档核查器。

新版以[根计划§2](../../实施计划与验收基线.md)、[规则书](../交大四年_DDL战争_游戏规则书.md)、[角色设计](../角色与专属卡池重设计_v2.md)及[卡表](../校园卡牌设计表_v2.md)为准。新版G0尚未冻结；以后使用独立版本登记、来源hash与新用例，不能覆盖本文件夹中的旧记录冒称新版通过。
