### 0.2 整体 UI 改善实施

按用户先交文档、后续再执行的要求，新增[整体 UI 体验与布局改善方案](../动作或者图片描述/UI体验与布局改善方案_参考杀戮尖塔2_20261104.md)及 FY-UX-001～015。详见[根计划 §0.11](../实施计划与验收基线.md)与[需求台账](../动作或者图片描述/需求台账.md)。用户已发出执行指令，按根计划 §0.12 和[实施设计](plans/2026-11-04-ui-experience-design.md)推进；A–D 已实施，实际命令、结果、截图及验收边界见[实施记录](UI体验改善实施记录_20261104.md)。

已实施范围包括完整同源卡文、卡牌悬停/聚焦/固定预览与预选确认、中央奖励选卡、学年奖励类别选择、图形路线、任务状态与角色信息、统一升级/移除比较、商品/事件/饰品/方向页面及固定导航。原“全文页面不重复悬停”只描述现有全文版；当前对象展示改版中，奖励/商店/牌组等使用本文分层预览规则，正文不重复全文，完整效果始终可查看。费用、替换对象和关键后果在确认前直接可见。

浏览、筛选、详情、比较与本地预选不提交业务，不改变领域/RNG/revision；确认只经 GameSession 使用当前 offer/choice、稳定实例 ID 与 revision。稳定 campaign 选择和战斗效果内强制待选保留各自保存与取消语义。角色触发机会、固定/随机节点预告、方向/去向结果和终局原因以权威语义及只读视图为准，所需新增字段已在本节及实施设计登记，不由 UI 推算。新增只读字段为 campaign 结果预览、节点公开预告、终局原因和战斗角色专属摘要；预览复制领域状态验证，既不发布也不推进 RNG。设置可选 presentation 字段兼容旧设置，text_scale=100/125/150、reduced_motion、animation_speed=0/1/2/4；不修改局存档 schema。页面草稿绑定渲染时的 run_id/revision，同版确认最多提交一次，过期刷新清本地预选。已有 G7 证据不自动继承为新版验收。

### 0.3 2026-11-05 实机反馈追加

按根计划 §0.13 和[追加设计](plans/2026-11-05-ui-followup-design.md)实施 FY-UX-016～023、FY-ART-003、FY-AUD-003。所有预选保留候选并原位标记；卡牌悬停/选中不改变外部尺寸。地图当前节点加深，业务返回后居中下一可达层，本地查看保留滚动。方向/去向复用图文面板，餐食单张生成并核查后接入。专注/结束回合统一视觉，规则与记录换位。牌堆详情显示完整卡面；GameSession 的 zones_public.draw 为按定义/升级/实例 ID 稳定排序的成员集合，真实抽取序列及 RNG 状态保持隐藏，其他区域沿既有公开信息。查看/排序/预选不改变领域、RNG 或 revision。继续仅允许未结束的有效会话/存档；新局仅在未结束或不可读旧档存在时确认替换。柔和音效保留个人设置并限制突发复音；验收结果独立登记，不沿用旧批次证据。

未固定的卡牌说明优先放在候选网格外侧，避免挡住相邻卡牌点击；进入说明的窄间隙保留当前内容，支持滚动阅读。`I` 固定后使用较宽面板并隔离背景焦点，`Esc` 关闭并恢复原焦点。页面重建后按稳定布局重新定位，说明不得落到页面外。证据见[追加实施记录](UI追加反馈实施记录_20261105.md)。

## 3. 战斗信息与动作

| 对象 | 必须由领域返回并可查看的信息 |
|---|---|
| 基础 | 精力、专注、放松、DDL、任务阶段/未完成量/公开意图、有效卡面/费用/合法目标/禁用原因 |
| 林序 | 前牌类型、连携条件、被动机会、可取回前策略、准备上限/到期与实例限次 |
| 论文 | 开题状态、进度/引用/修正、完成度分项、下层付款、已用名/本回合已用名、唯一发表位置及完整结算预览 |
| 章节 | 三槽顺序、常驻/基础区分、何时生效、本轮自然/额外激活、换章/换序/撤章及发表退场信息 |
| 任务状态 | 每目标六负面/层数/窗口、侵蚀自然与提前、诱发剩余次数、混合被动机会，公开易伤/虚弱非独占；有限复制显示合法源/目标和容量 |
| 伙伴/场景 | 协同、伙伴实例当前/最大精力、护卫/支援、正常/额外行动记录，场景剩余触发及能力生效时点 |

论文区手动使用为领域动作，正常付款且只基础+记账；自动运行不是出牌。伙伴自动选择最早任务，无通用手动目标要求。公开弃牌/耗尽信息，隐藏抽牌序不展示。

付款前预选可取消且不提交写命令；已经抽牌后的效果内待选必须完成，锁住其他输入，只提交当前choice_id。错误保留工作区，旧revision刷新后不自动重发收益。有限复制的源/目标、换班/换章和槽序选择均须由领域提供合法集合；拖动和刷新不清限次。

## 4. 考试、奖励与节点

考试标签提前公开；14种完整替代面及升级可查：7合作/5伙伴策略为独立作答，2场景为固定考场。先替换再选择，不出现考试召伙伴/单位恢复/普通场景选择。合作类型仍触发被动；固定考场允许章节常驻。

所有授牌候选只显示当前人物+公共资格，每人50种，单次普通战仍3选可跳过；基础、衍生、临时及跨人物排除。候选/价格由领域冻结，查看/关闭不重抽。四年模式学年 Boss 后进入学年大奖励，前三年领奖后跨年，大四领奖后毕业总结；旧切片保留第一学期终点语义。地图节点完成返回地图，下一站点击进入，商店主动离开；未冻结服务显示原因，不用UI补收益。

## 5. 保存与失败

规则成功、当前局写盘、Profile合并、清标记分开报告；保存失败只重试保存，不重发业务。战斗效果内待选禁保存并解释原因，campaign 稳定待领奖允许保存并冻结候选。事件用run_id/revision/index消费并保留离场名称快照，不重复播放。未知内容/不兼容/IO错误保留诊断，不伪装空牌组。
