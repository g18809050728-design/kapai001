# 界面层契约

版本：v2.0｜日期：2026-10-29｜状态：新版文字交互需求，未做新版详细布局或实现。

## 1. 边界

UI只读GameSession视图、预览和设置选项，提交公开命令；不持有可写领域状态，不自行计算资源、费用、卡池或考试面，不直接调用BattleEngine/RunService。表现只消费已发生事件，关闭/加速动画不影响规则或RNG。

现有v1页面、uid、测试及截图保留在运行工程与[G7历史记录](G7界面执行记录.md)，精确旧契约可从Git 历史恢复。本轮不把这些测试宣称为新版通过，也不依据新文字去改程序。

## 2. 选人与新局

新版目标展示四人被动、专属起手、资源与三条流派，说明流派可在同人物内混搭。公共10张+2专属为永久12张，P03另有战内草稿，不能把它显示为永久第13张。移除新版选人必须配初始饰品的展示要求。

新局配置显示生产内容与正常难度；继续可用与文件存在分开表达。替换旧局明确确认，取消保旧；损坏/不兼容旧档先归档再重开，IO/摘要合并失败展示可重试原因。用户设置不改当前seed或难度。

## 3. 战斗公开信息与出牌

显示精力、专注、放松、DDL、当前人物资源/上限、任务未完成量/阶段进度与公开意图。卡面使用领域返回的有效普通/升级/考试文本、实际费用、目标和禁用原因，不能在UI套全局考试数值。

展示单位精力、护卫与行动记录、场景剩余触发、能力生效时点、唯一草稿位置和资源支付选值。实例/同名限次由领域返回，不因拖动或刷新清零。公开弃牌/耗尽信息，隐藏抽牌顺序不展示。

预选可取消且不提交写命令；已抽牌的效果内待选必须完成。待选锁住其他规则输入，只接受当前choice_id合法确认；错误保留选择与工作区。提交携带run_id/revision，旧视图请求失败后刷新，不自动重发出牌或购买。v2伙伴自动协作，不增加手动协作目标按钮需求。

## 4. 考试、奖励与节点

进精英/期末前展示独立作答、固定考场和DDL。合作与轮换排班显示各自独立作答面，公共场景显示固定考场面，升级预览也显示完整双面。不能先弹单位/换班选择再转换卡面。

奖励与商店显示人物/公共归属、稀有度、费用和完整效果；不显示其他人物专属牌作为可得候选。冻结候选与价格由领域提供，重绘不重抽；期末终点直接总结。事件/升级/变化目标由领域提供合法集合，草稿不入永久操作候选。

地图完成节点后返回并等待点击下一站；商店主动离开。同页详情与刷新保留合理浏览位置，页面切换重置。服务未冻结或领域未支持时显示原因，不用UI自造收益。

## 5. 保存、日志与错误

显示业务命令结果与持久化结果的区别：规则成功但保存失败时允许重试保存，不能重发业务。待选时保存禁用并说明原因；终局摘要、Profile合并、标记清理分别报告。日志来自公共事件和名称快照，以run_id/revision/index消费，避免重复演出。

未知内容、兼容性与IO错误保留诊断，不显示为空牌组或空进度。现有v1入口与存档保持原状，本轮不创建新版错误页面或素材。

## 6. UI阶段与验收

六项新版需求统一登记于[角色卡池文字需求](../动作或者图片描述/角色卡池重设计需求_v2.md)与[台账](../动作或者图片描述/需求台账.md)：选人、资源、考试、获取、草稿/单位/场景、资源消费交互。全部仅文字、待实现。

新版G0～G5只要求覆盖需求，不要求图、布局或动画。G6核查资源复用与新增图，G7再制定详细视觉/动作设计并实现，G8验证完整可见用户路径。未来测试需覆盖有效面与费用一致、预选取消、待选锁、重复输入、资源选值、无跨角色候选和动画开关状态/RNG一致；当前均未执行。
