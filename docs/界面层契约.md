## 3. 战斗信息与动作

| 对象 | 必须由领域返回并可查看的信息 |
|---|---|
| 基础 | 精力、专注、放松、DDL、任务阶段/未完成量/公开意图、有效卡面/费用/合法目标/禁用原因 |
| 林序 | 前牌类型、连携条件、被动机会、可取回前策略、准备上限/到期与实例限次 |
| 论文 | 开题状态、进度/引用/修正、完成度分项、下层付款、已用名/本回合已用名、唯一发表位置及完整结算预览 |
| 章节 | 三槽顺序、常驻/基础区分、何时生效、本轮自然/额外激活、换章/换序/撤章及发表退场信息 |
| 任务状态 | 每目标六负面/层数/窗口、侵蚀自然与提前、诱发剩余次数、混合被动机会，公开易伤/虚弱非独占；有限复制显示合法源/目标和容量 |
| 伙伴/场景 | 协同、伙伴实例当前/最大精力、护卫/支援、正常/额外行动记录，场景剩余触发及能力生效时点 |

论文区手动使用为领域动作，正常付款且只基础+记账；自动运行不是出牌。伙伴自动选择最早任务，无通用手动目标要求。公开弃牌/耗尽信息，隐藏抽牌序不展示。

付款前预选可取消且不提交写命令；已经抽牌后的效果内待选必须完成，锁住其他输入，只提交当前choice_id。错误保留工作区，旧revision刷新后不自动重发收益。有限复制的源/目标、换班/换章和槽序选择均须由领域提供合法集合；拖动和刷新不清限次。

任务上方展示本轮点「结束回合」后将结算的意图摘要。悬停看摘要，点击意图或用键盘打开可滚动详情。详情列出目标、效果、循环或停留规则、附属资格和特性的触发点。战斗的压力与屏障预估使用当前状态，并计入敌方准备阶段的屏障清理和已预告的技能。出牌及结算中的条件变化会影响实值。图鉴使用基础值。直接增减剩余专注的敌方意图发生在玩家行动之后，下一轮准备会重新计算专注。[UIR-086](../动作或者图片描述/需求台账.md)

任务血条下的状态槽同时显示来自该任务的特殊机制。少抽牌、首牌加费、随机弃牌、精力上限降低等在场机制常驻。轮末扣剩余专注、施加负面状态等图标随当前意图更新，并在任务可行动时显示。已生效的状态依旧按受影响的对象与实际层数显示。机制详情说明目标及具体触发时点。[UIR-088](../动作或者图片描述/需求台账.md)

同一任务可同时显示在场特性、结课效果与本轮特殊意图。多个结课效果按实际顺序写在同一结课图标的详情中。条件压力、全体压力、多段压力与单次召唤分别给出实际结算边界。已结算的绞尽脑汁、迷惑和攻击免疫等按状态记录的目标实例显示实际层数或剩余次数。嘲讽及溢出滚动沿用原状态槽交互。[UIR-089](../动作或者图片描述/需求台账.md)

战斗顶栏和主角血条使用结算后的战斗精力上限。仅旧视图缺少该字段时沿用局流程上限。[UIR-089](../动作或者图片描述/需求台账.md)

取回和弃牌在原候选控件上更新选中状态、数量和确认动作。单选可直接改选，清空和 Esc 只撤销本地选中，待选由对应的规则命令确认。结束回合由按钮与 E 共用输入保护。本次提交后，演出完成且快速输入停顿 600 毫秒才重新开放结束回合。[UIR-087](../动作或者图片描述/需求台账.md)
