# 界面层契约

版本：v3.1｜日期：2026-10-30｜状态：仅文字需求，未做新版布局、素材或实现。

## 1. 边界

UI只经GameSession只读视图/预览和公开命令，不持有可写状态、不计算规则或随机候选。表现消费已发生事件，动画开关/速度不改状态或RNG。v1页面、UID及测试仍见[G7历史](G7界面执行记录.md)，不继承给v3。

## 2. 选人与卡池

四人被动、各40专属和12永久起手完整可查；公共12种中的前4种共10张实例进入起手。P01/P03/P04各三主流派，P02两主流派、另配桥接/支持；分组各10，不把工具组冒称独立路线。人物内可混搭。P02开题固有占首次抽5一格，发表为战内衍生，不显示成第13张永久牌。无新版初始饰品要求。

新局/继续/替换旧局维持明确确认、取消保旧、先归档校验不兼容原件再重开等语义；IO及摘要提交失败显示可重试原因。设置不更改当前seed/人物/难度。

## 3. 战斗信息与动作

| 对象 | 必须由领域返回并可查看的信息 |
|---|---|
| 基础 | 精力、专注、放松、DDL、任务阶段/未完成量/公开意图、有效卡面/费用/合法目标/禁用原因 |
| 林序 | 前牌类型、连携条件、被动机会、可取回前策略、准备上限/到期与实例限次 |
| 论文 | 开题状态、进度/引用/修正、完成度分项、下层付款、已用名/本回合已用名、唯一发表位置及完整结算预览 |
| 章节 | 三槽顺序、常驻/基础区分、何时生效、本轮自然/额外激活、换章/换序/撤章及发表退场信息 |
| 任务状态 | 每目标六负面/层数/窗口、侵蚀自然与提前、诱发剩余次数、混合被动机会，公开易伤/虚弱非独占；有限复制显示合法源/目标和容量 |
| 伙伴/场景 | 协同、伙伴实例当前/最大精力、护卫/支援、正常/额外行动记录，场景剩余触发及能力生效时点 |

论文区手动使用为领域动作，正常付款且只基础+记账；自动运行不是出牌。伙伴自动选择最早任务，无通用手动目标要求。公开弃牌/耗尽信息，隐藏抽牌序不展示。

付款前预选可取消且不提交写命令；已经抽牌后的效果内待选必须完成，锁住其他输入，只提交当前choice_id。错误保留工作区，旧revision刷新后不自动重发收益。有限复制的源/目标、换班/换章和槽序选择均须由领域提供合法集合；拖动和刷新不清限次。

## 4. 考试、奖励与节点

考试标签提前公开；14种完整替代面及升级可查：7合作/5伙伴策略为独立作答，2场景为固定考场。先替换再选择，不出现考试召伙伴/单位恢复/普通场景选择。合作类型仍触发被动；固定考场允许章节常驻。

所有授牌候选只显示当前人物+公共资格，每人50种，单次普通战仍3选可跳过；基础、衍生、临时及跨人物排除。候选/价格由领域冻结，查看/关闭不重抽。期末直接总结。地图节点完成返回地图，下一站点击进入，商店主动离开；未冻结服务显示原因，不用UI补收益。

## 5. 保存与失败

规则成功、当前局写盘、Profile合并、清标记分开报告；保存失败只重试保存，不重发业务。待选禁保存并解释原因。事件用run_id/revision/index消费并保留离场名称快照，不重复播放。未知内容/不兼容/IO错误保留诊断，不伪装空牌组。
