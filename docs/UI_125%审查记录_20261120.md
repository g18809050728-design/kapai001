## 本轮修改

1. 待选卡面补全：`battle_layout.gd` 的选择面板在候选牌不在手牌时，会从弃牌堆/消耗堆读取完整卡面，避免林序取回、弃牌回收等待选出现空卡。
2. 取回待选提示：新增“选择要取回的牌；不选直接确认则放弃（本回合机会已消耗）”，避免玩家误以为必须选牌。

## 保留与说明

- 手牌扇形重叠会遮住相邻卡的部分正文，这是既有交互；悬停、点击详情与 `I` 详情提供完整文本，125% 未引入新的卡面字号变化。
- 设置与图鉴在 125% 下需要滚动，但底部操作区固定且无覆盖；属于可接受的滚动布局，不修改页面结构。
- 未检查 150% 与 960×600 组合；本轮范围按用户指定的 125%。
