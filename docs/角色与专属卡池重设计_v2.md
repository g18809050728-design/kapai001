## 2. 设计裁决与校园辨识度

三个方向比较：继续共池只强化被动，改动少但角色体验仍趋同；按专业彻底隔绝玩法，辨识度高但选牌容易固定；**采用角色专属池加小型公共校园池**，让人物拥有独特资源和决策，公共牌承担生活、调节与基础工具。流派是构筑提示，同人物三条流派可自由混搭，没有局外选流派或转职按钮。

借鉴《杀戮尖塔2》的资源闭环、抽弃筛选、持续能力、伙伴续航、单一载体成长及终结窗口。保留以下校园决策：

- 目标是清空任务未完成量，不杀死同学；伙伴不会被写成牺牲素材。
- 精力是跨节点健康，专注是每回合时间投入，放松吸收压力。主动透支只有有限牌提供，并遵守支付后至少剩1精力。
- DDL 不因成长流派停止。临期牌提供补救，但不加时、不跳过期末阶段；过度准备会超时。
- “独立作答”“固定考场”是公开条件；同学帮助在考试中转为先前内化的分工和知识，不能现场求助。
- 校园事件表现人物成长，不按“编程角色不能做实验”限制任务。四人面对所有课程，区别在解决问题的方式。

不引入星资源、充能球、灾厄斩杀或照搬外观叙事。引用原卡只说明机制研究来源，不代表与其数值一一对应。

每人永久起始牌组 **12 张**：R2-C-01×4、R2-C-02×4、R2-C-03×1、R2-C-04×1，加上表中两张专属牌各1。P03 的临时草稿不计入这12张，首次抽5后再加入手牌，满手则入弃牌。开局全部未升级；正常精力72/72、生活费60、基础专注3、手牌上限10。

P03 的起手闭环为“读文献得引用→列提纲可花1引用增加稿件，并触发被动放松→提交草稿清稿件完成任务”。不花引用也能列提纲，未获得新牌前即可体验两种资源的关系，不能把引用消费入口只放在后续奖励里。

v2 首期**不装备 v1 的A01–A04初始饰品**，将角色发动能力集中到被动和起始牌，避免同一身份分散在三处。旧饰品不自动继承到新版，新版首期奖励/商店也不投放 v1 饰品；保留“校园物件”故事形象，未来若重新加入须另做名单和机制评审。本轮没有设计新版饰品系统，也未修改旧程序饰品。

## 4. 十二条流派及其闭环

每人有40种不同ID的专属设计：三条流派各10种，另有10种通用衔接。公共牌、升级面和临时草稿均不计入40种。普通/进阶牌承担启动、防护与转化，稀有牌提高上限；不要求凑齐一整套，不以拿到一张稀有牌为唯一通关条件。

每人普通20种、进阶15种、稀有5种。这是卡池构成，不替代§8的奖励抽取权重。专属ID为01～40：01～06和19～22为第一流派，07～12和23～26为第二流派，13～18和27～30为第三流派，31～40为通用衔接。通用衔接仍只属于本人物，不是第四流派或公共池。各角色可独立使用或在同人物流派之间混搭。

## 5. 资源、触发与能力时序（v2 规则增量）

| 规则 ID | 精确定义 |
|---|---|
| R2-RES-01 | 编译5、数据6、引用6、协同6、稿件24为上限。初始0，获得时先加后裁切，溢出无补偿；不得跨战保留。只能由所属角色的卡与被动读写，没有跨角色换算。 |
| R2-RES-02 | “必须消耗”在出牌前校验，资源不足不可用；“可消耗0至n”由玩家选择合法整数；“可消耗1/2”是0或指定值；“消耗全部x”允许0。支付在当前命令工作副本中，与专注一起校验后提交，失败不改变资源。 |
| R2-RES-03 | 消耗全部的x固定为支付瞬间值，先扣再算卡面；同一牌后续获得资源不计入x。阈值描述使用该段执行前的当前值；“此前”排除正在结算的牌。资源消耗事件每次实际扣除正数才产生，花0不触发被动。 |
| R2-TRG-01 | 主动弃牌仅指卡面要求的手牌选择弃置，含公共整理书包。回合末弃牌、满手入弃牌、耗尽不算；一次效果弃多张视为一个事件。抽牌后不足规定数量时，只弃当前可选数量；0张不触发。 |
| R2-TRG-02 | 所有新能力从下回合起生效，打出当回合不追溯。能力牌离开循环，进入能力区，本战保留；同名不同实例/升级版不能叠加，第二份不可打出且显示原因。能力增益的“首次”计数按能力名共享。 |
| R2-TRG-03 | 新准备触发固定在旧放松清零、自然专注计算后、基础抽牌前执行。新能力按打出顺序触发；与本提案场景同窗口的总优先序待新版G0冻结；本提案无v1饰品。回合计数先重置，阶段切换不重置。 |
| R2-TRG-04 | 单张牌主效果、旧阶段检查结算完成后，先触发人物被动，再按能力打出顺序触发同事件能力；触发不得递归生成同类“主动弃牌/打出一张牌”事件。P04合作面结算只有一次合作出牌事件。 |
| R2-LIM-01 | 所有写明“每实例每回合限打1次”的牌共享同一实例的回收次数，弃牌/回收/临时改费不重置；不是按手中副本位置计数。R2-P01-13的奖励按同名所有实例合计每回合1次。 |
| R2-LIM-02 | 所有完成量先计算整数表达式，再按v1屏障和任务规则执行；min/floor按数学含义；多任务同时完成仍先生成强制下一阶段再判胜利。DDL每完整轮末正常减少；本设计没有延长或冻结DDL的牌。 |
| R2-LIM-03 | 许知微重复测量、序列观测、仪器维护、复现实验按各自战斗实例记录本战成功打出次数，正在结算的出牌计入本次；第2次起才用增强段，不随次数继续增长。弃牌、回收、阶段转换不清零；同ID另一副本独立计次；战后归零，未来稳定存档须保存。 |
| R2-LIM-04 | 有限回收按卡文限定弃牌堆、归属、永久资格、主类型与基础费用，取回不改费用、打出次数或限次；候选为空则出牌前禁用。取回牌满手入弃牌，仍执行该回收牌的耗尽。保留到下回合只保护下一次轮末弃牌，标记在离手或该次弃牌通过后移除；草稿自带保留不受此一次性效果期限影响。 |

能力与资源上限为防止无界成长的设计约束，并不是“已证明不存在无限连招”。将来必须用回收、0费、能力重复、满手与阶段恢复用例验证。

## 6. 草稿、场景和合作单位

### 6.1 唯一草稿

P03 每战只生成一个 R2-T31“提交草稿”：费用2，保留，消耗全部稿件m，完成8+m，之后正常进入弃牌堆；m可为0。它可再次抽到或被专门取回，提交之后稿件归0、引用保留；稿件是人物本战资源，不绑定卡片实例，不因临时弃置草稿清空。上限24使单次基础最大完成量32，尚未计通用工作增益。

草稿不进永久牌组、不在奖励/商店出现、不可升级/复制/变化/耗尽/删除；“耗尽另一张手牌”的候选排除草稿，无其他候选则不能出牌。允许主动弃牌，但保留可防止回合末自动弃置。满手取回或生成时入弃牌，不能复制或丢失唯一实例。完成战斗后删除，下一战重新生成且稿件清零。若未来事件需要永久变化卡牌，候选同样排除它。

### 6.2 公共场景

R2-S01 自习室为单个当前场景：建立时不立即触发，随后两次准备各获得3放松（升级5），第二次发放后移除。再次建立替换原场景，旧剩余次数作废，以新实例重新计2次；不能叠加或同一准备多次触发。固定考场整段转为卡表中的回忆面，不建立、不处理剩余次数。本提案没有其他新场景。

### 6.3 三位合作伙伴

| ID | 身份 | 精力/上限 | 协作完成量 | 支援与护卫 |
|---|---|---:|---:|---|
| R2-U01 | 复习搭档 | 3/3 | 2 | 无支援、无护卫 |
| R2-U02 | 资料同学 | 4/4 | 1 | 每次行动前使主角获得2放松；无护卫 |
| R2-U03 | 项目搭档 | 5/5 | 3 | 护卫，按v1默认单体压力承接规则 |

沿用v1最多3单位、入场先后、换班待选、行动前支援→协作→自身失去1精力、归零暂离、压力不溢出规则。单位协作默认自动指向当前最早生成的未完成任务，后续行动前重检；玩家不新增单位攻击操作。召入同名单位可形成不同实例。卡面的精力/协作修正只作用于本次召入，不追溯、不永久训练伙伴；修正后初始精力等于新上限。临时补位召入同一R2-U02的短驻场实例：普通2/2、升级3/3，协作仍为1、行动前支援仍为2放松；不新建第四种单位。恢复单位精力最多到当前实例上限，不能把短驻场恢复成基础4上限。

## 7. 考试不是合作流派的废牌关

**本文显式替换 v1 的统一“合作牌5/7放松”做法。** 七张合作牌及轮换排班、轮值支援逐张拥有考试面，费用、主类型、升级次数和耗尽性质保持；公共场景也有固定考场面。完整普通与升级文本见卡牌表。无标签时用普通面；独立作答时换合作与排班面；固定考场时换场景面；同时存在两个标签时各自按类型替换，不能把普通效果与替代面一起执行。

| 牌 | 普通独立作答面概要 | 保留的角色关系 |
|---|---|---|
| 室友搭把手 | 完成5、放松3，耗尽 | 合作类型保留，触发被动协同 |
| 复习搭档 | 抽2弃1、放松4，耗尽 | 筛选后转入个人答题 |
| 项目搭档 | 完成9、协同1，耗尽 | 前期分工转化为个人推进 |
| 考前互讲 | 放松6、协同1，耗尽 | 不召人，也能启动协同 |
| 共享资料 | 抽2、协同1，耗尽 | 使用已经整理的资料知识 |
| 轮换排班 | 放松5、协同1，无单位选择 | 无单位时仍可正常出牌 |
| 课题碰头会 | 完成6、协同1，耗尽 | 合作类型保留，个人执行已有分工 |
| 轮值支援 | 放松7、抽1，无单位选择 | 将轮值经验用于个人节奏 |
| 临时补位 | 抽1、放松4，耗尽 | 保留合作类型，不生成短驻场单位 |

合作牌的单位参数升级在考试面不另执行；使用该牌明确的升级考试文本。替代面仍算原卡主类型，P04被动、接力方法和小组提交均可识别。场景回忆面仍算场景牌。单位恢复/入场/换班效果在独立作答中全部跳过，不能调用召入待选，也不要求单位槽。

例：考试中P04首次打普通室友搭把手，费用1，完成5、放松3，然后被动增加1协同、2放松，总放松5；不召入任何单位。若接力方法此前已生效，再获得1协同；它是能力收益，不再触发第二次合作事件。数值等价性尚待测，不宣称与普通驻场总收益完全相同。

## 8. 卡池绑定与获取规则

所有永久牌使用新命名空间 `R2-C-xx` / `R2-P0n-xx`；人物故事ID继续P01–P04，但未来运行内容包必须独立版本化。普通战后奖励、商店、卡牌事件、变化、生成永久牌、学期奖励都经同一个“当前人物池+公共池”资格过滤，不能仅隐藏其他角色卡图。

| 来源 | v2 首期提案 |
|---|---|
| 普通战奖励 | 3张互不重复候选，可跳过；每位置先75%选本角色、25%选公共，再按普通70/进阶25/稀有5抽稀有度 |
| 精英奖励 | 同上池权重；普通35/进阶50/稀有15 |
| 期末奖励 | 当前第一学期终点直接结算，不追加无后续用途的卡牌；未来中间学期恢复此设计前另定 |
| 商店卡牌 | 3张本角色、1张公共，ID互不重复；普通/进阶/稀有=60/30/10，价格45/75/120；不出售基础牌、衍生牌或v1饰品；入店冻结 |
| 事件“交流方法” | 本角色普通/进阶池按70/30产生2选1，可不拿；不因文案提及其他人物而授予其专属牌 |
| 事件“调整学习计划” | 删除1张合法永久牌后，从同一人物资格池同稀有度变化为另一ID；无候选则该选项在支付前禁用；不得删到少于8张 |
| 升级/训练/删除 | 每张最多升1次；衍生牌不能选。休息“训练合作”在独立作答路线仍可升级该合作牌双面，但不训练单位独立数据 |
| 特殊负担 | v1遭遇若产生X01等负担，它们是遭遇注入而非奖励牌，按旧含义独立保留；无角色资源或跨池能力，不进入168种永久牌统计 |

基础牌R2-C-01/02只用于开局，不进奖励/商店；其他166种永久设计均可按角色资格出现。每个角色实际可见奖励牌为40种专属+6种非基础公共=46种。先剔除不合法/已在本次候选中的ID，再做随机选择；稀有度空池按“普通→进阶→稀有”的固定顺序找非空层；人物/公共某侧空池时转另一侧；两侧都空则缩短候选，不补其他人物牌、不重复ID。角色份额和稀有度均使用reward流，候选产生一次后随稳定快照保存；预览/重绘不重抽。牌组已有同ID不排除再次获得，单次候选不能重复。

**首期没有跨角色选牌、借专业、转职、卡池解锁或彩色万能奖励。** 人物间交流通过故事、公共牌及学习方式呈现，保证资源牌不会落入没有资源定义的人手中。

## 9. 校园节点与人物故事

新人物设计仍放在第一学期六层结构中，不增加第二学期、毕业系统或联网。四人面向同一课程压力和期末，不能按专业免考。故事节点提案如下，具体事件JSON和台词留待新版G0后逐项实现：

| 人物 | 事件触发与矛盾 | 对应已有选项语义 | 行为主题 |
|---|---|---|---|
| 林序 | 课设能运行，同学却不理解 | 升级一张专属牌 / 从合资格普通牌2选1 / 离开，收益互斥 | 解释与交接也是完成工作 |
| 许知微 | 对照组失败，要不要删记录 | 升级数据防护牌 / 获得一张筛选牌 / 离开，不能刷取数据 | 误差值得记录，数据只在战内产生 |
| 沈见章 | 还有一小时，文章仍不完美 | 升级交付牌 / 删一张冗余永久牌（遵守下限）/ 离开 | 及时交付可优于无限返修 |
| 唐以宁 | 组员进度不齐，是否全部包办 | 升级合作牌双面 / 获得一张公共工具牌 / 离开 | 分清责任，考试自己作答 |

事件为后续内容候选，本轮不声称实现，也不另增持久资源。生活费、恢复与升级费用仍须在新版G0统一裁决；上表免费选项各事件每局仅一次，不能循环刷取。
