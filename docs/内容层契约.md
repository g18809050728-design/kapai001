## 3. 卡牌与机制必须表达的语义

每张牌完整表达归属、牌名键、分组、主类型、稀有度、基础及完整升级面、完整考试面、费用/目标/选值、生命周期、限次和定义引用。不得用全局考试常量代替14种逐牌完整替代文本，不让UI自行拼升级效果。

| 机制 | 内容与领域层的承接要求 |
|---|---|
| 林序 | 相邻策略→工作、前牌永久来源、每回合被动一次、同实例本战重用、首段加值上限12及重费减费上限1 |
| 论文 | 开题/关闭、本篇已用牌名与回合同名集合、进度10/引用5/修正、分层付款、增幅白名单与上限5、唯一发表生命周期 |
| 章节 | 三槽顺序、部署生效回合、基础与常驻分离、自然/额外窗口、每实例额外激活记录、发表撤章 |
| 任务负面 | 侵蚀20/诱发3/脆化3/乏力4/虚弱3/易伤3，附着任务实例；自然/提前结算、诱发快照和4次上限、抽牌施毒、批次计数、混合被动与有限复制分别定义；易伤虚弱全角色通用 |
| 伙伴 | 协同6、首合作被动、正常/额外行动、精力消耗、短驻场实例上限、考试面 |

能力下回合生效、同名不叠；限次不因回收/换区/换序刷新。实际出牌、主动弃牌、论文记账、卡牌施加、章节自动、侵蚀自然/提前、诱发、检索连锁及批次收益、伙伴协作是不同事件。未知操作或触发必须拒绝，不吞掉不认识的部分。

解题发表不可永久获得/升级/复制/变化/耗尽/删除；开题只生成或取回同一个实例。章节复印保留源定义及牌名键，附临时、不可部署、使用耗尽覆盖，不新增定义。旁听笔记统一同名。合作召入可有本实例精力/协作修正，当前值不能超实例上限；不得恢复成基础单位数值。
