# 沈见章毒师与全角色通用功能修订

日期：2026-10-30｜版本：v3.1｜范围：设计文档、设计JSON与Excel。当前程序仍为v1，本轮未改程序、运行数据、素材或玩家存档。

## 1. 本次改成什么

沈见章的40张专属重新组织为多负面联动的毒师。原来围绕同一种状态安排持续、消费和扩散，构筑过于接近；本版改成**持续毒、反应毒、混合抑制**三种收益方式。易伤、虚弱是全角色基础功能，人物身份由施加效率、混合被动和触发配套体现。

四人仍各40种专属、每人四组各10。林序、许知微、唐以宁各改2张支持牌；公共池由8种扩为12种，补易伤、虚弱、破盾和群攻。最终共172种永久牌、2种论文衍生、174个卡定义，每人奖励资格40+10=50种。升级面不充数量；起手仍12张，沈见章专属起手改为破题追问、削弱论势。

与本轮改前快照逐字段相比，沈见章39张有变化，支持牌“回看笔记”保留原有限回收效果；加上其余三人6张，共修改45个既有定义，新增4个公共定义。论文衍生和其他既有卡未改，具体字段差异见文末机器记录。

完整机制见[角色设计§5](角色与专属卡池重设计_v3.md)，逐牌基础/升级及组前导读见[卡表](校园卡牌设计表_v3.md)，筛选版见[Excel](../artifacts/redesign-20261030/校园角色与专属卡池_v3.xlsx)。文件名与R3卡ID沿用v3，内容版本更新为v3.1；不能与v1运行内容或旧存档混读。

## 2. 内核与被动

毒师需要有一套互相配合的手段：持续削减任务、当回合诱发反应、腐蚀防御、降低压力，再选择合适的工作牌推进。各状态有自己的作用和时机，选牌时需要考虑组合和出牌顺序。

被动 **复合反应**：每回合首次通过卡牌正文，给已经有另一种负面的任务建立一种新负面，正文结束后，该新状态额外+1层。单纯加厚旧状态不触发；一次群体牌只强化一个合法目标，实际强化才消耗机会。自动施毒和检索连锁不能发动被动，额外层不递归。

例如已有侵蚀后再施虚弱，虚弱可以从1变2；空目标依次获得诱发、易伤时，后建立的易伤可以获强化。被动鼓励补入缺少的状态，不要求凑齐六种，也不让群体施加成倍强化。完整候选顺序、失效和上限规则统一在角色设计维护。

## 3. 六种负面分别做什么

| 状态 | 玩家理解 | 上限与到期 | 如何配合 |
|---|---|---|---|
| 侵蚀 | 持续毒，留给后续任务阶段推进 | 上限20，每次自然结算按当前层输出后减1 | 条件加厚、有限增殖、提高结算频率；不消费毒层换爆发 |
| 诱发 | 反应毒，挂上后继续出牌便能触发 | 上限3，行动结束清；每目标每回合默认/额外总计最多4次 | 低费牌、过牌、有限额外触发，主要收益在当前回合 |
| 脆化 | 腐蚀防御，使以后获得的屏障减半 | 上限3，层数表示剩余压力窗口 | 配合移除已有屏障的工具，两个作用分开计算 |
| 乏力 | 持续减压，每段压力先减当前层数 | 上限4，在同一任务实例内保持 | 长任务、多段压力有价值；随后再计算虚弱倍率 |
| 虚弱 | 减压基础工具，压力乘0.75向下取整 | 上限3，压力窗口后减1 | 四个人都可用，配合乏力、防护和护卫 |
| 易伤 | 增伤基础工具，工作直接完成量乘1.25 | 上限3，压力窗口后减1 | 四个人都可用；不放大毒、伙伴或章节自动输出 |

侵蚀、诱发等状态完成量同样先经过屏障。三种计时负面在无压力的窗口也减1；任务阶段才生成、当轮不能行动的新任务不提前扣层。换阶段清旧任务状态，输出只作用快照中的原实例。六种类数不包含主角焦虑或任务强化“额外要求”。

## 4. 三条路线怎样分开

| 路线 | 选牌优先级 | 操作与主要收益 | 代价 |
|---|---|---|---|
| 侵蚀增殖（10） | 施毒、加厚、增殖、频率能力、防护 | 圈出疑点→疑点滋生；追踪记录持续施毒，加速剖析让自然窗口多结算，提前验算有限提前兑现 | 需要等待；短DDL、换阶段压缩后续收益 |
| 诱发连打（10） | 反应毒、低费、抽牌、抽牌施毒 | 设下追问→短句反问/翻页核证→逐句质询；二次追问提供额外触发，检索连锁与循证爆发奖励抽牌和施毒批次 | 先挂再打，当回合必须有后续手牌；每目标4次上限，不能靠重挂刷新 |
| 混合抑制（10） | 不同负面、工作输出、防护、维持窗口 | 削弱论势减压，拆解防线削防，公开前提增伤；论点交锋/全面质询按负面种类数兑现工作输出 | 要兼顾施加牌和输出牌；不靠单毒厚度，最多计4种 |
| 通用衔接（10，支持组） | 抽牌、防护、纠错、有限回收、保留 | 整理思绪找启动、留待答辩留关键牌、复盘取证筛选、配方笔记承接被动 | 工具过多会降低输出密度，不算第四条路线 |

侵蚀选择“用少量行动换后续收益”，诱发选择“把手牌与费用留在同一回合多次触发”，混合选择“先压低威胁再用工作推进”。三者可以混搭，但不用同一种厚度的状态作为全部收益来源。侵蚀扩散是第一路线内的多目标工具；没有另凑一条只在多目标有效的主路线。

## 5. 与《杀戮尖塔2》的参考关系

本轮使用2026-10-29已保存的中英文第三方API快照，抽取9张参考并逐条保存[原记录、来源路径与SHA256](../artifacts/redesign-20261030/debuff-revision/reference-cards.json)。这是固定快照中的卡文研究；游戏补丁未确认，不宣称最新牌库，也未把beta数据混入。

| 参考卡ID | 快照中的结构 | 校园转译 |
|---|---|---|
| DEADLY_POISON | 直接施毒 | 圈出疑点承担基础施毒入口 |
| POISONED_STAB | 攻击附带毒 | 破题追问兼顾直接完成和持续毒 |
| NOXIOUS_FUMES | 每回合向全体施毒 | 追踪记录成为自动铺毒能力 |
| BUBBLE_BUBBLE | 已中毒目标获得较高追加毒 | 疑点滋生奖励已有侵蚀，不另造资源 |
| ACCELERANT | 毒额外结算 | 加速剖析改变自然结算频率，校园版逐次减层并设自身上限 |
| CORROSIVE_WAVE | 当回合抽牌带来群体施毒 | 检索连锁限接下来3/4张实际抽牌，避免无限触发 |
| OUTBREAK | 施毒次数带来群体输出 | 循证爆发按合格施毒批次计数，群体一次算一批，每回合一次 |
| MALAISE | 同时削减力量与施加虚弱 | 削弱论势组合乏力与虚弱，形成长期减压配套 |
| STRANGLE | 当回合后续出牌造成额外失血 | 借其触发结构设计诱发连打，改为状态完成量和每目标4次上限 |

**原作的主要毒状态仍是Poison，STRANGLE的失血也不等于原作的第二种Poison。** 校园版六负面、反应毒归类、复合反应、上限、任务窗口和压力公式均属本项目扩展。借鉴的是施加入口、联动与收益方式，不是声称原作有六种毒或照抄数值。完整研究边界见[研究说明](杀戮尖塔2卡牌研究与校园转译.md)。
