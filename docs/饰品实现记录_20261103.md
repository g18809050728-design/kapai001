# 饰品 A25–A48 实现记录（2026-11-03）

状态：A25–A48 已接入 v1 生产清单；2026-11-03 规则、集成、既有 UI 套件及启动冒烟在 Godot 4.7.2 实测通过。此项是[根计划 §0.3](../实施计划与验收基线.md)授权的 v1 扩充，不构成新版 G0–G8 验收；人工视觉、平衡和完整用户路径仍未验证。

## 1. 范围与版本

来源为[饰品与怪物](饰品与怪物.md)的 24 件通用饰品 A25–A48，原文仍保留历史候选状态；本轮运行规则以根计划及[内容契约](内容层契约.md) [战斗契约](战斗模块契约.md) [局流程契约](局流程契约.md)的 v1 补充为准。A49–A52 与同文档 N13–N42/Q05–Q10 不在本轮范围；同号 N13–N38 已由另一份草稿落地，不能覆盖。v3.1 首期仍无饰品，旧 `docs/baselines/g0.json` 不因本轮改写。

| 组别 | ID | 内容与获取 |
|---|---|---|
| 白色 | A25–A32 | 8 件；v1 奖励与白色商店货位 |
| 蓝色 | A33–A40 | 8 件；v1 奖励与蓝色商店货位 |
| 紫色 | A41–A46 | 6 件；仅 v1 奖励 |
| 金色 | A47–A48 | 2 件；仅 v1 奖励 |

采用 v1 六槽、同名唯一、战斗外获取/替换；不加初始饰品。`campus_mvp.v1` 内容 hash 变化后，旧档按现有严格兼容校验拒绝；本轮不做迁移，也不读写真实玩家存档。

**已知生产可用性限制**：当前 v1 的 `data/definitions/cards.json` 中 `type: "ability"` 定义为 0 张，生产清单也未启用能力牌。A27 虽按本轮授权进入白色奖励/商店池，在当前生产局无法触发；A46 的能力牌分支同样不可达。隔离 fixture 可以验证对应处理器，但不能据此宣称两者的能力牌效果在生产局可用。本轮保持 24 件投放范围；补充能力牌或调整饰品投放须另行裁决。
