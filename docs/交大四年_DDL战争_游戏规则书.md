## 1. 游戏概览

### 1.1 目标

玩家选择一名交大学生，在一学期内沿地图前进，用卡牌完成作业与考试、管理压力与截止时间。完成任务、活到学期末即胜利；精力归零或 DDL 归零且仍有任务即失败。

### 1.2 单局结构

选人 → 开局 → 六层地图（普通/事件/商店/精英/休息/期末）→ 学期总结。战斗外保留精力、生活费、永久牌组与节点记录；战斗内资源在战后清除。

### 1.3 胜负 [END-001～003]

- **[END-001]** 主角精力大于 0，所有任务完成，且强制下一阶段与连锁都已处理完毕，才胜利。阶段工作量归零先生成下一阶段，不立即判整场胜利。最后任务真正完成后，停止无关后续效果，不继续扣单位续航、施压或扣 DDL。
- **[END-002]** 第一学期期末完成即本期终点，显示“第一学期完成”，不宣称完整四年通关。
- **[END-003]** 主角精力归零，或完整轮末 DDL 归零仍有任务，判失败。同一不可拆分效果中主角与最后任务一起归零，优先失败。普通恢复不能补救已经结束的失败；本期没有救命饰品。

## 2. 组件与术语

### 2.1 基础资源

| 资源 | 初始/上限 | 说明 |
|---|---:|---|
| 精力 | 72 / 72 | 主角生命；主动支付绕过放松且支付后至少剩 1；效果失去可归零 |
| 专注 | 0 / 10，自然 3 | 每回合准备恢复；出牌费用；不靠弃牌获得 |
| 放松 | 每回合准备清零 | 先于精力承受压力；不是生命 |
| 生活费 | 60 | 商店与事件费用；跨节点保留 |
| DDL | 6（默认） | 剩余完整轮末次数；遭遇可覆盖 |

### 2.2 任务与数值

- **未完成量**：任务还需要完成的数量；归零即完成。
- **完成量**：工作牌、状态、伙伴、章节等造成的进度。
- **压力**：任务对主角的威胁，先扣放松再扣精力。
- **屏障**：先于未完成量吸收完成量；任务准备时清除旧屏障。
- **阶段**：多阶段遭遇中的一段任务实例；切换时建立新实例。

### 2.3 卡牌分类 [EFF-001/002]

- 主类型：工作、策略、能力、合作、场景。一张牌只有一个主类型。
- 稀有度：基础、普通、进阶、稀有；衍生是生命周期分类，不是奖励稀有度。
- 永久牌：进入牌组、可升级；本战实例与永久定义分离。
- 衍生/临时牌：不进永久牌组与奖励池；战后移除。
- 流派标签只用于构筑理解，不是额外职业资格或伤害类型。

### 2.4 实例与定义 [ENT-001/002]

- 定义 ID 表示“哪张牌”；实例 ID 表示“这一张牌”。
- 同名多张牌可同时存在；升级一张不修改其他实例。
- 永久牌、战斗卡、任务、单位、场景分别有实例 ID；定义 ID 不代替实例 ID。
- 牌区：抽牌堆、手牌、弃牌堆、耗尽区、结算区、能力区、P02 论文区；顺序分别记录。

### 2.5 不启用的系统 [ENT-003]

不启用卡牌点数、连点、融牌；没有通用“弃牌换专注”。

## 3. 设置与开局

### 3.1 选人与起手 [RUN-001]

- 四人永久起手均 12 张：R3-C-01 写作业×4、R3-C-02 伸个懒腰×4、R3-C-03 整理书包×1、R3-C-04 喝水调整×1，加两张人物专属。
- 林序：快速定位、小步实践；许知微：开题、引言章；沈见章：破题追问、削弱论势；唐以宁：室友搭把手、分工清单。
- 正常精力 72/72、生活费 60、自然专注 3、基础抽 5、手牌上限 10，无初始饰品。
- P02 开题为固有，占首次基础抽 5 的一格，剩余位置正常抽取；不是额外赠牌。没有开题前不生成发表；其他人物没有初始衍生牌。

### 3.2 难度与资格 [RUN-002]

- 首期仅正常难度。
- 每人 40 种专属分 4 组各 10；P01/P03/P04 各 3 主流派，P02 两主流派加桥接与支持，全体 11 主流派。
- 同人物内可混搭；所有永久授牌入口统一“人物＋公共”资格，没有跨人物永久授牌。
- 永久牌组只能包含本人物专属与公共牌；本期未规定同名上限（起手基础牌即多副本）。牌组上限与通用下限待 G0，已知调整学习计划事件不得删至少于 8 张。

## 4. 回合结构

### 4.1 阶段顺序

一个完整回合按以下顺序：

```
玩家准备 → 玩家行动 → 合作阶段 → 弃手牌 → 任务阶段 → 完整轮末 → 下一回合
```

**[PLR-001/002]** 按准备顺序进入玩家行动；自然专注 3、基础抽 5，修正后最少 0。章节在专注恢复后、能力/场景与基础抽牌前运行。准备中的自动效果不算出牌，不能制造连携、论文记账或首策略/工作触发。

**[PLR-006]** 玩家行动结束与完整轮末分开；先清诱发与本回合检索连锁，再进入正常合作；困倦在对应玩家行动结束清除，弃牌后进入任务阶段，不额外恢复专注或扣 DDL。

### 4.2 准备顺序

1. 清空旧放松。
2. 重置本回合记录（已打牌、连携、首合作、限次等）。
3. 计算自然专注，扣除焦虑层数，清已生效焦虑。
4. 明确写“开战”的效果，仅首回合。
5. 已生效章节按槽 1→3 自动运行。
6. 能力与场景按入场时的共同创建顺序触发。
7. 基础抽牌 5，扣除拖延层数，清已生效拖延。
8. 明确写“抽后”的效果。

新能力、章节与场景都从下回合开始生效。每个触发结算完成再进入下一个，不能由动画回调推进。

### 4.3 玩家行动 [PLR-003]

玩家可以合法出牌、从论文区手动使用章节、查看公开信息或结束回合。每张牌与唯一待选完成后才能进行下一操作。章节手动使用正常付费，只执行基础效果与记账，不额外运行常驻。指定额外伙伴行动由卡文完成，没有通用手动选择协作目标。

### 4.4 合作阶段 [PLR-004]

结束行动后，先清诱发与本回合检索连锁，再快照存活伙伴，按入场顺序逐个：支援 → 协作最早未完成任务 → 自身失去 1 精力；归零暂离。每实例正常行动一次；出牌阶段召入可当轮行动，合作阶段新入场者不补入快照。卡文另给的额外行动每伙伴每回合最多一次，同样扣续航，不替代正常行动。行动前重检目标；胜利后不扣续航。

### 4.5 轮末 [PLR-005]

合作阶段结束后、任务阶段开始前，弃置非保留手牌，普通保留额度 0；卡文明示的临时保留只保护下一次轮末弃牌、离手即清；解题发表自带保留。以旧手牌快照逐张弃置，新触发入手牌不加入旧名单。保留仍占 10 张容量。随后进入任务阶段与完整轮末。

## 5. 资源与支付

### 5.1 专注 [ENG-001/002]

- 战斗初始 0，自然 3，上限 10，下限 0。
- 准备先清剩余专注，再计算本轮专注；敌方阶段不主动清空，但不能在该阶段主动出牌。
- 弃牌不自动获得专注；没有通用融牌。

### 5.2 支付与费用 [ENG-003]

- 专注不足、强制人物资源不足或目标不合法时不能出牌。
- 主动支付精力绕过放松，支付后必须至少剩 1；效果导致失去精力可归零。
- 实际费用 = `max(0, 基础费用 + 加费 - 减费)`。
- 预选取消与预检失败不扣费、不耗随机、不改 revision。
- 资源的必须消耗、可选消耗和消耗全部按人物规则与逐牌文本；只在实际扣除正数时发消费事件，x 取支付瞬间值。不能使用后续卡面获得的资源反付先前费用。

## 6. 牌区与抽牌

### 6.1 抽牌 [DRW-001/002]

- 逐张抽牌；手满即停止剩余抽取。
- 抽牌堆空则把弃牌堆洗入；两堆都空则停止，耗尽、能力与结算区不洗回。
- “抽到时”效果先处理再抽下一张，不补欠抽牌。
- 基础抽 5、手牌上限 10。生成/取回等非抽牌加入手牌，手满改入弃牌；不算主动弃牌，不补专注。保留牌仍占容量。

### 6.2 主动弃牌 [DSC-001]

只有卡文主动选择手牌弃置才算主动弃牌；一次多张为一个事件，实际 0 张不触发。轮末弃牌、满手入弃牌、出牌归区与耗尽不算主动弃牌。

### 6.3 耗尽与临时牌 [DSC-002/003/004]

- 耗尽牌本战不再洗回；能力区本战保留。
- 永久牌与本战实例分开。每战开题生成/取回唯一 R3-T201 解题发表：2 费、保留、正常弃牌；禁止升级/复制/变化/耗尽/永久获得/删除，战后移除。
- R3-T202 旁听笔记为 0 费抽 1 耗尽，统一同名、战后移除。
- 章节复印沿用源定义 ID，只生成临时不可部署基础面，可执行基础效果与记账，使用耗尽。
- 普通回收只允许永久牌；开题取回发表是明确例外。
- 战后销毁战斗卡、临时覆盖、章节/论文/任务负面/同名限次/伙伴等记录；下战由永久牌组重建，精力不自动回满。

## 7. 出牌与效果队列

### 7.1 出牌流程 [PLY-001]

1. 校验相位/待选/实例及同名限次。
2. 解析升级与考试面。
3. 收齐支付前目标、换班/换章和资源选值。
4. 计算并校验费用。
5. 整体支付。
6. 进入结算并记录实际出牌、快照原诱发。
7. 卡牌正文与强制阶段。
8. 人物被动。
9. 同事件能力按打出顺序。
10. 原诱发快照结算。
11. 正常归区。

章节部署进入论文区；手动重用留原槽。自动触发不添加实际出牌记录。

人物快照：

- 林序在当前工作主效果前固定前一牌类型，工作完成后判被动，之后更新连携计数。
- P02 在正文前固定新/旧名字，正文后记账，引用专注使用当时余额，不足抽 1。
- 沈见章逐项记录“已有另一负面、实际新建一种状态”的候选，正文后复合反应只强化一个。
- 唐以宁合作正文后得被动协同，不可倒付正文消费。

所有人物在出牌开始快照原有诱发目标与层数；正文、被动及同事件能力后按原实例结算诱发；新施诱发不触发本牌。

费用已付后旧目标失效则跳过对应剩余段，其他合法效果继续、不退款。主角归零优先失败；正式终局停止无关后续，但发表关闭本篇与退章属于同一效果的必要收尾，仍须完成。

### 7.2 待选与信息 [PLY-002]

- 抽后弃牌等选择必须先看到实际抽取再选，不能取消整牌回滚信息。
- 待选只接受当前 choice_id 的合法确认；不出牌、不结束回合、不保存半条效果。
- 错误确认保留最近工作区；重启恢复最近成功写盘的稳定档。
- 预选取消与拒绝不改状态/RNG/revision。

### 7.3 效果与触发 [RES-001/002/003]

- 每个不可拆分效果后处理归零、暂离、阶段及连锁；主角归零失败优先。
- 普通来源按稳定创建顺序、实例 ID 和效果索引排序。
- 人物被动先于同事件能力；能力只在生效回合开始后响应。
- 自动结算不递归制造出牌/施加事件。
- 换区、回收、改费、换序不刷新实例/同名限次；阶段不重置回合。
- P02 同名每回合最多实际打一次；升级及临时副本共用同名键。
- 0 费循环须有耗尽或实例限次；队列诊断中止是错误处理，不是合法无限玩法。
- 林序重复练习等按同实例本战成功使用次数，包含正在结算的这次；第 2 次起固定增强、不继续成长；同名副本分开。
- 回收不减费；下一工作准备加值合并上限 12，下一重费工作减费合计上限 1，均轮末清。
- 侵蚀施加批次、诱发每目标 4 次/首次、复合反应、检索连锁剩余抽牌与循证爆发每回合计数均独立记录；伙伴额外行动与章节激活不能借换区刷新。
- 自动/被动加层不制造新的正文施加事件。

## 8. 完成量、压力、屏障与护卫

### 8.1 完成量 [DMG-001/002]

`完成量 = max(0, floor((基础 + 适用固定加值 - 惩罚) × 适用倍率))`。

- 先扣屏障，再减未完成量；新阶段不承接旧阶段超额完成量。
- 下一张工作牌的通用加值只作用第一段；群体牌只给所选主目标，其他目标按原值，除非牌文明示不同。
- 工作增益不自动增强单位协作；多段逐段检查，群体同段同时应用再处理离场。
- 易伤只进入工作牌直接完成量倍率；状态、伙伴、章节自动均不享受。

### 8.2 压力 [DMG-003/004]

- 每段先合并固定加值，再减乏力至最低 0，然后乘虚弱 0.75 向下取整。
- 先扣放松，再扣精力，两者最低 0。
- 主动精力支付、直接失去精力与压力是不同变化。
- 最早入场护卫承接默认单体压力；不改向全体或显式点名。每段重选，护卫暂离时伤害不溢出主角。例如 3 精力护卫受 5×2：首段暂离，第二段无其他护卫则打主角。

### 8.3 屏障与多段

- 屏障吸收完成量，归零前不伤害未完成量。
- 脆化只改变新获得屏障的数值，不移除已有屏障。
- 多段效果逐段检查目标；旧目标失效跳过剩余段，其他段继续。
- 群体牌同段同时应用，然后处理离场与阶段。

| 协同 | P04 上限 6，按牌文消费或读门槛 | 本战，初始 0 |

| 诱发 | 3；后续成功出牌按开始时层数产生状态完成量 | 每目标每回合默认与额外最多 4 次，行动结束清 |
| 脆化 | 3；新获屏障 ×0.5，不移除已有屏障 | 压力窗口后减 1 |
| 乏力 | 4；每段压力先减层数，最低 0 | 任务实例内保持，不自然衰减 |
| 虚弱 | 3；压力逐段 ×0.75 向下取整，全角色通用 | 压力窗口后减 1 |
| 易伤 | 3；工作直接完成量 ×1.25，全角色通用 | 压力窗口后减 1；不增强状态/伙伴/章节自动 |
| 焦虑 | 2；下次自然专注每层少 1 | 对应准备生效后清 |
| 拖延 | 3；下次基础抽牌每层少 1 | 对应抽牌生效后清 |
| 困倦 | 2；下次玩家行动工作第一段每层少 1 | 该玩家行动结束清 |
| 额外要求 | 3；任务每层压力 +2 | 本战，仅明确效果移除；投放待 G0 |
| 护卫 | 单位存在标记，不叠层 | 离场失效 |

### 9.3 施加与到期

- 施加时先加后裁切；上限溢出无补偿。
- 脆化/虚弱/易伤的层数是剩余压力窗口数，倍率不按层重复相乘。
- 无压力的窗口也消耗计时层；任务阶段才新生成、当轮不能行动的任务不提前扣层。
- 阶段替换清除全部任务状态；新阶段不继承。
- 侵蚀自然结算后减 1；加速剖析下每次结算分别减 1。
- 诱发在玩家行动结束清除；重新施加不刷新已触发次数。
- 焦虑/拖延/困倦在对应结算后清；可再次被施加。

### 9.4 沈见章被动：复合反应

每回合最多一次。逐项执行卡牌正文的直接施加时，若目标在该项施加前已有另一种负面，本项又从 0 实际建立一种新负面，则记录候选。正文结束后，从仍存活、新状态仍存在且有增加容量的候选中，按任务生成顺序 → 正文效果顺序选一个，新状态额外 +1 层；实际成功才消耗机会。单纯加厚不触发；群体牌只强化一个目标；强化不生成新的施加事件、不递归。自动施毒、检索连锁、自然结算与伙伴不发动此被动。

## 10. 角色规则摘要

### 10.1 林序：连携与复用

- **连携**：同一玩家行动阶段，当前工作牌的前一张成功打出的牌主类型为策略时，当前工作牌属于连携；中间的能力/合作/场景会打断相邻关系。自动触发、回收、章节自动运行不算打出。回合开始清前牌记录；阶段转换不清。
- **被动·步骤复用**：每回合第一次符合连携、且前一策略是可回收的永久牌并仍在弃牌堆时，结算工作牌后可取回该策略。耗尽、能力区、正在结算或不在弃牌堆的牌不合格，不占用机会。满足条件时放弃取回也消耗机会；满手时不可完成取回，机会仍消耗。费用、基础费用与限次不变；0 费策略取回也不刷新已用限次。
- **准备效果**：下一张工作第一段 +N 合并为待用加值，合计上限 12；只作用第一段及主目标；回合结束清零。下一张重费工作减费同回合最多累计 1 点，成功打出才消耗。

### 10.2 许知微：论文与章节

**开题与牌名**：开题开启一篇论文；已有论文时开题不可用。每篇初始进度 0、引用 0、修正 0、已用牌名集合为空。开题自身与解题发表不参与记账。发表后可重新开题。

**记账**：已开题时，普通卡牌主效果完成后：本篇未用的牌名加入集合并进度 +1（上限 10）；已用牌名尝试引用 +1（上限 5）。进度满仍记录新名字；引用满不增加、不收费、不补抽。判定新/旧名在卡牌主效果前快照。章节手动重用可记账，自动运行不能。

**引用付款**：第 1、2 层免费；第 3、4、5 层分别额外支付 1、2、3 专注。付款发生在主效果后，使用当时剩余专注；付得起则扣费加层；付不起则不加层、改抽 1，并停止本次多层获取，不对剩余层重复补抽。

**完成度**：`C = clamp(进度×7 + 引用×6 + 完成度修正, 0, 100)`。修正可正可负，持续到本篇结束；不是直接完成量。

**唯一发表**：每战首次开题生成唯一临时 R3-T201。保留、2 费、不可升级/复制/耗尽/永久获取。后续开题把同一实例从抽牌堆或弃牌堆移回手牌；原本在手不再生成，满手入弃牌。未开题时不可用。

**发表结算**：按主效果前的 C 与当前任务集合快照：主目标 C+10，其他目标 floor(C/2)，C=100 时所有目标同段再 +20。先统一处理该批目标，再处理强制阶段；新阶段不吃旧论文余量。结算后清进度/引用/修正/已用名字/未用增幅，全部章节退回弃牌，关闭论文。即使此发表完成战斗，清理仍须完成。

**章节**：六章均为 P02 永久策略；论文区最多 3 个有序槽，同名最多一章；已有论文才能部署。首次从手牌打出先执行基础效果，再进入空槽；满槽预选替换，旧章退弃牌；同名已在场时，另一副本只执行基础与记账并正常弃牌。章节从部署后的下回合起，在专注恢复后、能力/场景与基础抽牌前按槽 1→3 自动运行，每章一次；输出自动选择最早生成的未完成任务，每章运行前重检。自动运行不算出牌、不记账、不触发首张策略/工作类能力。手动从论文区使用须正常付费，只结算基础与记账，章节留原槽。集中研讨开启额外窗口，每章每回合最多一次额外激活，且必须早于本回合部署已生效。

**增幅与换题**：增幅上限 5，跨回合保留，到发表/战后清；强化下一张卡正文第一个白名单数值（抽牌、放松、恢复精力、获得专注、直接增加进度、直接获得引用），一次消耗；不强化费用、完成量、发表、修正、负面、状态层数、章节自动或被动。换题可将一个已用名字重置为未用，成功才使修正 −1；不退进度/引用，不刷新同名次数。

### 10.3 沈见章：六种任务负面

| 状态 | 上限 | 作用与到期 |
|---|---:|---|
| 侵蚀 | 20 | 任务准备清旧屏障后，按当前层数产生持续完成量；每次自然结算后减 1 |
| 诱发 | 3 | 出牌开始时已有诱发的任务，在正文/被动/同事件能力后按开始层数产生完成量；每目标每回合默认与额外合计最多 4 次，行动结束清 |
| 脆化 | 3 | 新获得屏障 ×0.5 向下取整；压力窗口后减 1 |
| 乏力 | 4 | 每段压力先减层数，最低 0，再算虚弱；任务实例内保持 |
| 虚弱 | 3 | 每段压力 ×0.75 向下取整；压力窗口后减 1，全角色通用 |
| 易伤 | 3 | 工作牌直接完成量 ×1.25 向下取整；压力窗口后减 1，全角色通用，不增强自动输出 |

侵蚀窗口：任务准备清全部旧屏障后，快照当时存活任务，按生成顺序各自然结算一次；每次读取当时层数，完成后仍为同一任务才减 1；新阶段不补入快照。诱发窗口：每次成功出牌开始时快照已有诱发目标的实例与层数，结算后按目标生成顺序对仍存活的原实例各触发一次；刚建立的诱发不响应本次出牌。混合抑制的“种类数”只统计上述六种，不含焦虑或额外要求。

### 10.4 唐以宁：伙伴与内化

- **协同**：初始 0、上限 6、本战有效；必须消耗不足则拒绝，可选支付允许 0。
- **分工默契**：每回合首张合作牌完整结算后给 1 协同、2 放松；考试面不产生第二次合作事件。
- **伙伴**：最多 3 个，同名允许不同实例；召入满槽时预选撤下 1 个。主动撤回/被替换不触发额外收益、不返回合作牌。伙伴归零只是暂离，不是死亡。
- **行动**：每次协作执行支援 → 自动对最早未完成任务协作 → 自身失去 1 精力，归零暂离；任务完成先检查阶段/终局，已胜利不再扣续航。常规合作阶段每个当时存活伙伴行动一次；额外行动每实例每回合最多一次，同样扣续航。
- **独立作答**：不召伙伴、不做单位目标/满槽选择，合作与要求伙伴的策略改用完整考试面；保留主类型、费用、升级与耗尽。

## 18. 同时效应、优先级与边缘案例

### 18.1 排序

1. 当前效果的强制阶段。
2. 人物被动。
3. 同事件能力，按打出顺序。
4. 出牌开始快照的诱发。
5. 归零/暂离/阶段/终局检查。
6. 普通来源按稳定创建顺序、实例 ID、效果索引。

### 18.2 示例

- **护卫承接**：3 精力护卫受 5×2。首段 5 点打护卫，护卫暂离；第二段无其他护卫则打主角。
- **易伤与自动输出**：任务有易伤时，只有工作牌直接完成量 ×1.25；侵蚀、章节、伙伴自动协作不吃易伤。
- **发表与阶段**：发表完成当前阶段时，超额完成量不结转到下一阶段；清理论文与退章仍须完成。
- **同名与副本**：P02 升级前后同名；临时副本、公共牌与手动重用共用同名键，每回合只能成功打出一次。
- **侵蚀与阶段**：阶段切换清除侵蚀；新阶段不承接旧毒层，也不补入旧快照。
- **诱发与刚施加**：本牌刚施加的诱发不触发本牌；触发按出牌开始快照的旧实例与层数。
- **0 费循环**：必须有耗尽或每实例每回合限次；换区/回收不刷新限次。
- **满手取回**：手牌 10 张时林序不可完成取回，机会仍消耗；生成/取回入手牌满手改入弃牌。
- **待选保存**：待选期间保存返回 CHOICE_PENDING；非法/过期确认保留最近工作区与 revision。

### 18.3 失败优先

同一不可拆分效果中主角与最后任务一起归零，优先失败。普通恢复不能补救已经结束的失败。正式终局停止无关后续，但“发表关闭论文并退章”这类同一效果的收尾仍须完成。

## 20. 术语表

| 术语 | 含义 |
|---|---|
| 完成量 | 推进任务进度的数值；先扣屏障 |
| 未完成量 | 任务剩余 HP；归零完成 |
| 压力 | 对主角的威胁；先扣放松再扣精力 |
| 放松 | 每回合清零的临时防护 |
| 屏障 | 先于未完成量吸收完成量 |
| 连携 | 前一张成功打出的是策略时，当前工作牌获得连携 |
| 取回/回收 | 从弃牌堆拿回牌；不减费、不刷新限次 |
| 耗尽 | 本战不再洗回 |
| 保留 | 保护下一次轮末弃牌；仍占手牌容量 |
| 固有 | 开局先于普通洗牌抽取，但仍占基础抽牌 |
| 增幅 | 强化下一张卡首个白名单数值，一次消耗 |
| 换题 | 重置一个已用牌名并修正 −1 |
| 侵蚀/诱发/脆化/乏力/虚弱/易伤 | 六种任务负面，见 §9 |
| 焦虑/拖延/困倦 | 压缩专注/抽牌/工作第一段的临时负面 |
| 独立作答/固定考场 | 两种考试标签，分别转换合作/伙伴牌与场景 |
| 稳定边界 | 无待选、效果队列已完成、可保存的状态 |
