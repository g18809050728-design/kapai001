# 《交大四年：DDL战争》游戏规则书

文档版本：v2.0｜更新日期：2026-10-29｜状态：当前设计规则，待新版G0冻结；程序仍为v1。

## 0. 阅读与维护

本文维护基础时序、胜负与目标规则；人物机制、资源细节和获取数值见[角色设计](角色与专属卡池重设计_v2.md)，逐牌普通/升级/考试文本见[卡表](校园卡牌设计表_v2.md)，任务原型见[统一设计](交大四年_DDL战争_统一设计文档.md)。旧规则正文已归档，不与本文并列生效。

下列条款是设计依据，不代表程序已接入。`data/definitions/rulesets.json`已经存在，但仍为v1运行配置，不代表本文数值。固定编号延续既有语义；被移出的完整版本功能不占用新机制编号。R2规则编号引用角色设计§5，遇到未裁决项目不得从旧配置静默补入。

## 1. END：胜负

**[END-001]** 主角精力大于0，所有任务完成且强制下一阶段与连锁已经处理完毕，才胜利。阶段工作量归零先生成下一阶段，不立即判整场胜利。最后任务真正完成后停止无关后续效果，不继续扣单位续航、施压或扣DDL。

**[END-002]** 第一学期期末完成即本期终点，显示“第一学期完成”，不宣称完整四年通关。

**[END-003]** 主角精力归零，或完整轮末DDL归零仍有任务，判失败。同一不可拆分效果中主角与最后任务一起归零，优先失败。普通恢复不能补救已经结束的失败；本期没有救命饰品。

## 2. ENT：实体与实例

**[ENT-001/002]** 主角有精力/上限、专注、放松、人物资源、状态与触发记录；任务有未完成量/上限、屏障、阶段、意图和稳定顺序。永久卡、战斗卡、任务、单位与场景分别有实例ID，定义ID不代替实例ID。同名多张牌可存在，升级一张不修改其他实例。

牌区包括抽牌、手牌、弃牌、耗尽、结算及能力区，顺序分别记录。状态无统一槽位上限，按各自上限裁切。**[ENT-003]** 不启用卡牌点数、连点或融牌系统。

## 3. MAP：地图与跨节点状态

**[MAP-001]** 只能进入相邻下一层可达节点，不返回已完成节点。任务及所有必处理奖励完成后离开节点，返回地图由玩家点击下一站；商店主动离开。战斗中不进入其他节点。

**[MAP-002]** 第一学期6层、8个候选节点对象，每条路线经过6节点：普通→事件/普通→商店→普通/精英→休息→期末。最多二选一，保证不打精英的通路。

精力、生活费、永久牌组、节点记录跨节点保留。专注、放松、人物战内资源、状态、单位、场景、能力与临时牌战后清除。战斗结束不自动回满精力。

## 4. INI：初始化

**[INI-001]** 从永久12张及后续获得的永久牌创建本战实例，用battle随机流洗牌；带入当前/最大精力。专注和放松置0，人物资源置0，无初始单位、场景或饰品。建立首阶段任务、共享DDL、公开意图与考试标签，重置战斗记录后进入首次准备。

首次准备顺序：清旧放松→处理本时点负面→重置回合计数→计算自然专注→明确开战效果→准备触发→基础抽牌→明确抽后效果。P03在首次基础抽5之后生成唯一草稿；不另抽第二份起始手牌，满手入弃牌。后续准备没有开战段。

## 5. ENG：专注与支付

**[ENG-001]** 战斗初始专注0，自然专注3，上限10，下限0。准备先清剩余专注再计算本轮专注；敌方阶段不主动清空，但不能在该阶段主动出牌。

**[ENG-002]** 弃牌不自动获得专注，没有通用融牌操作。

**[ENG-003]** 专注不足、强制人物资源不足或目标不合法时不能出牌。主动支付精力绕过放松，支付后必须至少剩1；效果导致失去精力可归零。实际费用为max(0,基础费用+加费-减费)，预选取消与预检失败均不扣费、不耗随机。

资源的必须消耗、可选消耗和消耗全部按R2-RES-02/03；只在实际扣除正数时发消费事件，x取支付瞬间值。不能使用后续卡面获得的资源反付先前费用。

## 6. DRW：抽牌与手牌

**[DRW-001]** 逐张抽牌；手满即停止剩余抽取。抽牌堆空则把弃牌堆洗入；两堆都空则停止，耗尽、能力与结算区不洗回。“抽到时”效果先处理再抽下一张，不补欠抽牌。

**[DRW-002]** 基础抽5、手牌上限10。生成/取回等非抽牌加入手牌，手满改入弃牌；不算主动弃牌，不补专注。保留牌仍占容量。

## 7. PLR：玩家阶段

**[PLR-001/002]** 按初始化的准备顺序执行，再计算基础抽5及拖延/能力修正，最少0张。新能力从下回合起生效；准备触发在自然专注计算后、基础抽牌前。场景与能力的交叉优先序须在新版G0明确；不能让实现任意选择。

**[PLR-003]** 出牌阶段允许合法出牌、查看公开信息和结束回合；每张牌与待选结束后再进行下一操作。v2单位自动协作，不增加手动指定协作目标。

**[PLR-004]** 出牌结束进入合作阶段。开始时快照存活单位，按入场顺序逐个支援→协作完成→自身失去1精力，归零暂离。每单位每回合最多1次；出牌阶段召入的单位可当轮行动，合作阶段中新进入者不补入名单。默认目标为最早生成的未完成任务，每次行动前重检；若已胜利不再扣续航。

**[PLR-005]** 随后弃置非保留手牌。普通保留额度0；缓存命中、预留缓冲、保留备份、预约答辩和保留意见按卡文标记另一手牌至下回合，草稿自带保留。以固定旧手牌名单逐张弃置；触发中新获得的牌不加入旧名单。一次性保留标记在离手或该次弃牌通过后移除。

**[PLR-006]** “玩家行动结束”与“完整轮末”分别处理，不混用；弃牌后进入任务阶段，不额外回专注或扣DDL。

## 8. ENM：任务阶段与轮末

**[ENM-001]** 清任务旧屏障，处理准备触发。**[ENM-002]** 全部可行动任务按顺序先执行意图非压力部分：屏障、状态、负担等。**[ENM-003]** 再按顺序施加压力，多段逐段重检目标；不得把两类行动随意交错。

**[ENM-004]** 处理完整轮末效果与失败/阶段连锁，未结束才扣DDL并检查超时，然后公开下一意图，进入下次准备。任务阶段生成的任务当轮不行动；玩家阶段生成的新阶段可参与随后任务行动。

## 9. PLY：出牌与效果内选择

**[PLY-001]** 校验阶段/待选/实例限次→解析升级及考试有效面→收齐支付前目标与可选资源→计算和校验全部费用→整体支付→进入结算区并记录出牌→按正文执行与检查阶段→处理人物被动→按能力打出顺序处理同事件能力→进入弃牌/耗尽/能力区。触发顺序以R2-TRG-04为准；不得在能力队列中再次递归制造同类出牌事件。

支付后目标失效的部分跳过，其他合法效果继续，不因目标消失退款。正式终局立即停止无关后续。

**[PLY-002]** 抽后弃牌必须先抽再选，不允许看见结果后取消整牌。待选只接受匹配确认，不可另出牌或结束回合。错误确认保留最近已发布工作区；强制退出恢复最近成功写盘的稳定状态。待选工作区不持久化为半条效果存档。

## 10. DMG：完成、压力与护卫

**[DMG-001/002]** 完成量=max(0,floor((基础+适用固定加值-惩罚)×适用倍率))，先扣屏障，再减未完成量。压力先扣放松，再减精力，两者最低0。恢复按基础→加值→倍率→向下取整→精力上限裁切。

下一张工作牌的通用加值只作用第一段；群体牌只给所选主目标，其他目标按原值，除非牌文明示不同。工作增益不自动增强单位协作。多段逐段检查，群体同段同时应用再处理离场；新阶段不承接旧阶段超额完成量。

**[DMG-003/004]** 主动精力支付、直接失去精力与压力是不同变化。最早入场护卫承接默认单体压力；不改向全体或显式点名。每段重选，护卫暂离时伤害不溢出主角。例如3精力护卫受5×2：首段暂离，第二段无其他护卫则打主角。

## 11. BUF：资源与状态

**[BUF-001～004]** 每种状态须声明来源、对象、数值、叠加、时点、到期和驱散。不能只写“持续一回合”。获得后按上限裁切，溢出无补偿，已经结算的恢复/抽牌不倒扣。

**[BUF-005]** 当前设计使用：

| 名称 | 上限与作用 | 生命周期 |
|---|---|---|
| 编译 | 5；林序卡明文读取或消费 | 本战，初始0 |
| 数据 | 6；许知微卡明文读取或消费 | 本战，初始0 |
| 引用 | 6；沈见章卡明文读取或消费 | 本战，初始0 |
| 稿件 | 24；沈见章修订积累、草稿提交清空 | 本战，初始0 |
| 协同 | 6；唐以宁卡明文读取或消费 | 本战，初始0 |
| 焦虑 | 2；下次准备每层少1专注 | 生效后清除，可指定净化 |
| 拖延 | 3；下次基础抽牌每层少1 | 生效后清除，可指定净化 |
| 困倦 | 2；下次玩家行动工作第一段每层少1 | 对应行动结束清除，可指定净化 |
| 额外要求 | 3；任务每层压力+2 | 本战，仅明确效果可移除；首期遭遇是否使用待G0 |
| 护卫 | 存在标记，不叠层 | 单位离场失效 |

人物资源只能由所属角色机制读写，不通用换算。灵感、复习、心流及查重护盾不进入v2首期目录；旧运行数据仍为v1保留。能力同名不叠加，第二份不可打出，升级版也视为同名。

## 12. SUM：召入、换班与暂离

**[SUM-001/002]** 先解析考试面。普通面召入时最多3单位，满槽支付前选换班或取消。支付后整体移出旧实例、创建新实例并记录入场顺序，处理入场效果。同名单位可为不同实例；具体卡面可能使用已有单位效果，不假设所有合作牌都强制召入。

**[SUM-003]** 精力归零立即暂离，主动换班记录不同原因。离场停止未来行动和关联效果，不撤销已发支援，没有牺牲、死亡产牌或换班退费。

## 13. SCN：学习场景

**[SCN-001/002]** 当前只有R2-S01自习室。建立当轮不触发，随后两次准备各3放松，升级5，第二次后移除。重建替换旧实例，剩余次数作废，以新实例重计2；不叠加。固定考场改用卡面回忆效果，不建立场景，也不扣任何场景计次。

## 14. DSC：牌区与临时牌

**[DSC-001]** 只有卡面要求从手牌选择弃置才算主动弃牌；一次弃多张是一个事件，实际0张不触发。轮末弃牌、打出后入弃牌、满手入弃牌及耗尽均不触发首次主动弃牌收益。

**[DSC-002/003]** 战内改费、耗尽与临时移除不修改永久牌组；战后销毁本战实例，下战从永久牌重建。草稿R2-T31每战唯一、可循环弃牌，不能升级、复制、变化、耗尽或删除，战后移除，限制覆盖通用目标选择。

**[DSC-004]** 耗尽牌本战不再洗回；能力牌进入能力区，下回合起生效，本战保留，同名不叠加。

## 15. EFF：卡牌类型与稀有度

**[EFF-001/002]** 一张牌一个主类型：工作、策略、能力、合作或场景。稀有度为基础、普通、进阶、稀有；衍生是生命周期分类，不是奖励稀有度。流派标签用于理解构筑，不是额外的职业资格或伤害类型。完整升级文本与考试文本按卡表执行，不自行补算升级收益。

## 16. RES：检查与触发

**[RES-001]** 每项不可拆分效果后处理归零、暂离、强制阶段与连锁，再进入下一项；主角归零失败优先于最终胜利。普通同时来源沿稳定创建顺序、实例ID和效果索引排序，不用字典遍历或动画回调决定。

人物被动与能力的新事件窗口按R2-TRG-01～04；能力按打出顺序，不能追溯当回合。场景与能力同一准备窗口的总优先序、付款时资源触发与主效果之间的精确队列映射须新版G0冻结，不能据旧实现宣称已确定。

**[RES-002]** 实例限次不因弃牌、取回或改费重置，同名共享限次按牌文。阶段切换不重置回合计数。免费资源牌须有耗尽或限次，队列诊断中止属于错误处理，不是允许无限组合的玩法。

**[RES-003]** 重复测量、序列观测、仪器维护、复现实验按各自战斗实例成功打出次数判断第2次起的固定增强段，包含正在结算的这次；多次重用不继续累加，同ID副本独立。回收、阶段转换不清零，稳定保存须记录，战后清除。有限回收必须遵守卡文类型、费用与永久资格限制，不重置实例记录。

## 17. DDL：截止时间

**[DDL-001]** DDL为剩余可经历的完整轮末次数，全场共享。初始6允许第1～6个玩家行动阶段；第6轮末仍有任务则失败。轮末效果先于扣DDL，提前胜利不扣。当前卡池无延长或冻结DDL效果。

**[DDL-002]** 强制阶段先建立新任务实例，旧屏障/状态清除；主角资源、牌区、单位、场景、回合与DDL均不重置，旧目标多段剩余部分跳过。

## 18. EXM：考试面

**[EXM-001]** 提前公开限时、独立作答与固定考场标签，不能仅因“首领”名称推断限制。

**[EXM-002]** 独立作答替换七张合作牌及轮换排班、轮值支援的正文，固定考场替换公共场景正文，共10个逐牌双面，完整普通/升级文本见卡表。保留费用、主类型、升级次数与对应耗尽规则，替换先于目标、槽位和费用校验；不叠加普通面，不产生单位选择或入场效果。

示例：P04本回合首次打普通室友搭把手，费用1，考试面完成5、放松3；被动再加1协同、2放松，总放松5，不召入单位。公共自习室的固定考场面为抽1、放松5，升级放松8，并耗尽。

## 19. RUN：开局与人物

**[RUN-001]** 四人均为新版首期目标，永久起手12张、正常精力72/72、生活费60。公共构成为R2-C-01×4、R2-C-02×4、R2-C-03×1、R2-C-04×1，两张人物起手按角色设计。P03首次抽后额外草稿不计永久数量；本期无初始饰品。

**[RUN-002]** 首期仅正常难度，其他难度不继承旧倍率；同人物三流派自由混搭，任何永久卡来源都不能给予其他人物专属牌。

## 20. ECO：获取与交易

**[ECO-001]** 成本、余额、目标、资格和下限全部校验后整体提交，取消/失败不扣费、不发牌、不推进随机。已售库存不补、已领取奖励与已完成选项不重复处理，重绘与恢复不重抽冻结候选。

**[ECO-002]** 普通/精英均为3个不同ID候选，可选1或跳过；先75%本人物/25%公共，再按普通战70/25/5、精英35/50/15选择普通/进阶/稀有。基础牌与草稿排除，每人可见46种奖励牌。空池与重复处理完整规则见角色设计§8，不回退其他人物卡。第一学期终点不再给构筑奖励。

**[ECO-003]** 商店3专属1公共，单次ID不重复，稀有度60/30/10，售价45/75/120，入店冻结。不出售基础牌、衍生牌或v1饰品。调整学习计划事件变化不得删至少于8张；通用删除下限、商店删牌价格/次数及其他服务经济须新版G0统一冻结，未定时不执行该服务。

**[ECO-004]** 饰品装备与掉落不属于v2首期，无赠饰品或空饰品池折钱规则。

## 21. GRW：升级与成长

**[GRW-001]** 每张永久卡最多升级1次；衍生牌不能选。训练合作等同升级该合作牌普通/考试双面，不新增永久单位属性。休息恢复、负担处理、服务费用与具体选项待新版G0；不沿用旧百分比作为定案。

**[GRW-002/003]** 第一学期直接总结，后续学期、履历与毕业解锁均为未来范围。本轮不修改旧存档或解锁进度。
