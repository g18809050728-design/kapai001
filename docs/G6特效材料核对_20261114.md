## 3. AI逐项结论

| 材料 | 本批状态 | 下一次核对点 |
|---|---|---|
| 笔锋轨迹 | 保留比较 | 方向/明暗可读；减弱直硬闪电感，核对手部来源 |
| 轻命中 | 保留比较 | 局部亮核与碎片清楚；最终尺度及真实作用点 |
| 重命中 | 保留比较 | 与轻击有粗细和体量差；控制亮区遮挡 |
| 压力轨迹 | 语义返工 | 更像火焰法术，校园压力意象不足 |
| 防护 | 保留比较 | 开口弧与攻击有区别；前置遮挡问题必须收敛 |
| 抵挡 | 保留比较 | 撞击可辨；仅吸收与真实精力减少分开 |
| 破防 | 保留比较 | 碎裂可辨；冰晶形态与校园题材关系待核对 |
| 恢复 | 语义返工 | 尖锐旋纹像攻击，缺少温和聚合与流向 |
| 专注变化 | 语义返工 | 像向下爆裂，获得与支付需分别明确 |
| 伙伴入场 | 保留比较 | 纸条和地面弧有题材联系；不代表已完成召入 |
| 状态附着 | 语义返工 | 像斩击，持续状态不明，深底轮廓偏弱 |
| 阶段冲击 | 语义返工 | 偏爆炸，需结合具体阶段实体/剪影 |

上述均为AI观察，所有`selected=false`，人工接受与许可待核对；完整原话、实际查看文件与hash见[visual-review.json](../artifacts/verification/vfx-reference-20261114/visual-review.json)。孤立材料更接近参考中的局部作用与轮廓区分，但没有据此宣布已达到二代手感。
