## 实现与实际覆盖

| 行为 | 实现 | 实际覆盖 |
|---|---|---|
| 逐张真实抽牌 | [BattlePresentation](../src/ui/battle/battle_presentation.gd) 在队列启动前隐藏全部待抽牌，逐张移动实际手牌控件，落位后恢复操作；紧凑布局临时保留容器槽位 | 两尺寸首帧隐藏、实际控件身份、单张移动、不透明卡面、逐张落位、飞行中不可选、重复事件不重隐藏 |
| 原位直接弃牌 | 保留上一视图的真实手牌控件；出牌原位提示，结算或主动弃置直接进入目标堆 | 生产 play_card/end_turn，保留原控件身份，起点与原卡位中心一致，无中央中转 |
| 统一四倍速度 | [BattleScreen](../src/ui/battle_screen.gd) 的 effect_speed() = 页面倍速 ×4，供[队列](../src/ui/battle/battle_event_animator.gd)、飞牌、血条、闪光、浮字和切页清理使用 | 1× 下飞牌/队列倍率、任务条 before→after 中间值；抽牌 0.125 秒、弃牌 0.115 秒、血条 0.225 秒、提示约 0.263 秒；队列分别 0.14/0.13/0.28 秒，页面倍速继续叠加 |
| 清理及规则边界 | 关闭动画、重绘、尺寸变化和下一命令恢复手牌与临时槽位；最后事件持续结束后才报告完成 | 动画关闭、跨标准/紧凑布局尺寸切换、最后一击奖励切页与自动释放；完整状态/revision/RNG 对照 |

领域视图仍由 GameSession 即时发布，暂存仅属 UI。同步规则路由 fixture 在发下一命令前显式跳过演出，没有放宽规则断言。[时序套件](../tests/suites/test_ui_battle_map_feedback.gd) 为百毫秒动作暂停场景并按实际 Tween 时长推进截图采样，避免首次纹理上传和截图耗时吞掉中间帧；命令仍由真实会话执行，切页清理另有正常时钟覆盖。
