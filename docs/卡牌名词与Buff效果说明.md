# 卡牌名词与 Buff 效果说明

整理日期：2026-10-16。适用范围：当前第一学期版本，并补充标明完整设计中尚未进入当前牌池的状态。

本文用于解释卡面，不另行制定规则。通用玩法以[游戏规则书](交大四年_DDL战争_游戏规则书.md)为准，内容专属数值以[统一设计文档](交大四年_DDL战争_统一设计文档.md)为准，当前生产内容可对照[卡牌数据](../data/definitions/cards.json)、[状态定义](../data/definitions/statuses.json)和[规则数值](../data/definitions/rulesets.json)。

最常用的对应关系是：**精力相当于生命值，专注是出牌资源，完成量是对任务的输出，放松用于抵挡压力。**

## 1. 基础资源与战斗名词

| 名词 | 含义与例子 |
|---|---|
| **精力** | 主角还能坚持多久，相当于生命值。受到压力后可能减少，降到 0 且没有明确的救命替代时，本局失败。战斗结束不会自动回满。 |
| **最大精力** | 精力能够恢复到的上限。例如当前精力 60、最大精力 72，恢复 20 后最多为 72。 |
| **专注／费用** | 打牌使用的资源。“1 费”通常表示支付 1 点专注。每次玩家准备阶段，剩余专注清零，再按基础 3 及其他修正计算本回合专注；上回合剩余值不累加，持有上限为 10。 |
| **完成量／完成 X** | 对任务推进多少工作，相当于攻击输出。“完成 6”先抵消任务屏障，剩余部分减少未完成量。 |
| **未完成量** | 任务还剩多少工作，相当于敌人的生命值。降到 0 表示当前任务或当前阶段完成；多阶段首领可能继续进入下一阶段。 |
| **压力** | 任务对我方的攻击。通常先扣放松，再扣精力。 |
| **放松** | 我方临时防护。例如受到 8 压力、有 5 放松，则消耗 5 放松，损失 3 精力。主角和合作单位的旧放松在下次玩家准备阶段清零。 |
| **屏障** | 任务的临时防护。例如任务有 4 屏障，你打出“完成 6”，实际只减少 2 未完成量。旧屏障在任务下次准备阶段清零。 |
| **恢复精力** | 补充精力，但不能超过最大精力；可能受场景等恢复修正影响。 |
| **支付精力** | 用精力作为主动出牌代价，放松不能抵扣。例如《熬夜》支付 4 精力，需要支付后至少剩 1 点才能使用；明确免除代价的效果先计入校验。 |
| **失去精力** | 效果直接扣除精力，也绕过放松；与主动支付不同，它可能使精力降到 0。 |
| **DDL** | 截止时间，表示还能经历的完整轮末次数，全场任务共享。每轮末减 1；归零时仍有任务就失败。卡牌上的“DDL≤3”包含剩 3、2、1 轮。 |
| **意图** | 任务接下来准备做什么，例如施加压力、增加屏障或施加负面状态。 |
| **生活费／金钱** | 购买卡牌、饰品、餐食和商店删牌等使用的局内货币，跨节点保留。 |

### 一轮与一场战斗的区别

一轮通常依次经历：**玩家准备 → 抽牌 → 玩家出牌 → 合作单位行动 → 弃牌 → 任务准备与行动 → 轮末。**

“本回合／本轮”只覆盖相应的一轮或明确时点；“本战”覆盖整场战斗。多阶段首领切换阶段仍属于同一场战斗，专注、牌堆和总 DDL 等不会因此重置，旧阶段的超额完成量不结转到新阶段。

## 2. 卡牌类型与品质

| 类型或标记 | 含义 |
|---|---|
| **工作牌／作业牌** | 推进任务的牌，例如《写》《细心写》。规则书称“工作牌”，当前界面称“作业牌”，两者是同一种类型。 |
| **策略牌** | 提供放松、抽牌、恢复、专注、净化等效果，例如《暂时休息》《寻找思路》。 |
| **合作牌** | 召入同学协助，例如《室友搭把手》。遇到“独立作答”限制时改用备考面。 |
| **场景牌** | 建立持续生效的学习场景，例如《找到自习室》。遇到“固定考场”限制时改用回忆面。 |
| **能力牌** | 使用后提供本场持续效果，牌本身退出抽牌循环。同名持续能力默认不叠加。完整设计中有，目前首学期牌池未包含。 |
| **白／蓝／紫／金** | 品质或稀有度分类，不代表费用，也不直接决定效果数值。 |
| **基础** | 卡牌的获取或分类标签，例如初始牌中的《写》《暂时休息》。不是额外效果。 |
| **特殊／临时** | 特殊牌不属于普通正式牌分类；临时牌只存在于本场，不加入永久牌组。当前《分心消息》同时带有这两种标签。 |
| **升级** | 增强永久牌的指定效果或降低代价，具体变化看升级预览。当前最多升级一次；升级栏只写变化项，不一定重述全部卡面。 |

## 3. 卡面操作与限制词

| 词语 | 具体意思 |
|---|---|
| **抽 N 张** | 从抽牌堆拿 N 张牌。抽牌堆空时，将弃牌堆洗入后继续抽；手牌上限为 10，手满时停止抽牌。 |
| **弃 N 张** | 从手牌中选择牌放进弃牌堆，之后仍可能再次抽到。普通弃牌不会恢复专注。 |
| **弃至多 N 张** | 可以少弃，也可以不弃。例如《转换思路》弃 0／1／2 张，分别抽 1／2／3 张。 |
| **取回** | 将指定牌直接从弃牌堆拿回手牌，例如《复盘》。不等于免费打出，使用取回的牌仍要支付费用。 |
| **保留** | 让选中的手牌免于本次回合结束弃置，留到下回合。《版本控制》保留的是使用时选中的另一张手牌，只有这一次保留效果，仍占手牌空间。 |
| **耗尽／界面中的“消耗”** | 使用后进入耗尽区，本场不再洗回抽牌堆。永久牌组里的这张牌还在，下场战斗恢复。 |
| **消耗 N 层状态** | 扣掉状态层数，与“卡牌耗尽”是两件事。强制消耗的层数不足就不能出牌；“若有则消耗”的附加效果可以跳过。 |
| **净化／移除负面状态** | 未指定种类时，从焦虑、拖延或困倦中选一种清除。例如“净化 2 层”是选择一种负面，最多移除其 2 层，并非三种各减 2 层。没有负面时仍可执行卡牌的其他效果。 |
| **层数** | 状态数量，不直接表示持续回合数。例如“2 层焦虑”表示下一次少 2 专注，不是持续两回合。 |
| **第一段** | 一张牌第一次产生的完成量。若一张牌有多段输出，只作用于第一段的加成不会重复加到每段。 |
| **同段额外＋X** | 与原输出合并后结算。例如“完成 14，同段＋4”，就是一次完成 18。 |
| **下一张工作牌** | 从当前时点往后，下一张实际打出的工作牌；中间使用策略牌不会消耗这个机会。 |
| **本回合打过某牌** | 要求此前在同一回合已经成功打出指定牌。例如《细心写》的条件是本回合先打过《查资料》。 |
| **每实例每回合限一次** | 每一张独立的牌分别计数。两张《编译》可以各打一次；同一张取回后，本回合不能再打。 |
| **每战限 N 次** | 整场战斗累计计数。若某场景的次数按定义在本战累计，换走再换回也不会刷新次数。 |
| **费用－1，最低 0** | 减少实际支付的专注，不能减成负数，也不会因为费用低于 0 而倒赚专注。 |
| **不可打出** | 不能主动使用。《分心消息》主要占用抽牌和手牌位置，回合末正常弃置，没有额外被动扣费。 |
| **永久牌组** | 当前局跨战斗保存的牌组。战内耗尽不会删除永久卡；奖励、商店、事件和休息等战斗外操作可以改变它。 |

注意：“打出后进入弃牌堆”不算“弃牌”事件。只有从手牌区弃置到弃牌堆，才会触发明确写着“弃牌时”的效果。

## 4. 当前版本的 7 种状态

Buff 通常指有利状态，Debuff 指不利状态。下面同时列出玩家增益、玩家负面及任务自身的强化。普通战斗状态不跨战保留。

| 状态 | 持有者与效果 | 上限与结束时间 |
|---|---|---|
| **灵感** | 玩家增益。每层使下一张工作牌第一段完成量＋2。例如 2 层灵感，让基础“完成 6”变成“完成 10”。 | 上限 **5 层**；用于下一张工作牌时全部消耗，未使用则本轮末清除。 |
| **编译** | 玩家的代码路线资源。只有卡牌明确读取或消耗时才产生收益，本身没有通用输出加成。例如《打印Hello》只要编译≥1，就同段额外＋3。 | 上限 **5 层**；跨回合保留，本战结束清除，明确消耗它的效果会扣层。 |
| **焦虑** | 玩家负面。下次玩家准备阶段，每层使本回合专注少 1。无其他修正时，2 层焦虑让基础 3 专注变成 1。 | 上限 **2 层**；生效后清除，也可提前净化。 |
| **拖延** | 玩家负面。下次基础抽牌时，每层少抽 1 张。例如 2 层让基础抽 5 变成抽 3；不减少卡牌正文的额外抽牌。 | 上限 **3 层**；影响一次基础抽牌后清除，可净化。 |
| **困倦** | 玩家负面。对应的玩家出牌阶段中，每张工作牌第一段每层少完成 1。例如 2 层困倦让基础“完成 6”变成“完成 4”。 | 上限 **2 层**；该次玩家出牌阶段结束时清除，可净化。不会像灵感一样用一张牌就耗掉。 |
| **护卫** | 合作单位的保护标记。替主角承接默认指向主角的单体压力。多个护卫优先由最早入场者承接；不拦截全体压力或明确点名其他对象的压力。 | 不叠层；单位离场后失效。某段压力使护卫暂离时，该段多余压力不溢出到主角；下一段重新确定目标。 |
| **额外要求** | 任务的强化状态。每层让该任务施加的压力＋2。例如基础压力 6，有 2 层则变成 10；多段压力每段都会增加。 | 上限 **3 层**；不会每回合自然减少，可用《检查卷面》等指定效果移除。任务离场或换成新阶段时清除旧状态。 |

### 灵感与编译的区别

**灵感直接增强下一张工作牌，并一次用完；编译是供特定卡牌读取或消耗的资源。**

对当前《打印Hello》来说，1 层和 5 层编译都只提供同样的＋3，因为它检查的是“有没有至少 1 层”；使用《打印Hello》也不会扣除编译。

### 焦虑、拖延与困倦的区别

- **焦虑**限制下次可用于出牌的专注。
- **拖延**限制下次基础抽牌的数量。
- **困倦**降低对应行动阶段中每张工作牌的第一段完成量。

它们都能被净化，但触发时点不同。如果焦虑已在准备阶段生效并清除，之后净化不会返还已经少获得的专注。

## 5. 合作单位、场景与考试限制

| 名词 | 含义 |
|---|---|
| **召入** | 将合作单位放进场上。最多同时存在 3 个单位；满场时需要选择换班或取消。 |
| **协作／合作值** | 单位每次行动提供的完成量。例如合作值 6，通常表示每次协作完成 6；任务屏障仍会吸收。工作牌专属加成不会自动增强协作。 |
| **支援** | 单位的额外能力，通常先支援，再协作。按规则，协作后单位自身失去 1 精力作为续航消耗；若此前已完成最后任务并获胜，则停止后续步骤。 |
| **暂离** | 单位精力归零后离场，停止后续行动，关联持续效果停止。 |
| **换班** | 主动让旧单位离场，换入新单位，不会退还之前召入的费用，也不等同于受压暂离。 |
| **建立场景** | 启用一个持续环境；场上只能有一个，新场景替换旧场景，同名场景也不叠加。场景牌耗尽不代表场景消失。 |
| **准备阶段触发** | 从建立后的下一个玩家准备阶段开始触发，不会在建立场景的当回合补发。持续减费等修正可以立即生效。 |
| **独立作答／备考面** | 考试限制：合作牌正文改为获得 5 放松，升级后 7，不再召入单位；费用与耗尽标记保留。 |
| **固定考场／回忆面** | 考试限制：场景牌正文改为抽 1、获得 2 放松，升级后放松为 4，不再建立场景；费用与耗尽标记保留。 |

### 当前四个合作单位

| 单位与召入卡 | 基础精力／合作值 | 支援或特点 |
|---|---|---|
| **F01 热心室友**，《室友搭把手》召入 | 10／2 | 护卫，承接默认单体压力。 |
| **F02 忙碌学霸**，《请教学霸》召入 | 4／6 | 没有额外支援，协作输出高、驻场精力较少。 |
| **F03 耐心助教**，《请教助教》召入 | 6／1 | 规则规定每次行动移除主角 1 层焦虑；无焦虑时改给主角 2 放松。 |
| **F04 可靠组长**，《组队分工》召入 | 12／2 | 护卫，每次行动先给自身 2 放松。 |

单位数值为未升级召入时的基础值。F03 焦虑层数处理等生产行为仍有已登记缺口，详见[G2 执行记录](G2内容与基础状态执行记录.md)和[G4 执行记录](G4局流程执行记录.md)；本表解释定义中的规则，不作为缺口已修复的证明。

### 当前三个场景

| 场景与建立卡 | 效果 |
|---|---|
| **L01 自家书桌**，《回到自家》建立 | 从下次玩家准备开始，每次恢复主角 2 精力，每场战斗最多触发 3 次。换走再换回不刷新本战次数。 |
| **L02 宿舍**，《宿舍自习》建立 | 每次玩家准备，等概率获得一项：恢复 1 精力、获得 1 专注、抽 1 张、对行动顺序最前任务完成 3。下一次结果会预告。 |
| **L03 自习室**，《找到自习室》建立 | 每回合第一张工作牌的专注费用－1，最低为 0。这是持续减费，建立后可即时适用；本回合若已经打过工作牌，不会重新获得“首张”机会。 |

## 6. 完整设计中的其他状态

以下状态已在规则书和统一设计中定义，但**尚未进入当前第一学期生产状态清单**，不能据此认定当前版本可获得。

| 状态 | 设计效果与持续时间 |
|---|---|
| **实验数据** | 上限 5 层，实验牌根据正文读取或消耗，不自带通用输出加成。本战保留。 |
| **引用** | 上限 5 层，论文牌根据正文读取或消耗，不自带通用输出加成。本战保留。 |
| **复习** | 上限 5 层，复习牌根据正文读取或消耗，不跨战积累。 |
| **心流** | 上限 5 层，每层让工作牌第一段完成量＋1；只要至少有 1 层，每回合基础专注额外＋1。5 层也只额外＋1 专注。本战保留。 |
| **查重护盾** | 任务的特殊屏障，可以被完成量消耗或被指定牌削减，任务准备时清零。它不是“查重率”百分比；与普通屏障共存时的普通输出扣减顺序仍待 Q-007 裁决。 |

## 7. 三个读牌示例

以下只按所列牌和状态计算，不计人物、饰品、场景或其他修正。

### 示例一：《查资料》接《写》

1. 使用未升级《查资料》，获得 2 灵感并抽 1 张。
2. 接着使用未升级《写》，基础完成量为 6。
3. 灵感提供 2×2＝4，最终完成量为 **10**，灵感清空。
4. 若任务有 3 屏障，则消耗 3 屏障，减少 **7 未完成量**。

### 示例二：有编译时使用《打印Hello》

1. 你持有至少 1 层编译。
2. 未升级《打印Hello》基础完成量为 5，满足条件后同段额外＋3。
3. 最终完成量为 **8**，编译层数不变。只有明确写着消耗编译的牌才会扣层。

### 示例三：《查资料》接《细心写》

1. 本回合先使用未升级《查资料》，获得 2 灵感。
2. 接着使用未升级《细心写》，基础完成量为 14。
3. “本回合打过《查资料》”提供＋4，2 层灵感再提供＋4。
4. 合并为一次 **22 完成量**，随后灵感清空。如果中间已经用其他工作牌消耗了灵感，则这里只剩条件加成，完成量为 18。
