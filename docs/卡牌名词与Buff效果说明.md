# 卡牌名词与Buff效果说明

版本：v3.1｜日期：2026-10-30｜适用：新版文档设计，程序未接入。

## 1. 基础数字

| 名词 | 玩家含义 |
|---|---|
| 精力 | 跨节点健康；压力10、放松6则少4精力，战后不自动回满 |
| 专注 | 回合出牌成本，自然3；下轮先清剩余再计算，上限10 |
| 放松 | 当轮压力防护，下次准备清旧值 |
| 完成量/屏障 | 完成量先扣任务屏障，再减少未完成量 |
| DDL | 剩余完整轮末次数；归零仍有任务即失败，多阶段共享 |

|---|---|---|

## 3. 论文用语

开题后，首次使用某牌名使进度+1（最多10），重复名尝试引用+1（最多5）；同名每回合最多打一次，复制和升级不改名字。第3/4/5引用分别额外付1/2/3专注，使用主体结算后的余额；不足不加该层改抽1，多层获取遇不足停止。

完成度=夹在0～100的“进度×7＋引用×6＋修正”。解题发表主目标完成C+10，其他floor(C/2)，C=100时所有目标再+20。发表清本篇记录、退全部章节，关闭论文；之后可合法重新开题，仍使用同一个发表实例。

论文区最多3章，下回合开始按槽序自动提供抽牌、防护或完成量；自动不是出牌、不记账。手动重用正常付费，只基础效果与记账。固定考场不禁止章节。

增幅上限5，只强化下一张卡正文首个白名单正向数值：抽牌、放松、精力恢复、专注、直接进度/引用；不强化完成量、修正、发表、负面或自动/被动。换题移除一个已用名，成功才修正-1，不刷新本回合同名限次。

## 4. 状态与结算

| 状态 | 上限与效果 | 到期 |
|---|---|---|
| 侵蚀 | 20；任务准备清旧屏障后按当前层数产生持续完成量 | 每次自然结算后减1；提前验算不减 |
| 诱发 | 3；后续成功出牌按开始时层数产生状态完成量 | 行动结束清；每目标每回合默认与额外合计最多4次 |
| 脆化 | 3；新获屏障×0.5向下取整，已有屏障不变 | 该任务压力窗口后减1 |
| 乏力 | 4；每段压力先减层数至最低0，再算虚弱 | 任务实例内保持 |
| 虚弱 | 3；任务压力逐段×0.75向下取整，全角色通用 | 该任务压力窗口后减1 |
| 易伤 | 3；工作牌直接完成量×1.25向下取整，全角色通用 | 该任务压力窗口后减1；不增强伙伴、章节自动或状态 |
| 焦虑 | 2；下次自然专注每层少1 | 对应准备生效后清 |
| 拖延 | 3；下次基础抽牌每层少1 | 对应抽牌生效后清 |
| 困倦 | 2；下次玩家行动工作首段每层少1 | 对应行动结束清 |
| 额外要求 | 3；任务压力每层+2 | 本战，仅明确移除，首期投放待G0 |
| 护卫 | 承接默认单体压力，不拦全体/点名 | 伙伴离场失效，单段过量不溢出 |

六负面是任务状态，引用是P02论文记录，协同是P04战内资源，不混用。状态完成量仍过屏障。三种计时负面无压力也消耗窗口，新生本轮不行动任务不扣；换阶段全部清除。复合反应只强化正文新建立的不同状态，每回合一次，详细快照与批次规则见角色设计§5。

## 5. 牌区和操作

主动弃牌只指卡文选择手牌弃置；轮末、满手转弃牌与耗尽不算。耗尽是本战不再循环，不是删永久牌。回收只取合法永久牌，不减费、不刷新限次；满手时牌仍在弃牌堆。

能力下回合生效、同名不叠。临时保留保护下一次轮末弃牌，离手即清；发表自带保留。每张永久卡最多升级一次，衍生不升级。必须消费不足则不能打，可选0不触发消费收益，消费全部x先快照再清空。直接失精力可导致失败，不能与“支付后至少留1”混淆。

## 6. 伙伴、场景、考试与获取

最多3伙伴：复习搭档3精力/2协作、资料同学4/1且每次行动前主角放松2、项目搭档5/3且护卫。每次支援→协作最早未完成任务→自身失1精力；正常每回合一次，指定额外行动每实例最多一次。短驻场按自身实例上限恢复，主动撤回不退卡。

最多1场景：自习室后两次准备放松3/5；专题自习后两次抽1，升级再放松3。14种完整考试面保留费用和类型，先替换再校验；考试合作仍触发被动、不召同学。论文区与伙伴、场景分开。

永久奖励统一当前人物+公共，排除基础两种和所有衍生/临时实例，每人50种资格，单次仍为3候选。两种论文衍生是解题发表、旁听笔记；章节复印使用源牌名，不新增卡种。完整共同时间顺序及未决项见[规则书](交大四年_DDL战争_游戏规则书.md)。
