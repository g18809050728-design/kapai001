# 卡牌名词与Buff效果说明

版本：v2.0｜日期：2026-10-29｜适用：新版文档设计，程序尚未接入。

## 1. 先看懂四个基础数字

| 名词 | 含义与例子 |
|---|---|
| 精力 | 跨节点的健康；压力10、放松6，则精力少4，战后不会自动回满 |
| 专注 | 每回合投入时间；自然3，用来支付卡费；下轮先清剩余再计算 |
| 放松 | 当轮压力防护；先扣放松再扣精力，下次准备清旧值 |
| DDL | 剩余完整轮末次数；归零仍有任务即失败，多阶段共享 |
| 完成量 | 减少任务未完成量，先过屏障；不是伤害同学 |
| 屏障 | 任务的临时阻碍，在任务准备清除；不同于主角放松 |

| 人物 | 资源 | 怎么理解 |

全部初始0、战后清零，超上限裁切，不跨人物换算。不是每人同时管理五种资源。具体被动与卡面以[角色设计](角色与专属卡池重设计_v2.md)和[卡表](校园卡牌设计表_v2.md)为准。

## 3. 关键词与容易混淆的动作

| 词 | 精确含义 |
|---|---|
| 主动弃牌 | 卡面要求选择手牌弃置；一次弃多张是一次事件；轮末弃牌、满手入弃牌与耗尽不算 |
| 耗尽 | 本战离开循环，永久卡下一战恢复；不等于删除永久牌 |
| 保留 | 该次轮末不自动弃，仍占手牌；临时保留与自带保留按卡文 |
| 能力 | 打出后进入能力区，下回合起生效；同名不叠加，第二份不可打出 |
| 每实例限次 | 同一张牌取回也不刷新，不按手牌位置另计 |
| 必须消耗 | 不足即不能出牌 |
| 可消耗0至n | 玩家选合法整数，选0不触发资源消费收益 |
| 消耗全部x | 允许0，x取支付瞬间存量，先清资源再算正文 |
| 升级 | 每张永久卡最多1次，看完整升级文本；不升级临时草稿 |

例：许知微用整理书包抽2弃1，本轮首次主动弃牌后获得1数据；轮末丢掉其他牌不会再次触发。沈见章读文献得引用，列提纲可消耗1引用增稿件，首次实际消费再得3放松。

## 4. 负面状态与护卫

| 名称 | 上限/效果 | 结束时点 |
|---|---|---|
| 焦虑 | 2；每层下次少1专注 | 下次准备计算后清除 |
| 拖延 | 3；每层下次少抽1 | 下次基础抽牌生效后清除 |
| 困倦 | 2；每层下次工作第一段少1 | 对应玩家行动结束 |
| 额外要求 | 3；任务每层压力+2 | 本战，明确效果可移除；首期投放待G0 |
| 护卫 | 不叠层；承接默认单体压力 | 单位离场 |

零点校准只移除明文指定的焦虑，不等于清除所有负面。护卫不拦全体或点名压力，伤害不溢出主角。旧灵感、复习、心流与查重护盾不作为新版首期关键词。

## 5. 合作、场景与考试

伙伴为复习搭档R2-U01、资料同学R2-U02、项目搭档R2-U03；最多3个。按入场顺序自动对最早未完成任务协作，行动为支援→协作→失去1自身精力，归零暂离。满槽召入先选换班或取消，同学不被表现为牺牲品。

场景只有R2-S01自习室：随后2次准备各3放松，升级5，第二次后移除；重建替换并重计2次。地图自习室背景不自动提供此效果。

独立作答用七张合作牌及轮换排班、轮值支援各自的考试面；固定考场用公共场景的回忆面，共10个双面ID，保留费用与类型，普通正文不再执行。例：室友搭把手考试面完成5、放松3，P04首次合作再得协同1、放松2；不会召人。预览必须展示当前考试面，具体升级见卡表。

## 6. 唯一草稿与卡池归属

P03首次基础抽5后获得唯一R2-T31：2费、保留，消耗全部稿件m完成8+m，正常入弃牌可再抽到。它不能升级、复制、变化、耗尽或删除，战后移除，不计永久起手12张。草稿是交付载体，稿件是人物资源，两者不互换。

选人锁定专属卡资格，同人物三流派可混搭；公共8张为共通工具。基础2种不进奖励，因此每人可见40专属+6公共=46种奖励牌。完整基础规则与未决项见[规则书](交大四年_DDL战争_游戏规则书.md)；本文用于解释，不另造规则。
