# UI、音效与地图设计总结

更新：2026-11-04｜状态：四学年原型已接入，正式美术/音乐、平衡和 G8 待完成。

当前默认 `campus_four_year` 使用四张连续学年地图，不分上下学期。[四图方案](四大地图复杂化设计方案.md)维护拓扑，[奖励文档](饰品奖励与学期结束大奖励设计_v0.md)维护 8 次饰品与 4 次学年大奖励。旧入口保留第一学期切片，范围例外见[根计划 §0.6](../实施计划与验收基线.md)。

## 1. 已实现的 UI

沿用现有米白纸感资源、深青正文与金色强调，优先展示真实效果和资源成本。

FY-UX-001～015 已按 A–D 实施，完整规则/UI 回归与两尺寸 56 张实渲通过；代码映射、三档字号、截图及人工验收边界见[UI 改善实施记录](UI体验改善实施记录_20261104.md)。

| 页面/区域 | 当前行为 |
|---|---|
| 配置 | 新局只用四学年入口，聚焦四角色之一、按需查看起手、展开种子；固定开始/返回，旧局替换仍需明确确认 |
| 地图 | 按真实后继绘制路线画布，区分当前/可达/完成；随机遭遇明确标注，预选后进入，导航与定位固定 |
| 服务 | 图书馆/导师升级移除，实验室金钱与精力代价，社团/实习/剧情；一次一选可跳过，由领域预览控制可用性 |
| 饰品 | 卡牌对象与分层详情，已有三槽直接比较，明确替换对象/折算/跳过，确认一次生效 |
| 大奖励 | 高阶牌、升级移除、资源三类别首屏可见，进入类别后选对象；冻结候选可保存继续 |
| 方向/去向 | 大二方向、大四去向；低毕设回退延期答辩 |
| 总结 | 四年完成后毕业总结，失败/放弃与持久化状态分开 |
| 设置 | 自动保存、五路音量/静音、100/125/150% 字号、减少动态与演出速度；固定应用/返回，诊断按需展开 |

所有写命令只经 GameSession。显示和预览不改变规则、RNG、revision；保存失败只重试保存，不重发奖励。

## 2. 战斗信息与操作

标准窗口保留扇形手牌与拖拽；小窗口/大字号使用原生紧凑战斗，点击/数字键选牌，目标与手牌分区滚动、操作固定。任务状态和层数直接显示，资源摘要可打开人物专属详情；论文/章节/协同、前牌类型、能力数量及实际触发机会均为只读字段。完整可搜索手册仍待补，牌组已有查找/排序。

| 键 | 行为 |
|---|---|
| 1–9 | 按手牌顺序选择/使用，preview 校验 |
| I | 对象详情与词条 |
| P | 固定/解除悬停摘要，新命令或 Esc 解除 |
| G / F1 | 操作帮助与当前资源说明，尚无搜索手册 |
| D / L | 牌组 / 日志 |
| E | 结束回合，受待选/阶段/重复提交门控 |
| Esc / 右键 | 关闭面板或取消本地草稿，效果内待选必须完成 |

悬停窗按动画后实际卡牌位置避让，修复放大手牌重叠回归。DDL ≤3 有强调色和紧迫文字，≤1 加强提示；风险同时有文字。顶栏显示当前学年。实际渲染检查覆盖 1280×800、960×600，截图不替代最终美术签收。

## 3. 音频现状

| 项目 | 已实现 |
|---|---|
| 总线 | Master/Music/Ambience/SFX/UI，默认 100/70/50/80/70% |
| 设置 | 0–100 整数及静音，应用后持久化并在重启恢复，非法值拒绝 |
| 播放 | UI 单播放器＋8 个 SFX 轮换播放器，同 ID 60ms 防重复 |
| 生命周期 | 脱树不播放，退出停止并清缓存，缺资源可降级 |
| 事件 | 卡牌/任务/状态、论文/章节、伙伴召入替换离场、领奖/交易等 |
| 紧迫 | DDL 剩余时间对应 1.0/0.8/0.6 音高；任务阶段切换独立映射 |
| 资源 | 18 个程序化占位 WAV，44.1kHz、16-bit、单声道 |

占位 ID：ui_hover、ui_click、ui_back、detail_open、error、choice、card_draw、card_play、card_discard、card_exhaust、status、task_hit、task_done、ddl、paper、chapter、victory、defeat。伙伴和阶段目前复用现有音色。

Music/Ambience 总线与滑杆已有，但无 BGM/环境音素材及循环播放器。DDL 变调不等于动态音乐分层完成；Boss 多层音乐、转场/duck、正式混音、来源许可和人工听感仍待完成。[音频说明](../assets/audio/README.md)记录占位来源。

## 4. 四图现状

| 学年 | 主题 | 层数 | 节点数 | 机制 |
|---|---|---:|---:|---|
| 大一 | 适应与基础 | 12 | 20 | 探索 0–6，熟人及经济选项 |
| 大二 | 分流与专业 | 12 | 28 | 四方向与一次付费改向 |
| 大三 | 冲刺与选择 | 14 | 36 | 履历 0–6，折扣/候选/跨年资源 |
| 大四 | 收束与毕业 | 14 | 40 | 毕设 0–5，四去向/延期答辩 |

124 个候选节点均可达，每条通关路线 52 站。每年有无精英通路；实验室与竞赛有风险链，普通接休息、风险接导师，同层社团/实习提供支线服务。每图末层一个学年 Boss 槽位，各年有独立任务、阶段名与递增试玩数值；大四不同去向暂共享阶段模板，专属机制尚待完善。
