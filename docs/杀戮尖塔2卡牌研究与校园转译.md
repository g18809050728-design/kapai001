### 版本和可靠性限制

- 抓取日期2026-10-29，API没有请求beta分支；本次不把网页的beta卡与默认数据混合。网站页面与其他数据库统计口径可能不同，以下载JSON实际行数为准，不宣称“官方最新完整牌库”。
- `/api/versions`实测返回空数组；`/api/changelogs`混合网站发布与游戏更新，不能用最新网站版本1.3.1推断卡牌对应补丁。因此游戏版本记为**未能确认**，以抓取时间、URL和SHA256固定快照。
- GitHub main commit接口遇到403限流，未取得固定commit；已保存的递归树SHA不是本批API卡牌版本证明，不冒称下载来自某个固定commit。health接口403，错误的单数changelog路径404均未作为有效来源。
- Tavily缺少API密钥后改用直接访问上述公开接口；不将搜索摘要当作卡面原文。数据项目及接口字段说明见[上游仓库](https://github.com/ptrlrd/spire-codex)及[API文档](https://spire-codex.com/docs)。
- [Untapped卡牌页](https://sts2.untapped.gg/en/cards)已保存静态HTML，交叉阅读了Acrobatics、Afterimage、Tools of the Trade、Glacier等代表牌。它只作少量文本旁证，没有逐张验证577条，也不用于声称胜率或“公认最强流派”。

中英原始快照、角色说明和响应元数据留在本地工作区；[来源清单](../artifacts/redesign-20261029/source-manifest.json)记录请求来源与抓取信息。中文卡表SHA256为`68710d545e5744d986cdd0139ec2b2b0f21a21af2985a852d3f1c4cee8aada96`；英文为`fa908e4c6f77026a93fe5b8fff25f307fade8b6feb698cd5835e3f40107a39b8`。

## 2. Excel如何保留原始含义

总表保留来源ID、中英名称、color、费用与星费用、X标记、类型、稀有度、目标、基础文本、关键词、升级正文、升级patch、变量、生成牌、多人标记及完整来源JSON。颜色与强调标签在阅读列移除，能量与星图标转为`[能量n]`、`[星n]`，原始富文本仍在独立列及JSON中。

36条记录没有upgrade对象，141条记录没有升级正文。两者不是同一概念：例如“七星”的升级patch为`cost:1`，没有升级正文，不能写“无升级”；“余像”的patch为`add_innate:1`，正文不变也有关键词变化。Excel保留这些差异，仅在明确提供费用字段时生成升级费用，**没有自动重建所有升级卡文**；读者应同时看升级正文、费用和原始patch。空值保留来源未知，不伪造效果。

数据表带筛选、冻结窗格、换行及分类统计图。回读检查验证行数、唯一ID、中英ID对应、工作表、起手张数及不存在公式；检查结果见本地留存的workbook-validation.json。本轮没有在桌面Excel逐页人工视觉验收；文件级可读取不等于已验证所有显示尺寸。

以下是本项目的分析标签，**不是原作官方命名或玩家胜率结论**。15组模式覆盖36张真实代表牌；未标注的牌表示未逐张归纳，不表示没有协同。完整模式、代表ID和转译方向见Excel“流派模式分析”。

## 4. 如何落到我们的四个人物

林序的资源叫编译，但重点是“低费验证、排序、发布窗口”，而不是给故障机器人换电脑立绘。许知微的主动弃牌表现清理无效记录，但失败复盘又能利用误差；生成数据、防护和报告提交共同形成实验闭环。沈见章同时管理引用和一份稿件，让“查够资料还是先交”成为明确选择。唐以宁的伙伴有有限驻场，考试面仍能启动协同、抽牌和完成任务，因此选合作路线不等于主动在期末失去牌组。

每人40种分为三条流派各10种，加通用衔接10种，包含启动、防护、转化、兑现与桥接，角色内可以混合。公共8张体现生活和学习工具，不提供全员可互换的专业资源。完整决策、费用、升级、考试面、获取与迁移见[角色设计](角色与专属卡池重设计_v2.md)与[逐张卡表](校园卡牌设计表_v2.md)。

本轮完成的是有来源的研究与可评审卡面，并未运行新版。任何“强度适中”“四人胜率接近”“不存在无限循环”的判断都需要后续独立实现与样本，当前不作结论。
