## 文档核查命令

[核查程序](tools/verify_g0.py)使用Python标准库，可在项目根目录运行：

```powershell
& 'F:\minGw64\ucrt64\bin\python.exe' tools/verify_g0.py
& 'F:\minGw64\ucrt64\bin\python.exe' tools/verify_g0.py --documents-only
& 'F:\minGw64\ucrt64\bin\python.exe' tools/test_verify_g0.py
```

其他环境可用`python tools/verify_g0.py`。默认核查文档完整性和登记的G0就绪条件；`--documents-only`只检查文档，不能据此判定阶段通过。退出码0表示所选检查通过，1表示文件/链接/hash/基线结构错误，2表示文档有效但G0仍有阻塞。脚本核查ID、来源和明确的基线断言，不编译GDScript、不加载游戏内容、不证明所有自然语言语义一致；语义复核记录与机械报告共同构成G0证据。

[核查器回归程序](tools/test_verify_g0.py)在临时副本中运行9个真实CLI场景，覆盖正常基线、坏链接、来源hash漂移、额外MVP内容、非法地图边、缺失用例、数值漂移、重开MVP未决项及仅文档模式；退出码0表示各场景实际退出码及预期诊断均符合要求。它验证核查器的报错行为，不执行游戏用例，也不修改正式基线。

每次运行生成`artifacts/verification/<run-id>/`，保存`command.json`、`environment.json`、`inputs.json`、`stdout.txt`、`exit_code.txt`、`report.json`和`report.md`。输入hash对应该次检查快照；修改任何基线文档后重新运行。失败报告同样保留，不能用新通过结果覆盖失败证据。
