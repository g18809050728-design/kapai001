## 启动与核验

使用 Godot `4.7.2.stable`，在项目根目录启动：

```powershell
$env:GODOT_BIN = 'F:\GoDot\Godot_v4.7.2-stable_win64_console.exe'
& $env:GODOT_BIN --path .
```

玩家数据位于 `user://saves`（Windows 默认 `%APPDATA%\Godot\app_userdata\交大四年：DDL战争\saves\`）。同一账户下重新下载项目仍会使用此处进度；验收目录不作为玩家存档加载，发布包不要带入用户存档。菜单可配置新局后明确确认替换，取消保留旧局；损坏旧档先归档再重开。

```powershell
.\tools\verify_g1.ps1
.\tools\verify_g2.ps1
.\tools\verify_g3.ps1
.\tools\verify_g4.ps1
.\tools\verify_g5.ps1
python tools/verify_g7.py --godot $env:GODOT_BIN
```

本轮设计核查命令为 `python artifacts/redesign-20261030/verify_delivery.py`，实际输出及边界见[核查记录](artifacts/redesign-20261030/validation.md)。生成器、备份和机器报告保存在本轮交付目录。旧 `verify_g0.py` 固定检查 v1 来源；旧文档可从 Git 历史查阅，须在隔离历史目录运行，不得以当前根目录运行结果代表新版 G0。上述 Godot 工具仍针对 v1 程序。工程环境依赖见 `requirements-dev.txt`；各阶段命令和证据解释见相应执行记录。本轮未重跑 Godot。
