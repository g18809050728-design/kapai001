# 04 地图、全部局外页面与资源生产

UIR v2｜2026-11-13。地图和局外页面列为首个可玩版本的核心范围；本文件是明确的文字设计提案，不把“以后换背景”当作方案。参考R2-01/02/05/06/08；现状见CUR-01～03/11。

## 1. 全局外框先改，页面才有空间

`GameShell::_build_frame`目前的高覆盖浅色面板将被“场景底层＋窄HUD＋专用页面”替代。GameShell保留路由、保存状态、错误、确认替换旧局和唯一命令交接；页面不能各做一套存档或按钮规则。

1280×800提案：顶部56px为持续HUD，显示学年/角色、精力、金钱、3饰品槽；右侧固定牌组、地图、帮助、设置。战斗专注、DDL与角色资源放战斗专属条；局外没有的专注/DDL不造常驻假资源。状态图形附短数字，完整名称可聚焦查看；点击热区建议至少44×44，关键地图节点至少48×48。全局错误/保存提示使用不遮挡内容的独立通知区。

正常页面不再重复一整排“牌组/饰品/保存/菜单/规则”大按钮。动作按钮依附具体对象或固定确认条，普通导航使用HUD。地图入口在战斗中只能查看已经公开路线，不提供跨节点跳转。100/125/150%字号下重新排版；960×600收起次要标签，保持图标释义与键盘焦点。

统一状态规范：常态、悬停/焦点、预选、禁用及原因、提交中、成功、失败、已完成。所有临时预选使用旧ID并绑定run/revision；已选状态不能只靠颜色。默认“预选→明确确认”的业务模式继续有效。

## 2. 地图：从节点列表改为学年路线画布

### 2.1 布局与阅读方向

主视觉是一张展开的校园行程手册，路径向上推进，顶部是本学年终点。背景为疏朗校园地标速写，路线区域保留足够空白；不用复杂建筑平面掩盖分岔，也不用真实校园地理距离决定规则路径。

| 区域 | 1280×800建议 | 内容 |
|---|---|---|
| 全局HUD | y0～56 | 人物、资源、饰品、牌组、帮助/设置 |
| 学年条 | y64～108 | 大一～大四、当前学年标题、当前层/总层、全图/当前站 |
| 路线画布 | x24～936，y120～716 | 当前站及后续约4～6层；滚动查看全图 |
| 节点预览 | x952～1256，y120～716 | 节点类型/公开名称、情境小图、已知规则、可达原因、确认进入 |
| 底部辅助 | y732～784 | 图例/操作提示；放弃本局收入暂停菜单，不与前进并排抢权重 |

960×600仍保留画布与约240px预览区；150%字号无法满足时，预览变为底部可展开面板，未展开时不遮当前站与下一步。缩略全图为只读概览：点击一个缩略节点回到正常比例并定位，绝不从缩略图直接提交进入。四学年切换只浏览已公开数据；未解锁信息不提前显示，且不改变当前学年。

当前层数12/12/14/14、候选20/28/36/40、总路线52层保持；布局变化只改显示。y轴倒置用于向上前进，不倒置领域layer，不改保存的next_ids。

### 2.3 节点和路径状态

| 状态 | 节点表现 | 路径表现及可操作行为 |
|---|---|---|
| 当前站 | 墨圈印章＋“当前位置”小旗，形状稳定 | 仅它的直接合法后继为下一步路径 |
| 下一步可达 | 清晰轮廓、亮色纸底、小箭头；低频呼吸可关闭 | 当前→可达边实线；可预选与确认 |
| 已走过 | 小勾章，仍可查历史公开信息 | 只对真实经过的边加深，不能把两个visited节点之间所有边都画成走过 |
| 未来未到 | 低对比但类型可辨；公开范围外用未知标识 | 虚线，不允许进入；可说明“需从当前路线继续前进” |
| 已错过分支 | 细虚轮廓，附不可达标识 | 保留拓扑帮助理解，不靠颜色单独表达 |
| 悬停/键盘焦点 | 外轮廓与名称，右侧预览 | 可突出从该节点向前的公开连通关系，但不得暗示可立即跳转 |
| 本地预选 | 回形针标记＋预览栏“待进入” | 确认条显示“进入：类型/公开名称”；再次选别处只改本地草稿 |
| 提交/失败 | 提交中锁该动作，失败清楚说明原因 | stale revision刷新可达状态；不沿错误路径播放成功移动 |

曲线连接使用少量固定控制点，具有手绘笔迹但端点精确。坐标由学年、层、槽位及稳定布局配置决定；禁止使用游戏RNG制造随机抖动。布局后做交叉与图标避让；转弯不能让玩家误认两条边相连。旧档按保存的next_ids画边，不套当前新图模板。

地图装饰和路径分别绘制。当前站移动仅在成功进入节点后发生；路线笔迹描画可与房间淡入并行，建议约120～180ms，减少动态直接更新印章。即使只有一个后继也保留明确进入操作。

### 2.4 输入、返回与边界

滚轮/拖动空白平移画布，拖动超过建议6px阈值后不视为节点点击；阈值待实机验证。节点的点击命中框至少48逻辑像素，装饰超出命中区不另建点击对象。方向键沿可见节点合理移动，Enter预选，确认按钮执行进入；Esc取消本地预选。图例可临时突出一种类型，不能改变实际可达状态。

打开详情或牌组后返回：恢复同一地图滚动与焦点。完成房间后返回：将当前节点和直接后继放到可见区域，保留向前浏览空间；若用户正在同页浏览，只刷新状态不抢滚动。缩放/字号调整后按节点ID定位，禁止以旧像素坐标复位到错误节点。

验收要录下大四40节点、各分岔、旧档多后继、返回定位、预选取消及一次进入；检查124个节点ID和next_ids前后相同。地图的新图形与插画不是通过这项行为验收的替代品。

## 3. 局外页面逐页重做

### 标题与继续游戏

主菜单采用夜间/清晨校园舞台，主操作集中在左侧约30%宽度：继续冒险、新的四年、设置、帮助、退出；测试房间与新游戏/继续并列为主菜单一级入口，无存档可进入，不藏进设置。右侧是角色/校园局部动态，不能铺满高频飘纸。继续按钮附当前角色、学年与可继续状态；不能继续时显示原因，损坏档不能伪装成新档。替换未完局仍需原有明确确认，取消后返回原局。重开成功才转入新舞台。

### 四角色选择

`_render_setup`从四个文字页签＋190×210肖像改为四人底部头像条、左侧大幅全身/局部动态立绘、右侧机制说明。人物切换时短交叉淡入，姓名与三条信息固定：核心玩法、被动当前实际行为、起手代表牌。起始12张牌用统一牌框查看，不把样例牌当完整起手。高级种子折叠，难度与开始按钮固定在底部。P01自动取回偏差继续直接说明；演示循环只说明机制，不在选角页跑真实业务。

### 普通奖励与学年大奖励

普通奖励使用战斗结果背景＋中央领取桌，冻结候选用完整统一卡面横向摆开，主要效果直接可读；已结算金钱单独显示为到账结果，不能让动画再领一次。选择卡后原位加印、确认条显示对象，“跳过”保持次要但可达。确认成功卡飞向HUD牌组，剩余项目继续处理；保存失败区分“业务已生效但尚未保存”。

学年大奖励采用学年报告/成绩册场景。卡牌、调整牌组、资源三类先以明确收益和互斥关系展示；进入类别后固定候选、返回不重抽。升级比较沿用实际当前/升级面，新增数字差异高亮；移除显示具体实例和最低牌数；放弃补偿从quote读取。饰品满3槽时，候选与三个已装备物并列，选替换对象后显示前后对照；不只写“满了”。

### 校园商店、书店与打印店

店内人物/柜台形成场景，商品陈列是主操作区域。1280宽提案优先将常规卡牌并排陈列于桌面，餐食/饰品及移除服务分组放在第二层；按实际库存决定数量，超出容量明确分页并显示数量，避免默认半张卡被滚动裁断。960宽改成3列浏览与固定详情/确认条。商品仍用统一卡面，直接显示费用、主效果和规则摘要；价格签紧贴商品，不能与卡牌专注费用同形。

每个商品有可购买、余额不足、已售、预选、提交中状态。预选后在同屏显示价格、余额前后、真实餐食恢复量与必要替换；确认按钮明确写购买对象。成功盖售罄印、商品交付、金钱更新，继续留店；失败不播放交付。移除服务用橡皮擦/废稿夹作为入口，打开牌组选择，显示实际价格、次数、最低牌数；返回柜台保留位置。离开商店固定右下，不藏在商品末尾。

### 事件房间

采用约55%情境画面＋45%阅读/选择区。场景可铺满屏，但正文后有稳定低对比遮罩；标题、叙事、选项之间有明确间距。每条选项直接显示“行动、已知代价、已知收益”，负后果不藏在悬停，禁用时写原因。局部雨线、台灯、纸页等可循环，选项和文字不移动。

`_render_event`中的event_instance_id、冻结候选、candidate_details和选择阶段保持。需要选卡则在原场景上展开统一选牌层，面包屑显示“事件 → 行动 → 目标”，返回只撤销本地预选。V04“认真复习”单列“消耗6精力／升级全部合格工作牌”，展示所有实例前后对比，无单张选择。确认成功显示真实结果短句，再由原流程离开；失败仍停在可修正的状态。

4个生产事件定义与地图10个事件节点不是同一个数量。插画按事件定义与公开场景变体映射，不为每个地图title臆造新的事件效果。

### 休息与校园服务

基础休息页一进入就显示宿舍场景与当前人物；恢复、复习、训练等实际可用行动作为图形牌/桌面物件摆放，每项有简短结果。预选恢复立即显示`effective_heal_amount`与上限，不等确认后才出现情境图。预选升级/移除展开统一牌组与比较层；有代价的服务在确认前可见。确认后角色坐下休息或翻书，实际结果更新后返回地图；不把动作时长加到业务结算。

图书馆、实验室、导师、社团、实习/招聘、项目服务属于独立情境皮肤与行动内容，复用同一只读quote和选择框架。LAB需要保留至少1精力等既有边界必须直接显示；不能从画面装置推断新增配方/研发玩法。显示哪些选项完全由当前campaign_offer决定。

### 方向、毕业去向及跨学年

方向/去向用横向档案夹，每个选项有现有文案、确定收益/限制、相关情境图和条件。选择后仍可对比其他候选，明确确认后才生效。没有资格的选项保留可读原因；不开新功能或隐藏解锁规则。跨学年采用成绩册翻页与下一年地图标题短过渡，继承资源显示实际前后值；禁止在过渡中重建地图或重抽奖励。

### 牌组、牌堆、饰品、章节与帮助

统一对象浏览层，使用同一CardFaceView。顶部显示所在范围：“永久牌组”“弃牌”“消耗”“抽牌堆公开成员”；搜索/排序/筛选保留现有能力并扩展效果族筛选。排序是本地行为，抽牌堆标题明确“不代表抽取顺序”。同名卡用实例序号和升级级别区分；升级/移除操作必须选具体实例。

详细说明出现在网格外侧或固定阅读栏，不能遮邻卡选择；浏览弹层隔离背景焦点，Esc关闭回到原对象。战斗中I固定仅固定当前说明，沿用现有不锁出牌的行为；不能把局外浏览弹层的模态规则套到战斗说明。饰品展示3槽与条件/计次；章节区展示当前顺序、次回合/准备时点及具体牌，不与永久牌组混为一谈。帮助使用同一图标词典，正文包含放松/屏障的区别。空结果、无合格目标、长文、单项列表与多页列表都有明确状态。

### 设置、暂停、存档和总结

设置以文字、动态、声音、存储分组，使用标准稳定控件，不为校园装饰牺牲可调性。保留已选/当前生效/尚未应用、即时试听与应用保存语义；减少动态优先关闭演出并保留倍速偏好。失败提示说清哪一步失败，不把恢复备份做成无提示的普通按钮。

结局页以学年履历、实际毕业方向/失败原因、牌组与关键结果为主。胜利、精力耗尽、DDL失败、主动放弃按真实结果区分；展示当前局保存、Profile合并、待合并标记的各自状态。再次游玩走既有新局流程，不能用动画重放终局提交。测试房间保留独立HUD/编辑入口、退出回正式上下文；新演出在编辑/换预设后必须清理。

## 5. 资源清单与生产顺序

| 资源组 | 先做的验证样本 | 全量映射要求 |
