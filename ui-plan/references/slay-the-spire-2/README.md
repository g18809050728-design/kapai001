## 时间采样与观察

视频时间从下载文件起点计算；`video-sampling.json` 记逐帧采样位置，`gif-sampling.json` 记 GIF 帧延时。下面的时间只标记证据位置，**不是对游戏动作延迟、帧率或 Tween 曲线的测量**。

| 片段 | 可直接观察的先后关系 | 转译到本项目 |
|---|---|---|
| [Silent GIF](silent_anim-sequence.jpg)，0.00–0.44s、1.10–1.74s | 受击姿态与正常待机不同；行动时手臂/躯干/披风的轮廓发生变化，再回到待机 | 主角需要真实姿态变化；整张肖像平移或缩放不足以达到目标 |
| [敌方 GIF](ento_attack3-sequence.jpg)，0.90–2.02s | 身体由压低转为扬起再向前作用，局部粒子跟随而非全屏遮盖 | 任务拟物敌怪先摆出意图对应动作，再在目标处表现压力 |
| [Aeonglass GIF](final_aeonglass-sequence.jpg)，0.00–1.06s | 环由竖向转为水平，形成易读剪影后发出横向轨迹；之后恢复 | Boss 阶段和重行动用轮廓变化区分；待机纸页、时钟等独立循环不被受击重新开始 |
| [攻击与退场](attack-death-sequence.jpg)，视频1 1.20–1.80s、2.80–3.20s | 来源行动、目标处命中特效和跳字集中，敌人最后呈倒下姿态 | 命中、数值和受击应共用作用点；最后任务完成需要退场，不能先弹奖励盖住 |

| [商人及选卡](merchant-cards-sequence.jpg)，视频1 33.20–35.20s | 先是带人物的店内场景，随后是铺开的商品；价签依附商品；商人手部动态参与画面 | 校园商店需要店景与柜台，而非通用列表；购前效果与价格必须同时可见 |
| 同片段 35.60–36.00s；R2-02 稀有牌 GIF | 奖励牌整体一致，稀有度通过边框/短暂亮边强化，正文区保持稳定 | 统一战斗、商店、领奖的牌框；稀有度不挤占费用或主效果徽标 |

| [事件 GIF](event_3-sequence.jpg)、[桥梁 GIF](event1-sequence.jpg) | 叙事画面占主要空间；悬浮物/雨线在动，选项文字及点击位置稳定 | 事件画面局部循环，不让正文、代价和选项跟随抖动 |

R2-07 的技术启发是把持续循环、动作姿态和材质效果分层；R2-02 的启发是可点击性与少文字导航；R2-05 的启发是情境和选择的视觉分工。本作的具体形状、时长、阈值及代码拆分是我们的设计建议。

## 已知研究边界

已核对战斗、地图、商店、事件、休息、选角、奖励等代表画面及连续动作。尚未获得带版本号的二代完整无剪辑操作录像，未测量其按钮悬停阈值、地图滚动惯性、全键盘流程、牌组检索、设置页和异常交易行为。涉及这些方面的本项目规格明确按现有程序和用户需求设计，不挂“二代已验证”的名义。

本目录媒体仅作设计研究与评审，不加入 `assets/`、`UiStyle` 索引或正式导出。首个发布候选需要检查导出过滤；当前本轮未修改导出设置。
