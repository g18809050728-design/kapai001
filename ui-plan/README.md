## 范围与实施顺序

当前 `campus_four_year` 的 338 个启用定义包括 4 角色、174 卡、16 饰品、56 任务、53 遭遇、7 单位、7 场景、4 事件、16 状态和 1 ruleset。卡表有 172 张可升级卡、14 张考试替代卡、17 张能力卡、6 张章节卡。这些是内容覆盖数量，不能直接当作新图片订单。

实施顺序调整为：**事件/视图依赖与统一视觉规则 → 同时覆盖地图和战斗的资源样本 → 地图—战斗—奖励及地图—商店/事件/休息两个闭环 → 四角色和全部页面扩展 → 全量验证**。地图和局外页面从首个可玩版本开始进入，不再排到战斗全部完成之后。

本次已将关键布局、图标、动作和模块迁移写为可评审方案。G6 负责资产核对，G7 负责将方案落实并实机校准；不能再次把所有关键决定都写成“以后设计”。资源生产、实现和验收仍遵守[根计划 §0.19.2 与 G0–G8](../实施计划与验收基线.md)。本轮没有改动游戏代码、规则、正式素材或玩家存档，也没有生成新概念图。

## 设计取舍

采用有明确前后景和局部形变的二维手绘舞台：墨线区分轮廓，低饱和校园场景提供空间，纸质卡牌承载规则，朱红用于风险，青绿用于放松与可操作状态。避免把整屏都做成同色纸张、厚边框和泛金光。

参考二代的交互层级、图形地图、场景化房间和动作因果，保留本作的工作量、放松、DDL、论文、伙伴与学年机制。不会加入药水栏、多人投票、随机宝箱节点或地图绘画等当前程序没有的玩法。新增图标表达实际规则，不能依卡牌类别推断效果。

本版完成的是可执行计划及现状研究。正式美术签收、事件补齐、UI 实现、真人可用性、性能和 G8 完整四年路径均仍待执行。
