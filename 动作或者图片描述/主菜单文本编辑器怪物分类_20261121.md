# 文本编辑器怪物实体分类（UIR-078）

- 来源：用户 2026-11-21 要求“在上述分类后面添加怪物分类并将怪物实体划分进去”。
- 分类顺序：全部、卡牌、饰品、人物、剧情、词条、**怪物**、其他。
- 怪物实体：60 个正式任务（普通、精英、首领、附属）。
- 怪物字段：
  - 名称（`label:<task id>`）
  - 已有阶段名称标签（`label:<phase.name_key>`）
  - 已有意图名称标签（`label:<intent.text_key>`）
  - 只把文本库中真实存在的标签字段归入怪物；没有标签的阶段/意图仍由规则/硬编码默认值显示，不伪造新覆盖项。
- 分类过滤：怪物类型（普通/精英/首领/附属）。
- 兼容：怪物名称与意图/阶段标签从“其他”移入“怪物”；剩余“其他”198 个旧/共享名称实体保留。旧覆盖 UID 不迁移、不删除。
- 不变：规则、数值、压力、屏障、阶段顺序、命令、RNG、存档 schema 和正式存档。
- 验收：60 个怪物实体；怪物名称搜索只返回一个实体；意图字段修改影响对应共享意图文本；类型过滤；旧 UID 全归属；完整回归与实际实渲。
