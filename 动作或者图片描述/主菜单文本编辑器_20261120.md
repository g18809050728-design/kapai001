# 主菜单文本编辑器需求（UIR-076）

- 来源：用户 2026-11-20 直接要求“在游戏的主菜单界面添加一个能够自由检索浏览游戏内任意文本并进行编辑的文本编辑器”。
- 目标界面：主菜单“文本编辑”入口；不新增开局、测试房间或进行中冒险的入口。
- 核心能力：
  1. 对全部可编辑游戏文本建立统一目录，至少覆盖人物/卡牌/任务/饰品/事件/状态等名称、事件与房间剧情、规则词条、卡牌/饰品/人物被动说明。
  2. 支持按正文、ID、来源、分类自由搜索，按名称/说明/剧情/词条分类浏览，并可持续向下加载。
  3. 选中条目后在多行编辑框中修改；支持保存、撤销本条未保存修改、恢复本条默认、全部重置。
  4. 保存到本机覆盖文件，重新启动后仍生效；返回菜单或继续游戏后立即使用新文案。
- 安全边界：只修改显示文字；不得改变卡牌/任务/费用/效果/命令/RNG/存档 schema、正式存档文件或当前对局状态。原始 JSON/GDScript 文本保持，可恢复。
- 交互与可用性：
  - 1280×800 与 960×600 窗口，100/125/150% 字号下可读、可操作；主按钮至少 44 像素。
  - 有未保存修改时返回需二次确认；Ctrl+S 保存；Esc 返回/关闭默认文本。
  - 空搜索结果仍保留返回与重新搜索；文件损坏时回退原始文本并给出提示。
- 验收证据：实际主菜单/编辑器实渲、全量条目集合与分类计数、搜索/编辑/恢复/持久化/域不变检查、完整 UI 与规则回归。
- 不在本批：GDScript 中固定写死的按钮/提示文字（仍随程序），以及由规则实时拼装的数值短句；这些不属于可由内容数据安全替换的文本。用户最终视觉签收与原 G0/G6/G8 整版出口另记。
