# UI图片与动作文字需求

当前设计入口为[角色卡池v2需求](角色卡池重设计需求_v2.md)及[需求台账](需求台账.md)。新版四人各40种专属的浏览/筛选、资源、唯一草稿、逐牌考试面和每人46种奖励资格共登记5项VIS、1项ACT；均仅文字、待实现、未验证。页面目标以[界面层契约](../docs/界面层契约.md)为准。

本轮不生成新图片、不确定新布局或动画分镜、不实施UI。按[根计划](../实施计划与验收基线.md)先完成新版G0–G5；图片制作与资源核对在G6，详细设计与实现进入G7，完整可见用户路径在G8验收。

## 需求登记

新增需求先登记唯一ID、来源、页面/组件、触发条件、要表达的信息/动作、禁用/失败状态及未决项，可用[单项模板](描述记录模板.md)。已有需求发生变化则同步原记录。ID不复用，v2使用R2-VIS/R2-ACT，保留旧VIS/ACT用于追溯v1。

需求状态依次为“需求已登记→资源已核对（适用时）→设计已确认→已实现→已验证”。无需图片可注明跳过资源环节；“设计已确认”不能冒称用户人工签字。实现和验证须链接实际文件、触发输入与结果，截图不能单独替代行为证据。
