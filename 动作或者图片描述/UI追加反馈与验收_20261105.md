# UI 追加反馈与验收

日期：2026-11-05。来源：用户三张 `image copy*.png` 与同次文字反馈；延续 FY-UX-001～015，实施范围见[根计划 §0.13](../实施计划与验收基线.md)，设计见[本轮设计](../docs/plans/2026-11-05-ui-followup-design.md)。以下条目均已实施，逐项真实验证及剩余人工验收见[本轮记录](../docs/UI追加反馈实施记录_20261105.md)，旧证据不替代新结果。

| ID | 需求与可观察条件 |
|---|---|
| FY-UX-016 | 奖励、商店、目标和牌组卡牌在反复悬停、聚焦、点击和取消后保持尺寸稳定；选中仅改变边框和标记，不纵向增长。100/125/150% 字号下文字完整可读。 |
| FY-UX-017 | 地图当前节点使用明显加深的底色，优先于已完成标记；每次业务返回地图，在容器布局和滚动恢复之后居中显示下一可达层；本地预选、查看保持手动滚动。 |
| FY-ART-003 | 生成一张校园餐食图，沿用米白纸、水彩、深青细线风格，接入商店餐食；保留提示词、参考图、原件、生成参数、hash 和核查结果。 |
| FY-AUD-003 | 用柔和纸张/木质短音替换尖锐音色，降低音量并限制突发叠加；悬停静音、低价值逐牌/状态事件合并或抑制；保留重要操作/失败/结局反馈和个人音量设置。 |
| FY-UX-018 | 事件行动、饰品候选、升级/移除目标及服务预选后，候选原位保留并高亮所选，底部确认；需要额外目标时在同页增加选择，不用孤立名称替换全部内容。 |
| FY-UX-019 | 学习方向/毕业去向用已有相关插画、等宽图文面板填充；全部选项、已知后果及确认入口可见，预选只读。 |
| FY-UX-020 | 核查用户称“循环爆发”的卡牌（当前目录近似名为“循证爆发” R3-P03-19）；完整显示触发条件、下回合生效、次数和完成量，按权威卡表验证实际效果，不凭描述改造规则。 |
| FY-UX-021 | 战斗右上规则与记录交换位置，专注和结束回合采用统一纸面、青绿与暖金表现；标准/紧凑模式保留动作 UID、键盘及输入锁。 |
| FY-UX-022 | 抽牌/弃牌/耗尽详情用可滚动卡牌网格显示卡面和说明；抽牌堆只公开稳定排序后的成员集合，不提供实际抽取顺序，不推进 RNG。查看不能打牌或改变状态。 |
| FY-UX-023 | 无可继续对局时继续按钮灰显禁用；没有未结束旧局时，新建配置提交后直接开始；未结束或不可读旧档保留替换确认及原件保护。 |
