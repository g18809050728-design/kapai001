# G7 一学期界面与交互设计

日期：2026-10-15。依据既有界面契约及用户继续推进指令实施；资源为 G6 已核对的 46 张实底插画，视觉核对细节见 [G6 记录](../docs/G6资源准备执行记录.md)。用户未提供生图平台授权信息，发布前来源许可核验保留在 G8，不能把 AI 视觉核对写成人工审批。

## 视觉与页面

采用原生 Godot Control，1280×800 设计画布、960×640 最小窗口，随窗口缩放。米白纸面、深青文字、鼠尾草绿按钮、暖黄强调。字体使用系统中文回退；不把系统字体文件复制进仓库。背景仅营造校园氛围，文字放在不透明纸色面板上；人物和卡图以完整实底插画显示，不拉伸、不冒充透明立绘。主体区滚动，提示区常驻，按钮支持键盘焦点及悬停原因。战斗去掉顶部大插画，资源栏与两行操作置顶；任务/单位与选择/状态分别使用 190 高独立滚动列，手牌区高 220 并横向滚动，保障 960×640 下核心操作可见。卡面以 15 号文字并列显示专注与精力代价，零值照常显示；效果两行、悬停查看全文。

| 需求 | 布局与行为 | 可观察验收 |
|---|---|---|
| VIS-001/002 | 菜单显示标题、新学期、继续与设置；选人显示 P01/P04 原画、初始内容、正常难度和十进制 seed | 无档继续禁用；内存局优先继续；开局经 StartRunRequest；有旧局不覆盖 |
| VIS-003 | 自动保存设置、正式档和备份状态，明确恢复备份按钮 | 所有操作只经 GameSession；恢复来源可见；保存失败仍保留当前局 |
| VIS-004 | 地图按层展示节点，列出真实 next_ids 对应关系及状态 | 不可达节点 disabled，点击不改 revision；已完成节点与下一步清晰区分 |
| VIS-005/006 | 奖励与商品采用插画面板；候选、价格、替换饰品、删牌操作并列 | 草稿随当前选择生成，preview 决定能否领取/购买/离开 |
| VIS-007/008 | 事件显示成本、效果、候选；休息显示四类操作和牌目标 | 未完成决策不能离开；非法目标说明原因；重复绘制无旧按钮 |

| VIS-010/011 | 完整版本中间学期与毕业选择 | 本 MVP 不适用，不创建虚假可达页面 |

## 动作

- ACT-001：按钮点按立即反馈；选择候选只更新本地选中标记并重新预览；放弃必须出现第二次确认。所有规则操作经 shell → GameSession，导航不推进规则。错误和保存状态显示在固定提示栏。
- ACT-002：点击手牌后由预览提供目标/换班候选；补齐后提交。取消只清本地选择。待选候选来自 ChoiceRequest，确认按钮受 preview 门控；抽牌堆只显示数量，弃牌/消耗堆仅展示公开牌面。
- ACT-003：每次已接受命令先刷新完整只读视图与日志，再播放事件提示；动画约 0.12 秒/事件，可关闭或加速。动画不发规则命令、不写规则状态、不阻塞保存稳定性；按 run_id/revision/index 去重；来源/目标文字取同批日志标签快照，不显示内部实例编号。待选期间动画开关锁定。

## 实现与证据

共享控件 `src/ui/ui_page.gd`、样式/资源 `ui_style.gd`、会话路由 `game_shell.gd`、局流程 `page_flow.gd`、战斗 `battle_screen.gd`。UI 只读 GameSession 视图和独立美术/文案资源，不加载生产定义或存档。测试走真实 Button.pressed，使用隔离存储，覆盖页面门控、真实引擎战斗、稳定保存继续及动画 A/B。实际通过状态以 [G7 执行记录](../docs/G7界面执行记录.md) 为准；本文不是测试通过证据。
