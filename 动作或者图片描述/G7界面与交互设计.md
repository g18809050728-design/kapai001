# G7 一学期界面与交互设计

日期：2026-10-15。依据既有界面契约及用户继续推进指令实施；资源为 G6 已核对的 46 张实底插画，视觉核对细节见 [G6 记录](../docs/G6资源准备执行记录.md)。用户未提供生图平台授权信息，发布前来源许可核验保留在 G8，不能把 AI 视觉核对写成人工审批。

## 视觉与页面

### 2026-10-15 战斗改版

按用户要求采用独立全屏战场：上方紧凑信息栏，左侧角色肖像和资源，中央偏右摆放任务及公开意图，友方单位在左侧协作区，底部扇形叠放竖版手牌。整张牌可点击；悬停抬起、放大并置前；拖出手牌区域后在合法目标松手出牌，无目标牌在战场松手提交，非法位置或拖回手牌区取消，右键/Esc 取消本地操作。保留点击选牌再点目标路径。目标候选仅取 preview，不在 UI 推断规则。结束回合位于右下，牌堆位于底角，日志/规则/牌堆为覆盖面板；pending_choice 用居中遮罩选牌面板，确认固定可见。1280×800 舞台等比适配最低 960×640，战场及手牌不滚动；候选过多时仅模态候选区滚动。当前改版的实际验证以新一轮 [G7 记录](../docs/G7界面执行记录.md) 为准，旧布局证据仅保留为历史。

采用原生 Godot Control。局流程页面沿用米白纸面、深青文字和纵向滚动；战斗使用教室全景及深色遮罩、紧凑顶栏和暖黄目标高亮。字体使用系统中文回退。人物和卡图以实底插画按比例显示，不冒充透明立绘。手牌基础卡面为 168×244，显示插画、名称、费用角标、效果及底部专注/精力代价，零值照常显示；悬停可看完整效果与 preview 原因。候选缺少报价时显示“— / 效果候选”，不编造零费用。待选模态遮住后台，候选以卡面边框表达选中，确认按钮固定可见。

## 动作

2026-10-16 体验打磨补充（已完成必要验证）：地图首屏显示当前可进入的下一站，再展示完整路线；节点仍需玩家主动点击。局流程资源栏提供牌组/饰品详情覆盖面板，打开后隔离背景焦点，关闭后保留原页滚动；商店商品和删牌目标展示真实效果，离店按钮在商品之前可见。休息先选择恢复/升级/移除/训练，再显示对应面板；升级目标采用两列并展示当前与下一等级效果，恢复显示实际恢复量和基础上限。战斗可查看整个牌组及饰品，但抽牌堆仍只公开数量；弃牌/消耗堆显示公开牌效果，数字键 1–9 选择手牌（无目标牌直接使用），Esc 关闭详情或取消预选，待选及信息面板打开期间屏蔽出牌快捷键。通关明确说明本版本只含第一学期，新开局重新开始第一学期。功能及实际截图证据见 [G7记录](../docs/G7界面执行记录.md)。

- ACT-001：按钮点按立即反馈；选择候选只更新本地选中标记并重新预览；放弃与替换旧局必须明确确认。所有规则操作经 shell → GameSession，普通导航本身不推进规则；完成节点后的自动衔接另行提交公开命令，每条分别校验、保存并增加一次 revision。错误和保存状态显示在固定提示栏。同页选择、购买、保存后保留滚动位置；切页、换局或换节点回顶部，旧重绘的延迟恢复不能覆盖最新页面。
- ACT-002：手牌悬停放大；按住移动超过 10 像素进入拖拽，显示拖动副本、瞄准线与合法目标高亮。合法目标松手提交；无目标牌拖入战场松手提交。拖回手牌、非法位置、右键或 Esc 只清本地草稿。点击出牌路径仍可用，换班候选来自预览。待选来自 ChoiceRequest，鼠标点选卡面后确认；后台手牌、目标及其他规则命令锁定，模态内另有新学期入口，取消配置可返回原待选。抽牌堆只显示数量，弃牌/消耗堆仅展示公开牌面。
- ACT-003：每次已接受命令先刷新完整只读视图与日志，再播放事件提示；动画约 0.12 秒/事件，可关闭或加速。动画不发规则命令、不写规则状态、不阻塞保存稳定性；按 run_id/revision/index 去重；来源/目标文字取同批日志标签快照，不显示内部实例编号。待选期间动画开关锁定。

## 实现与证据

共享控件 `src/ui/ui_page.gd`、样式/资源 `ui_style.gd`、会话路由 `game_shell.gd`、局流程 `page_flow.gd`、战斗控制器 `battle_screen.gd`、舞台布局 `battle_layout.gd`、卡面 `battle_card.gd`、瞄准表现 `battle_aim.gd`。UI 只读 GameSession 视图和独立美术/文案资源，不加载生产定义或存档。测试使用隔离存储：原按钮套件覆盖页面门控、真实引擎战斗、稳定保存继续及动画 A/B；`test_ui_battle_pointer.gd` 通过真实 viewport 鼠标/键盘输入验证悬停、拖放出牌、取消和待选锁定。实际通过状态以 [G7 执行记录](../docs/G7界面执行记录.md) 为准；本文不是测试通过证据。
