SPINE NOTES

Dependency

• Spine runtime is required to use this package.

• Download and install Spine runtime v4.3 in your Unity project. The download link is also included in the documentation within the package.

 

Original Spine File Included

The package includes ready-to-use part sets and original Spine source files. Spine Editor users can modify their own parts using the originals included in the asset. Please note that editing the original files requires a Spine Pro license (the originals use meshes).

⚠️ Spine License Notice

This asset package contains animations created with Spine, which run via the Spine-Unity runtime.

Building / distributing a game that includes the runtime → Required

Editing the .spine source files / creating new content → Required (Professional)

• When a license is NOT required: Evaluating or testing the runtime Distributing a product as-is, without modification
