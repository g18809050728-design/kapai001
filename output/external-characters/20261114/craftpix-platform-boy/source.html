Cartoon Boy Character Animation Sprites

Description

Here is Cartoon Boy Character Animation Sprites for your project. This is a set that contains only one hero, but with huge potential for implementation in your 2D game project. Here you will find a character (a guy in a blue jacket and a helmet on his head). As well as unique motion animation sprites such as: idle, idle shoot, death, get hit, fall, jetpack, roll, swimp, jetpack shoot, jump, walk, on skateboard, on skateboard 2, on skateboard jump. In addition to these sprites, the archive contains individual body parts of the protagonist. This makes it easier to edit and change them.

Use this package to diversify your game world with new characters. Players will definitely appreciate the quality and graphics capabilities of this pack. The graphics here are vector, so absolutely any vector editor, such as Adobe Illustrator, is suitable for editing.

  • Quantity: 1 character;
  • Files: AI, EPS, PNG, Spine.
