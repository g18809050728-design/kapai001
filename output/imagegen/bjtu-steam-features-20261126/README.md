## 建议配文

大作业还没交，考试周已经来了。《交大四年：DDL战争》把北交大的四年校园生活做成一款回合制策略卡牌游戏。选择自己的主角和校园路线，构筑牌组，赶在 DDL 归零前完成任务。

### 01 · 大作业，回合制解决。
课后习题、英语作文、讲座考勤，统统变成看得见的对手。看清任务下一步要做什么，决定是推进进度，还是先留一点余地。

### 02 · 同一场 DDL，四种解法。
林序擅长复用策略，许知微围绕论文和章节做文章，沈见章利用侵蚀联动，唐以宁则靠伙伴协同。选择一位主角，再用他的专属卡牌打出自己的节奏。

### 03 · 四年怎么走，由你选。
从大一到大四，每学年的路线都有分岔。是赶下一场任务、进实验室，还是先找地方休息？在进入节点前，先看看前面可能遇到什么。

### 04 · 校园日常，也会出难题。
宿舍突然断电，休息能恢复精力，复习则要消耗精力来升级符合条件的工作牌。一路上还会遇到选课咨询、捡到校园卡等校园事件。
